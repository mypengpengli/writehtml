模型与联网设置

      

        
文字模型用于 AI 助手和改稿，可填写你的 OpenAI 兼容中转站。勾选“直接发送语音”时，录音会原样交给当前模型；不勾选才使用下方转写服务。

        
        
        
        
        
        
        
        
        
保存后可在编辑器顶栏或 AI 助手中快速切换；所有常用模型共用上方 Base URL 和 API Key。

        
        

        
联网搜索

        
        

          
          
        

        
输入内容会整体替换当前 Key 池；留空则保持不变。Agent 会逐次轮换，当前 Key 不可用时自动尝试下一条。

        
        

        
        

        

        
        
        
        
        
        
        
模型 ID 可自由填写，不要求 OpenAI 官方 Key；但该中转站必须实际支持 OpenAI 兼容的 /audio/transcriptions 接口。
