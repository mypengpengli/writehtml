# 跨体系技能对撞设计参考

## 体系对照表

### 修仙 vs 科技

| 修仙技能 | 科技对应 | 对撞效果 |
|----------|----------|----------|
| 万剑归宗（无数飞剑齐出） | 浮游激光炮阵列（无数光束齐射） | 剑光与激光交织，金色剑气撞上蓝色光束，空中炸开无数火花 |
| 金钟罩/护体神光 | I力场/能量护盾 | 金色光罩与蓝色力场碰撞，交界处产生涟漪波纹 |
| 御剑飞行 | 机甲高速飞行 | 空中追逐战，剑光拖尾vs推进器尾焰 |
| 五行遁术 | 光学隐身/热隐身 | 一个融入自然元素，一个科技隐形，互相探测 |
| 神识探查 | 雷达/传感器扫描 | 无形神识波vs电磁波，范围和精度各有优劣 |
| 天雷引（引天雷攻击） | 轨道离子炮（卫星打击） | 紫色天雷vs白色离子束，从天而降的毁灭对决 |

### 魔法 vs 超能力

| 魔法技能 | 超能力对应 | 对撞效果 |
|----------|----------|----------|
| 守护神咒（银色守护灵） | 心灵冲击波（紫色精神波） | 银色灵体挡住紫色冲击波，碎裂后重组 |
| 除你武器（缴械咒） | 念动力（控物） | 双方争夺同一件武器，物体在空中拉扯 |
| 幻影移形（瞬移） | 超级速度 | 一个凭空消失重现，一个残影连连 |
| 变形术 | 形态变化能力 | 双方不断变形对抗，形态千变万化 |
| 火焰熊熊（烈火咒） | 元素操控（火焰） | 魔法火焰vs异能火焰，颜色不同（红vs蓝），争夺控制权 |
| 统统石化（石化咒） | 时间减速 | 一个让身体石化，一个让时间凝固，效果类似但原理不同 |

| 修仙技能 | 魔法对应 | 对撞效果 |
|----------|----------|----------|
| 筑基期灵力护盾 | 盔甲护身（防御咒） | 东方灵光vs西方魔力，金色vs银色光芒碰撞 |
| 符箓（爆炸符） | 爆炸咒 | 符纸燃烧爆炸vs咒语光球爆炸，冲击波对撞 |

| 剑修剑意 | 魔杖核心共鸣 | 意志力对决，剑意锋锐vs魔力浑厚 |

### 科技 vs 超能力

| 科技技能 | 超能力对应 | 对撞效果 |
|----------|----------|----------|
| 重型机甲（钢铁巨人） | 超级力量（肉身硬扛） | 钢铁拳头vs血肉之躯，力量碰撞产生冲击波 |
| 浮游炮群（远程火力） | 念动力护盾（弹开一切） | 无数光束打在念力护盾上，如雨打伞面 |
| EMP电磁脉冲 | 能量吸收能力 | 科技克制手段被异能者吸收转化 |
| 纳米修复系统 | 超级再生 | 机械修复vs生物再生，速度竞赛 |

## 克制关系总则

- **修仙克魔法**：灵力纯度高于魔力，高境界修士可破解大部分魔法
- **魔法克科技**：魔法可干扰电子设备，咒语无视物理防御
- **科技克超能力**：科技装备可针对性压制特定异能
- **超能力克修仙**：心灵系异能可干扰修士心境，破坏修炼状态
- **注意**：克制关系非绝对，实力差距可逆转克制
