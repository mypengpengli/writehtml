# Word 图文资料归档

作者明确要求整理、导入或绑定 Word 资料时使用。先用 `read_imported_document` 读取文档原文、图片索引、章节索引和警告；长文分页读取，不能只处理被截取的附件前部便宣称全部完成。

- 人物固定身份与外貌用 `list_characters` / `save_character_card`；地点、建筑、场地、道具、组织标识归属于相应 `list_story_cards` / `save_story_card` 对象。
- 总纲、卷纲和未来章节安排用 `save_story_plan`，标为作者计划，不写进世界规则或已发生事实。
- 已写小说篇章可用 `import_document_chapter` 按文档章节索引原文复制，不重写。索引只是标题切分，不代表一定是已写正文；先阅读内容，排除章纲。没有标准章节标题时可使用现有新建与写入正文工具。导入到已有正文前需先读取并得到作者明确覆盖指令；默认新建，不覆盖作者手稿。
- 图片编号与附近标题、图注用于定位。需要判断视觉内容时用 `inspect_resource_image`；只有看图模型才能可靠理解实际图像，不能在纯文本模式下编造看图结论。归属不明、多人同框、示意图与正文矛盾时留在待归类图库，并提出具体待确认项。
- 用 `bind_resource_image` 绑定正式对象。人物为 `character`，其他设定为 `card`。名称描述具体版本，例如“林晚·冬季制服”“雾港·灾后广场”。衍生类型包括基础、服装、形态、状态、损毁、季节、标识及其他；有明确对应原图时填 `parent_image_id`，有明确剧情时点时填 `chapter_id`。不要默认把本轮所在章节作为图片时点。
- 同一对象允许多张基础图与衍生图，保存新图不覆盖旧图。仅在作者要求时 `set_primary=true`。同图需要用于多个对象时先 `copy_resource_image`，不能更改原绑定。
- 每一项以实际工具成功结果为准。最后简短汇报导入的规划、正文、设定与已绑定图片，以及保留待归类的图片和不可读取的格式。
