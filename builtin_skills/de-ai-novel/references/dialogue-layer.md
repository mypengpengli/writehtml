## 十四、对白去AI味专项（2026-08-25）

> 本文件为对白层完整正本（含全部示例与详述）。
> 定位：管**对白层**（引号内对话 + 独立段独白）的 AI 味；与叙述层专项（1-14 / 9.x / 17类 / C类）互补，二者合起来 = 全文覆盖。

### 14.0 与现有体系的接口（不冲突三原则）
1. **豁免机制分层**：语境三分类豁免法豁免的是**词面规则**（被 / 很X / 发X / 破折号密度）——对话 + 独白内豁免；**句式规则**（排比三连 / 金句腔 / 演讲腔 / 电报体 / 升华收尾）对话**不豁免**，由本专项管。17类清单"十"行已同步修订（原"对话可留"已改）。
2. **专项12（排比并列）分工**：正文排比→专项12（论证句式，正文杜绝）；对白排比→本专项五问（同构/空转/人设/口语/重叠），角色刻意排比（演讲/人设）为唯一例外。
3. **专项5（升华收尾）分工**：正文段末升华→专项5（写完画面就停）；对白/独白以金句收尾→P13（升华式结尾），大部分改日常收尾，升华只留给情绪顶点。

### 14.1 五问检测法（对白逐句执行，五问全过才合格）
1. **同构问**：对白里有没有"A，B，C"三连排比？（逗号排比"为了家族，为了尊严，为了她"；句号排比/电报体"三短句+句号+零口语粘连"）——无→下句；有→进入二问。
2. **空转问**：删掉任一项信息受损吗？第三项无实指吗？——不损/无实指→删空转项。
3. **人设问**：换成任何同类角色都成立吗？（遮名测试）——成立=通用模板，重写为专属或删。
4. **口语问**：大声读出来像口号还是人话？（停顿/犹豫/口语词/长短错落=人话；对仗/均匀节奏/石碑感=口号）
5. **重叠问**：排比后面紧跟解释句把意思又说了一遍吗？（语义重叠=排比纯铺垫，删排比留解释——一句话只说一遍）

| P02 | 万能金句 | 一句能刻在石碑上的话 | 删 / 让人说不完整 |
| P03 | 演讲腔/口号腔 | 铿锵有力打拍子 | 打散：停顿/口语词/动作打断 |
| P04 | 情绪标签对白 | "我很愤怒" | 删标签，语言内容流露情绪 |
| P05 | 对称对话 | 你一句我一句完美对称 | 破坏：打断/抢话/沉默/失衡 |
| P06 | 信息倾倒 | 一口气交代背景设定 | 拆散/行动化/只给必要（话痨人设=刻意设计，可留） |

### 14.3 七种改写方法（五问/模式库定位后调用）
1. **打散对仗**：砍空转项 + 长短句交替 + 加口语词 + 打破工整
2. **化口号为人话**：停顿犹豫 + 具体指代 + 动作打断 + 反问自嘲
3. **补人设专属表达**：语言指纹（职业/口头禅/句式习惯）+ 遮名测试
4. **一句话只说一遍**：留实指删空转，重复必删
5. **让情绪从语言里流出来**：删情绪名词，用语言内容/说话方式/微反应流露
6. **破坏完美回答**：回避/沉默/说一半/破坏对称
7. **拆信息倾倒**：拆散到多场景/行动化/对话化/只给必要

### 14.4 质检清单（对白交付前）
- [ ] 五问复核：同构/电报体/空转/人设/口语/重叠逐句过
- [ ] 模式库查漏：P02-P15 逐项扫全篇（重点 P15 话圆腔：有没有"不是X"补丁熨平冲突/顿悟式自我修正/话说得太圆？）
- [ ] 信息结构：信息无损 / 人设未漂移 / 一句一意 / 对话有功能 / 节奏匹配场景
- [ ] 朗读测试：大声读全篇对白，像人话吗？无"AI味残留"直觉？

### 14.5 使用边界
- 只改"怎么说"不改"说什么"：删修辞空转，不删剧情/伏笔/人设细节
- 人话优先于文采；对白服务角色，不服务作者
- 角色演讲/动员/祭文等正式场合排比合理，但须写清"在演讲"，且短、少、不常态化
- 剧本/口播等需金句感的体裁：口语问可放宽，空转问/重叠问仍遵守
- **独立段独白同样适用本专项句式检查**（思考也可以是AI腔）；词面豁免仍按语境三分类
- 发现新模式→追加进模式库，持续迭代（同本skill全链路规则更新流程）
