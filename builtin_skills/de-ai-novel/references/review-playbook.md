# 审查执行规范（双层扫描 + 段落分类触发条件总表）

> **溯源**：本节为审查执行规范正本（2026-09-11 定稿迁入）；节内编号（专项N / 9.x）为沿用的历史编号，与包内 C01-C27 的映射见 `narrative-craft.md` 末节。

> 定位：**从「规则」到「审查动作」的转换层**。核心机制＝按段落类型一次识别、全部规则同时执行。

## 十、审查执行规范（双层扫描+段落分类）——2026-08-12 沉淀

**教训**：第6-10章扫描用词面grep（忽然觉得/被/很X）修复了词面问题，但漏掉了"他父亲的名字。他父亲用过的机器"（内心独白段的第三人称转述）——**结构性/语义性问题无法用grep抓**（"他父亲"无信号词）。grep抓词面，抓不了结构；skill收录的规则如果没有转成"审查动作"，就不会在扫描时触发。

**双层扫描法（每批文本必做两层，缺一不可）**：
```
第一层·词面扫描：**①跑 `scripts/scan_hard_indicators.py <章节文件>`（包内 19 类正则：可扫C05论证/C06破折号/C07升华/C08解读/C10抽象感官/C12否定概括/C14夸大/C15宣传腔/C16模糊归因/C17谄媚腔/C18填充/C19同义循环——按输出命中片段逐个过语境三分类）** ②grep信号词（忽然+心理动词/**被**/不是而是/很X/有人/没停/至于/而连排/东西类喻体）——**"很X"用开放模式**：`很+[烈|晒|烫|刺眼|晃|亮|暗|热|冷|静|吵|轻|重|快|慢|稳|准]`（感官/程度形容词开放匹配）。**"被"字=专项8硬规则：grep `被[^子/动/单/褥/套]`（排除"被子/被动/被单/被褥/被套"等名词），命中后过语境三分类（引号内对话✓/独立段独白✓/正文✗必改——详见专项8三板斧）**。**"很X"=专项3硬规则：grep开放模式 `很[一-鿿]{1,2}`（含"很久/很深/很慢"等，脚本已内置 HEN_PATTERN），命中后过语境三分类（引号内对话✓/独立段独白✓/正文✗必改——给可观察细节/具体量度/质感喻体）**。**破折号=专项C06：脚本输出密度（处/千字）+双破折号插入（——X——）+上下文样例——正文密度≤3处/千字，超标即整章排查；语境判定：引号内对话"——"打断/结巴✓豁免（"你——你什么意思？"），正文"——"补充说明/解释✗必改（拆句或删），双破折号插入（——X——）必改**。**不设词面排除列表（词面白名单会漏网：曾把"很快/很好"误放行）——命中后做"语境三分类豁免"**：
```
① 引号内（对白）= 豁免（角色表达观察判断，人物塑造："你手很稳"）
② 独立段独白 = 豁免（角色自我评估："我的手很稳"）
③ 描写（其余）= 必改（叙述者贴标签/评分）
```
**内心独白必须独立成段**（一个自然段=一段思想流，不与动作/场景混段）——独白段特征：无引号、无动作叙述主语（无"他蹲下/主角看着"类）、内容为思考/感受/回忆；凭此与描写段区分（描写段有动作主语或场景物）。**该"独立段独白"识别标准与专项14"内心独白"场景共享（专项14管去主语/专项1管零转述/本机制管标签句式豁免——同一独白段，三规则协同；独白内"很X"须角色口吻，作者借独白塞标签仍违规）**。此语境三分类法同样适用于"是XX的/断定句/很X语境判定/属性判断/比较级结论（X比Y更Z）"等全部标签句式——豁免仅两种：对白（引号）+ 独白（独立段，且"比较级"在内心活动中仍优先展示具体反应）

**⚠ 独白识别补充判据（2026-08-22 沉淀）：独白段内出现"他/他的/他的名字"作"思考/感受/回忆主语"=不是独白，是叙述者转述**——"他想过很多次这个问题"（转述）→"想过很多次这个问题"（独白）；"他把选择权留给他"（转述，两个"他"）→"她把选择权留给我"（独白，第一人称）；"他要去的，是……"（转述）→"要去的是……"（独白）。**识别动作：判"独立段独白"时，除检查"无动作叙述主语"外，还要扫内容里的"他/他的"是否作思考主语**——是→退回专项1四步操作法改无主句/第一人称，不是（"他合上笔记本"动作主语）→保留。**此判据是"解说腔/转述腔"混入独白段的最大漏网口——"她把选择权留给他""他想过很多次"这类句子均因此漏过**。
第二层·语义审查：逐段读，先给段落分类，按类型跑对应专项
```

**矛盾检查结论（2026-08-13梳理）**：
1. **独白内"我的手很稳" vs 专项14去主语**——不矛盾，需澄清边界：独白内**"我"允许（第一人称自我评估），"他/他的"禁止（第三人称转述）**；"手很稳"（无主语）比"我的手很稳"更彻底，能省则省
2. **对话/独白的标签豁免 vs 描写必改**——一致：豁免仅两种语境（引号+独立段独白），且独白内豁免还受"角色口吻"约束；描写中一律必改
3. **9.14环境套话 vs 语境三分类③**——同规则两视角（"阳光很烈"=环境套话+很X），一致不矛盾，合并引用即可
4. **9.11作者判断 vs 专项12论证句式**——不同句式不同规则（"更麻烦"=9.11；"不是A而是B"=专项12），在概述段可同时执行

**每个专项的"审查动作"（skill→checklist）**：
- 专项1：逐段问"这段是内心独白吗？是→出现'他/他的/名字'任何一个=有叙述者在转述→删或改无主句"
- 专项8：词面grep"被"（排除被子/被动/被单/被褥/被套），命中→过语境三分类；正文命中=必改（三板斧：施动者主语/动作分解/生理反应）
- 专项9：每段对话问"称谓符合身份吗？话题有铺垫吗？双方共享背景有知情底和动机链吗？"
- 专项2：每个比喻过七问（含"删除损失测试"）
- 专项3：每个结论/评价/判断问"能换成动作/画面/细节吗？"
- 9.11：每个概述段问"是清单还是场景？有作者判断吗？结果是过程吗？"
- 9.12/9.13：被动检查（显性"被"字词面扫+隐形被动语义读）+时间线核对

**判定**：扫描结束问——**"词面层扫完，语义层读完了吗？"** 只扫了词面=只修了一半问题；结构性漏网（他父亲/主角翻了个身）必须靠语义层逐段分类捕获。

**修辞补偿心理（修复/改写时的高危动作）**：删掉一个华丽表述（结论/标签/金句）后，**不要补一个华丽的替代品**（比喻/排比/金句）来"增加文采"——这是"为比喻而比喻"的心理源头（删了"二级/练体育的/两个世界的人"→补"像一支笔挨着一根旗杆"）。规则：**删掉华丽表述后，接受朴素**——信息本身完整就直述，不补偿修辞。每个新添的比喻/修辞，过"比喻七问"（尤其第⑦问删除损失测试：删掉损失什么？零损失=装饰，删）。

**问题记录格式规范（对照表/导航器统一格式）**：
每个问题按"修改历程"记录，多轮修改按顺序罗列：

```
### 问题N ★等级（病根名）· 原第X行（第X章）
**原文：** > （第一版原句）
**第一轮：** > （第一次改写+为何仍不够）
**第二轮：** > （第二次改写+为何调整）
**终版：** > （最终版+为什么这个成立）
**判定：** （可复用的检查动作/信号词）
```

- 多轮标记词统一：第一轮/第二轮/终版/最终版（中途版本=已放弃的轮次，注明"为何放弃"）
- 单轮问题：原文 → 改写后（+说明）
- 导航器会自动提取轮次顺序渲染"原文vs改后"对比，多轮问题标"多轮"标签
