# 六轴判定框架（怎么判）＋ F 一致性轴（2026-09-05 新增）

> **来源**：轴定义与判定流水线沿用「五轴分类（2026-09-04 定）」，本包 F 轴为其扩展（2026-09-05 参照，来源侧未改动）。
> **本包改动**：v2 定为五轴（A/B/C/D/E），F 为「候选第六轴」由 v2 建议单列——**本包采纳为正式第六轴**，并补 F1 章内局部层（v2 只给了 F 的定义与归属，无判据）。
> **定位**：六轴是**判定维度**（怎么判），四层（风格/前置卡/识别/主线）是**规则存放位置**（规则放哪）。两者正交，可同时持有——同一条规则可以属于风格层、却按 B 轴判。

## 一、六轴定义（v2 原文，仅 F 为本包扩写）

| 轴 | 名称 | 判什么 | 孤立/越界 = AI 的判据 | 本包落点 |
|---|---|---|---|---|
| **A** | 承接轴 | 标签/结果动词/否定句之后，有没有动作、对白或可观察证据自证 | **孤立即 AI**（只下结论无承接） | 九类第2条（否定式无画面）、C12、风格层特征20-⑧族 |
| **B** | 契约轴 | 文体契约（说书体全知 / 现代内视角 / 说明体）决定同一表达是否合法 | **错配即 AI**（说书体里合法、现代内视角里越界） | 语域分层（R13 提案）、文体豁免（R9 提案） |
| **C** | 所指轴 | 解说/推断/归因**有没有所指**（依据/口吻/意图/信源/对象） | **空所指即 AI** | C16 模糊归因、C08 解读补白抢答、"仿佛"词位分判 |
| **D** | 角色化轴 | 收束/哲理/断言归**角色**（人物之口/内心引语）还是归**叙述者** | **叙述者越位即 AI** | C11 视角越位、**C23 叙述者收束**、语境豁免三分类第2条 |
| **E** | 规整与密度轴 | 句式规整度（生造平行结构/陈词框架）＋ 密度超章型基准 ＋ 统计信号 | **过规整/过密即 AI** | 统计信号三指标、C04 三段式排比、**C22 生造"不X不Y"** |
| **F** | 一致性轴（**本包新增**） | 长程与局部自洽（时间线/计数/呼应/来源/铺垫/状态） | **不自洽即 AI**；非风格层 | 本文件第二节（F1 章内）；主线层管 F2 跨章 |

**轴间依赖顺序（判定流水线，v2 原文）**：

```
B 契约定盘 → D 谁在说 / C 说什么 → A 怎么接 → E 量化佐证 → F 一致性（独立于风格层，最后单独过）
```

**为什么必须按这个顺序**：B 不定，后面全在错语域上判（把评书过门词当 AI 味）；A 在 C/D 之后，因为"承接什么"取决于"说的是什么、谁在说"；**F 放最后单独过**，因为一致性问题不属于"文风好不好"，改文风改不掉，且改风格时最容易顺手破坏一致性。

> **此前缺口**：主线层三张表只管 F2 跨章长程，**F1 章内局部根本没地方放**。这是章内问题长期漏判的结构性原因。

### F1-1 相邻重复（可脚本化 · 优先级最高）

- **判据**：同一连续字符串（≥8 字）或同一"主语+谓词"结构，在相邻 2–5 段内重复出现，且**中间无解释性变奏**。
- **正则/做法**：对去标点正文做滑窗，取长度 ≥8 的重复子串，检查其两次出现的位置间隔是否 ≤5 段。
- **反例**：`推门进来，带进一股风，门帘晃了一下，又落回去。推门进来，把伞靠在门边。` —— 相邻两句主谓完全重复，属笔误，必改。
- **正例（豁免）**：对白回环、有意复沓、母题递进。《我不是文豪》"子弹正中眉心"用两次（L165 马尔克斯的子弹 / L286 他自己的子弹），**是有意互文，判亮点不判违规**——差异必须先被看见（句式有别、所指不同），否则降为边缘。
- **判定纪律**：重复 + 无变奏 + 无意图标记 → 违规；重复 + 有递进/有互文对象 → 豁免。

### F1-2 数量 / 属性矛盾（可脚本化）

- **判据**：同一对象在同一章内，前后给出的**数量、颜色、尺寸、材质、方位**不一致，且中间无修复/更换/损耗动作。
- **做法**：抽取"数字+量词"与"属性形容词"与最邻近的名词/对象，建章内对象属性表，冲突即报。
- **反例**：`票面上的字洇了，勉强认出一个"巷"字的半边` → `半张票，三个字`。数量没有着落，中间无换票动作。
- **正例（豁免）**：中间有物理动作改变它（撕掉一半、雨水泡花、换了新的）。
- **判定纪律**：先查**中间有没有改变该属性的动作**；有 → 豁免，无 → 违规。

### F1-3 实体无铺垫登场（人工判为主，脚本可半自动）

- **判据**：具名实体（人名/地名/物件名）**首次出现**时即被当作读者已知，不带任何引入标记。
- **引入标记**（有任一即合规）：不定量词（一个/一张/有个）、感官引入（看见/摸到/闻到）、动作引入（掏出/翻开/推门进来）、同位说明（"XX，人称YY"）。
- **反例**：直接 `翻到"旧仓库"那一页`——本子当天第一次从柜里取出，前文只交代翻过首页与末页，读者无从知道有这一页。
- **反例**（笑傲AI）：岳灵珊凭空出现在破庙，无到场动作。
- **正例（豁免）**：该实体在**前文已出现过**（非首次）、或说话人本就认识（对白里直呼其名合规）。
- **判定纪律**：先确认是不是**首次出现**；二次出现不带引入标记是自然语言，不违规。

### F1-4 时序 / 因果倒错（人工判）

- **判据**：被引用的内容（台词、事件、知识）在文本中**出现的时间点晚于引用它的位置**，且未标倒叙。
- **反例**（笑傲AI L137）：刘正风引用"站着打天下第八十九，坐着打天下第二"，但该台词是令狐冲在回雁楼说的，文本到 L144 才由仪琳转述；而 L139 明确写着仪琳此时才"原原本本讲了出来"。
- **正例（豁免）**：明示倒叙（"后来他才知道……"）、或引用者是当事人（他本就知道，不需要文本先出现）。
- **判定纪律**：区分**叙述时序**与**故事时序**；只有当引用者不可能知道（非当事人、文本未交代）才违规。

### F1-5 章内状态矛盾 / 视角越界（人工判 + 脚本半自动）

- **判据**：同一场景的同一物理状态量前后冲突（光/门/人数/位置/声音）；或写出主角**不在场或看不见**的内容。
- **反例**：`灯全关着` ↔ `透出一点微光`，中间无开灯动作。
- **反例**：视角越界，写了主角不在场发生的事。
- **正例（豁免）**：中间有状态改变动作；或后句是**推测/传闻**且带标记（"听说""像是"需按 C 轴判所指）。
- **判定纪律**：状态矛盾与视角越界常**并发**（写了看不见的 → 状态自然对不上），改一处即解两处。

## 三、执行顺序（接进标准执行流程）

标准执行流程第 4 步（逐条判定）内部，按六轴过一遍；第 5 步（主线核查）之后**新增 F1 章内过一遍**：

1. **B 契约定盘**：先判这一稿的文体契约（说书体 / 现代内视角 / 说明体 / 反讽内心型），写下它，后面所有判定不许脱离契约。
2. **D → C**：谁在说（叙述者还是角色）→ 说什么（有没有所指）。
3. **A**：标签/否定句后有没有承接。
4. **E**：规整度与密度 + 统计信号（只作佐证）。
5. **F1 章内局部**：F1-1 相邻重复 → F1-2 数量属性 → F1-3 实体铺垫 → F1-4 时序 → F1-5 状态与视角。
6. **F2 跨章长程**：交回 `mainline-tables.md` 三张表。

**输出要求**：判定表（detection-rules.md 第五节）的"命中项"列，凡 F 轴命中须标 `F1-x`，不得混进风格类目——F 轴是硬伤，优先级高于任何文风问题。

## 四、与既有规则的关系

- **不替代四层**：六轴是判法，四层是规则库。一条规则可以住在风格层、按 A 轴判。
- **不新增拦截计数**：F 轴命中**人工判定**为准；F1 命中的发现与计数不进 block/warn，避免与机器命中混淆。
- **与 C13 的分界**：C13「结构失真」管**叙事事件顺序**（三明治对白、先结果后原因，属风格层）；F1-4 管**引用内容在文本中的出现时序**（属一致性层，非风格）。同上写法，C13 看"顺不顺"，F1-4 看"能不能"。
