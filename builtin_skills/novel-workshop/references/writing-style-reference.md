## 一、经典范例全文标注

### 范例段一：氛围建立 + 冲突入场

```
①一道闪电裂空而过②，黑暗中，这座在风中孤独伫立的小草庙③亮了一下，
只见那老僧在这片刻间已站在了庙门口④，一脸严肃⑤，双眉越皱越紧⑥。

西边村子中，不知何时⑦已起了一股黑气，浓如黑墨，翻涌不止⑧。
老僧站在草庙之中，死死盯着这股黑气⑨。

忽然，那股黑气一卷，盘旋而起⑩，径直便往村外而去，正向着草庙方向而来。
它速度极快，转眼即至⑪。老僧眼尖，一眼便看见其中竟夹带着一个小孩，
正是白天见过的林惊羽⑫。

老僧脸色一沉，再不迟疑⑬，也不见他如何作势⑭，枯瘦身子霍地拔地而起⑮，
直插入黑气之中。

黑暗中不知名处，传来了一声微带讶异的声音:"咦?"⑯

几声闷响⑰，黑气霍然止住，在草庙上空盘旋不去。老僧肋下夹着林惊羽，
缓缓落下，但身后袈裟已被撕去了一块⑱。

借着微弱光线，只见林惊羽双目紧闭，呼吸平稳，也不知是睡了还是晕了过去。

---普智上前一步---⑲

"阁下道法高深，为何对无知孩童下手，只怕失了身份吧?"⑳
"你又是谁，敢管我的闲事?"㉑
"此处乃青云山下，若为青云门知道阁下在此地胡作非为，只怕阁下日后就不好过了。"㉒
"青云门算什么，就仗着人多而已。老秃驴莫要多说，识相的就快快把那小孩给我。"㉓
"阿弥陀佛，出家人慈悲为怀，老衲断不能眼睁睁看着这小孩遭你毒手。"㉔
"好贼秃，你是找死。"㉕
```

### 段一技法标注

| 标注 | 技法 | 说明 |
|------|------|------|
| ① | 动词选最重 | "裂"比"闪"重十倍，破坏感和暴力美学 |
| ② | 氛围先于人物 | 在人物出现前用意象堆出气氛 |
| ③ | 意象叠加 | 黑暗+风中+孤独+伫立=四重压抑 |
| ④ | 动作即修为 | 不说"他很快"，用"已站在"展示 |
| ⑤ | Show不Tell | 不下结论"他很担心"，用"严肃"呈现 |
| ⑥ | 情绪通过细节 | "双眉越皱越紧"=忧虑但不慌乱 |
| ⑦ | 制造紧张 | "不知何时"暗示敌人已逼近但未察觉 |
| ⑧ | 四字短句控节奏 | "浓如黑墨""翻涌不止"突然加速 |
| ⑨ | 动作替代心理 | "死死盯着"比"他很戒备"有力十倍 |
| ⑩ | 短促动作 | "一卷，盘旋而起"番茄式快节奏 |
| ⑪ | 省略中间过程 | 7字完成接近过程，不写"它飞过了...又绕过了..." |
| ⑫ | 第三人称视角 | 通过老僧的视线引入信息，不跳出视角 |
| ⑬ | 果断不磨叽 | "脸色一沉，再不迟疑"=人物性格在动作中 |
| ⑭ | 省字法写高手 | "也不见他如何作势"说明修为不需蓄力 |
| ⑮ | 反差塑造人物 | "枯瘦"VS"拔地而起"=看似弱实则强 |
| ⑯ | 语气词做最大伏笔 | "咦?"三个字暗示背后还有主使 |
| ⑰ | 战斗压缩 | "几声闷响"覆盖整个战斗过程，高潮留白 |
| ⑱ | 信息叠层 | "袈裟已被撕去"=战斗结束+对手不弱+老僧没赢 |
| ⑲ | 过渡自然 | 对话前不需要"他说""他道"，动作直接衔接 |
| ⑳ | 对话有礼貌有距离 | "阁下"体现老僧身份和修养 |
| ㉑ | 反派不废话 | 直接反问，体现性格 |
| ㉒ | 对话含信息 | 亮出"青云山"背景+搬靠山+试探对方 |
| ㉓ | 反派有底气 | "青云门算什么"暗示反派来头不小 |
| ㉔ | 立场坚定 | 表明动机和决心，不拖泥带水 |
| ㉕ | 冲突升级 | 每轮对话升高一级：试探→对峙→威胁→骂战 |

### 范例段二：多阶段战斗 + 三层叙事

```
①随着他的话语，原来一直盘旋的黑气中，一道深红异芒在其中闪了一闪，
刹那间这小小草庙周围，阴风大作，鬼气大盛。②

"毒血幡!"③老僧脸上突现怒容，"孽障，你竟然敢修炼此等丧尽天良、
祸害人间的邪物，今日绝饶不了你!"④

那沙哑声音一声冷笑，却不答话⑤，只听一声呼啸，红芒大盛，从半空之中，
腥臭之气大作⑥，一面两丈红幡缓缓祭起。这时，鬼哭之声越发凄厉，
似有无数怨灵夜哭，其间还隐隐有骨骼作响声，令人毛骨悚然⑦。

"贼秃，受死!"那黑气中人一声断喝，只见从那血色红幡之上，突现狰狞鬼脸，
有三角四眼、尖齿獠牙，"咔咔咔咔"骨骼乱响处⑧，鬼脸上的四只眼睛突然
全部睁开，"吼"的一声，竟化为实体，从幡上冲出，带着无比血腥之气，
击向老僧。

---第一回合：法轮 VS 鬼物---

老僧脸上怒色更重，知道这毒血幡威力越大，修炼过程中害死的无辜之人越多。
要炼成眼前这般威势，只怕要以三百人以上的精血祭幡方才可以。⑨
这邪人实在是丧尽天良!

眼看那鬼物就要冲到眼前，老僧却并不放下肋下小孩林惊羽，只用持着
碧玉念珠的左手在身前虚空画圆，单手结佛门狮子印，五指屈起，指尖隐隐
发出金光，片刻间已在身前唤出一面金色法轮，金光闪闪，与那鬼物抵持
在半空中。⑩

"小小伎俩，也来卖......"⑪

---第二回合：七尾蜈蚣偷袭，战局逆转---

那老僧一个"弄"字还未说完，突然全身大震，只觉得抱着林惊羽的右手
手腕被异物咬了一口，一股麻痒感立时行遍半身，眼前一黑，身前法轮
登时摇摇欲坠。⑫

就在此时，前方那个鬼物又有诡异变化，在它左右四眼正中额头上，
"咔咔"两声，竟又开了一只血红巨目，腥风大起，威势更重，只听一声
鬼嚎，血色红光闪过，那鬼物将金色法轮击得粉碎，重重地打在老僧的
胸口上。⑬

老僧整个人被打得向后飞了起来，途中几声闷响，怕是肋骨已尽数断了，
肋下的林惊羽也掉在地上。片刻之后，他枯瘦的身子砸在草庙壁上，
"轰"的一声，尘土飞扬，一整面墙都塌了下来。⑭

"哈哈哈哈......"黑气中人一阵狂笑，得意无比。⑮

老僧颤巍巍地站起，喉咙一热，忍不住一口热血喷了出来，把身前僧衣都
染红了，甚至连手上念珠珠串都溅到了血迹。一时之间，他只觉得眼前金星
乱闪，全身剧痛，那股麻痒感觉也越来越逼近心脏。⑯

他强自镇定心神⑰，眼角扫过倒在地上兀自昏迷的林惊羽，却见在他衣襟之中，
缓缓爬出只分叉彩色蜈蚣，个大如掌，最奇异的是它尾部分了七叉，看去仿佛
有七条尾巴似的。而且每只分叉各呈一色，各不相同，色彩绚丽，只是美丽中
却带了几分可怖。⑱

"七尾蜈蚣!"老僧呐呐说了一句，语调中带了几分痛苦之意。⑲

---信息揭示：反派有计划，目标是老僧---

他脸上黑气越来越重⑳，嘴角也不断流出血来，似乎已是难以支撑，但仍然
强撑着不愿倒下。他看着半空中那团黑气，道:"你将这天下奇毒之物放在
那孩子身上，又故意隐藏实力，看准机会一击伤我。你是冲着我来的吧?"㉑

黑气中人"嘿嘿"冷笑一声，道:"不错，我便是专门冲着你普智秃驴来的。
若非如此，凭你一身天音寺佛门修行，倒也不好对付。好了，现在快快把
'噬血珠'交出来，我便给你七尾蜈蚣的解药，饶你不死!"㉒

普智惨笑一声，道:"枉我名中还有一个智字，竟想不到你炼这毒血幡邪物，
岂有不贪图噬血珠的道理。"他脸色一肃，断然道，"要我将这世间至凶之物
给你，却是妄想。"㉓

那黑气中人大怒:"那你便去见你的佛祖吧。"红芒一闪，毒血幡迎风招摇，
鬼哭声声，巨大鬼物再现，在空中微一盘旋，再次冲向普智。

---第三回合：六字大明咒，绝地反击---

普智手掌一翻，将那深紫珠子一把抓在手中，藏在怀里，双手随即结左右
水瓶印，两目圆睁，全身上下隐有金光，口中一字一字念道:
"吨嘛呢呗咪叫!"㉔

"六字大明咒。"黑气中人的口气立时多了几分凝重。㉕

随着普智"叫"字声落，刹那间所有碧玉念珠一起大放光芒，同一时刻，
那邪人祭起的鬼物已冲到跟前，血腥之气扑面而来。但一接触到碧玉青光，
顿时化为无形，不能近前，就此僵持在半空中。

饶是如此，普智的身子又是一阵摇晃，七尾蜈蚣是天下绝毒之物，纵然他
道行深厚，仍然难以抵挡。只是他隐泛黑气的脸上，却露出一丝淡淡笑容，
带了几分凛然。㉖

"呔!"㉗
普智一声大喝，如作狮子吼，声震四野，身前碧玉念珠受佛力驱驰，光芒
更盛，忽地一颗念珠"噗"的一声碎裂，在半空中幻作一个"佛"字，疾冲
向前，打在那鬼物脸上。

"哇......呀!"那鬼物一声凄厉号叫，登时退了几步，周身红芒大为衰退，
显然已受了伤。黑气中人怒道:"好你个秃驴!"

他正要动作，只是为时已晚。说时迟那时快，片刻间七八颗念珠都幻作
佛家真言打中鬼物。那鬼物号叫不止，连连退避，做恐惧状，在被第九颗
碧玉念珠击中时，终于一声长嚎，五目齐齐迸裂，骨骼乱响，轰然一声
跌落在地，挣扎了几下，便僵直不动了，缓缓化作血水，腥臭无比。㉘
```

## 二、31 条写作铁律

### 氛围与描写

1. **环境先于人物出场**——在人物出现之前，先用2-3个意象堆出气氛。
   ✅ "一道闪电裂空而过，黑暗中，小草庙在风中孤独伫立"
   ❌ "这是一个风雨交加的夜晚"

2. **动词选最重的一个**——"裂"＞"闪"，"砸"＞"撞"，"攥"＞"握"。
   ✅ "闪电裂空而过"
   ❌ "天空闪过一道闪电"

3. **用动作展示情绪，不下结论**——不下结论"他很愤怒/担心/害怕"。
   ✅ "双眉越皱越紧""指节泛白""死死盯着"
   ❌ "他非常担心"

### 节奏与压缩

4. **战斗压缩——只写结果和关键帧**——战斗中的招式过程不要写，只写开始和结果。
   ✅ "几声闷响，黑气霍然止住"
   ❌ "他先出左掌，继而横扫一腿，再变掌为爪，向对手面门抓去"

5. **战斗分三阶段，每阶段反转一次**——占优→被阴/逆转→绝地反击。
   ✅ 法轮占优→七尾蜈蚣偷袭→六字大明咒绝地反击
   ❌ 一直压着打直到胜利

6. **省略过渡，直接跳接**——不要写"他走啊走，终于到了"。
   ✅ "它速度极快，转眼即至"
   ❌ "它穿过了西边的树林，飞过了村口的小河，绕过了一座土坡，来到了草庙前"

### 信息释放

7. **信息叠层——一句话递3层信息**——让每一句话同时完成推进剧情、塑造人物、制造情绪。
   ✅ "袈裟已被撕去了一块"(战斗结束+对手强+老僧没赢)
   ❌ "他和对手打了一架，谁也没胜过谁"

8. **设定通过冲突带出**——世界观信息不在旁白中说明，放在战斗/对话中揭示。
   ✅ 老僧心中算"三百人精血祭幡"带出毒血幡的邪恶
   ❌ "毒血幡是一件非常邪恶的法宝，需要很多人的精血来炼制"

9. **名称在关键时刻给出**——不要让角色一开始就报名字，在读者最想知道时再揭晓。
   ✅ "普智"在2000字后才出现
   ❌ "普智上前一步，说道……"(开场就报名字)

### 人物塑造

10. **高手不需要心理描写**——用6个字代替300字内心戏。
    ✅ "他强自镇定心神"
    ❌ "他心中十分慌乱，不知道接下来该怎么办，但他还是努力让自己冷静下来……"

11. **动作即性格**——一个人物是什么性格，通过他怎么做来展示。
    ✅ "他对小孩不管不顾，双眼死死盯着黑气"(慈悲但冷静)
    ❌ "他是一个慈悲但冷静的高僧"

12. **反派必须有智商**——反派设局、隐藏实力、有人质，主角赢了才有含金量。
    ✅ 把七尾蜈蚣藏在小孩身上，示弱后偷袭
    ❌ 反派只会大喊"我要杀了你"然后被反杀

### 感官与画面

13. **第一次登场的法宝/技能用3+种感官描绘**——视觉+听觉+嗅觉+触觉同步输出。
    ✅ 毒血幡出场=深红异芒(视)+鬼哭(听)+腥臭(嗅)+阴风(触)
    ❌ "他祭起了毒血幡，这是一件邪物"

14. **拟声词增强画面**——"咔咔咔咔""轰""噗"让读者听到场景。
    ✅ "咔咔咔咔，骨骼乱响"
    ❌ "骨骼发出响声"

15. **脆弱的胜利比完美胜利有张力**——赢了但不是全赢；赢了但代价巨大。
    ✅ 击杀了鬼物但七尾蜈蚣的毒已入心脏
    ❌ 完美反杀，毫发无伤

### 对话与叙事

16. **对话同时干4件事**——每一轮对话都要承担身份展现+背景交代+冲突推进+情绪制造。
    ✅ "此处乃青云山下……"(身份+背景+威胁+试探)
    ❌ "你叫什么名字？""我叫张三。"

17. **对话不写过渡词**——用动作替代"他说""她道"。
    ✅ "老僧双手合十道:'阿弥陀佛……'"(动作在前)
    ❌ "老僧说道:'阿弥陀佛……'"

18. **三层叙事并行**——一场战斗同时推进战斗线+信息线+情绪线。
    ✅ 表层(战斗进程)+中层(世界观信息)+深层(读者情绪)
    ❌ 只写战斗过程

### 跨章构建与信息纵深

19. **分布式信息释放**——同类信息的多种示例，按"首章≤3个+后续分批补充+callback回响"的节奏分配，禁止一章内堆砌全部例子。
    ✅ 第4章散修职业举例留保安/网约车/敲代码3个，"养生茶老哥"挪到第6章黑市初探callback复用
    ❌ "散修干什么的都有——当保安的、开网约车的、敲代码的、卖养生茶的、送外卖的、开锁的、修空调的……"一锅端

20. **人物招牌动作即时兑现**——人物设定卡中的"习惯动作"，必须在角色首次经历对应触发情绪时立刻使用，不要等到中后期才用。
    ✅ <角色乙>人物卡"紧张→转古玉戒"，第4章首次紧张认亲时刻即兑现
    ❌ 人物卡列了三个招牌动作，正文前20章一个没用，角色始终"脸盲"

21. **跨章感官锚点**——同一核心概念（同一个人/同一件物品/同一段关系）在不同章节出场时，锁定同一个感官维度（温度/触感/声响/气味）建立隐蔽的跨章呼应。
    ✅ 第1章<标志物甲>"温热渗出，回应了他一下"→ 第4章<标志物乙>"微微发烫，轻轻应了他一下"（同为师父道心碎片，温度+触觉维度锁定）
    ❌ 每次出场换不同的感官比喻，读者感受不到隐藏的跨章连接

### 语言精简与叙事效率

22. **形容到位，不加比喻叠层**——好形容单枪匹马就够。形容词已经画出画面，不要再叠一个比喻去解释，等于告诉读者"我怕你想象力不够"。
    ✅ "白底红字的招牌，歪歪扭扭的写着——'天衍风水馆'"（"歪歪扭扭"已画出画面）
    ❌ "歪歪扭扭，像是有人喝高了拿毛笔写的——'天衍风水馆'"（叠了比喻，画蛇添足）

23. **对话不帮角色解释已知关系**——角色之间的对话，不要让A向B解释B自己已经知道的事。读者通过侧面信息自行拼图，比直接告知更有参与感。
    ✅ <角色甲>对<角色乙>："你爹告诉你，那只是一只残疾蛤蟆"（<角色乙>知道她爹是谁，不用解释），后文"掌门在我渡劫前一晚……"侧面带出"爹=掌门"
    ❌ "后来掌门——也就是你爹——告诉你"（<角色乙>不知道她爹是掌门？这是说给读者听的）

24. **动作即转场，不报幕不编号**——对话段落不写"说了两句话。第一句：……第二句：……"，也不反复用"他说道/她又说"报幕。用动作+直接引语无缝衔接。
   ✅ 他往前探了探身子："……" <角色乙>的手开始抖。<角色甲>接着说："……"（动作+直接引语，不编号不报幕）
   ❌ 他往前探了探身子，说了两句话。第一句："……" 第二句："……"（剧本格式，打断叙事流）

### 冗余剔除与视角一致性

25. **同义信息合并不拆句**——一个意思不用两个近义短语反复说。感知类描述（情绪、氛围、体感）合并成一句，不做同义词展开。
   ✅ "一个声音在脑子里响起来，毫无情绪起伏"（13字，感知源+单一结论）
   ❌ "一个声音响起来了。不是耳朵听见的，是直接刺进脑子里的，没有抑扬顿挫，没有情绪的起伏"（33字，"没有抑扬顿挫"和"没有情绪的起伏"说的是同一件事，拆成三句展开=灌水）

26. **留白让标点完成，不补叙述旁注**——破折号断句=角色自己咽回去了、省略号=角色说不下去、引号内的空白=沉默。标点已经完成了动作，叙述员不需要跟在后面解说"后半句咽了回去""话没说完""他沉默了一会儿"。
   ✅ 赵姐眨了眨眼："你师兄？你不是说你师兄——"（破折号自己完成了"咽回去"，不需要旁注）
   ❌ 赵姐眨了眨眼："你师兄？你不是说你师兄——"后半句咽了回去。（"后半句咽了回去"是叙述员在补刀——读者已经看出破折号=咽回去了）

27. **POV内心独白用角色语言，不用作者标签**——第一人称/限第三人称的内心独白中，时间和空间的指称必须来自角色记忆库，不能使用"序章""前文""章节"等元叙事词汇或作者视角的外部标签。
   ✅ "他认识这种感觉。那是，前世渡劫的时候，隔着雷劫阵扫下来的神识。"（"前世渡劫"=角色记忆库中的词汇）
   ❌ "他认识这种感觉。不是第一次。序章的时候，隔着雷网渗过来的那种冷，和现在，是一样的。"（"序章"=作者/大纲视角的词汇，角色不会知道自己活在"序章"里）

### 一次展示，不二次解释

28. **已展示的设定不再二次解释**——通过动作/感官/对话已经展示过的设定信息（能力升级、人物关系、物品归属），不要在后续段落中用比喻、对比或说明句再复述一遍。信任读者已经看到了。
   ✅ ③"耳朵竟然捕捉到前面路口大爷在打电话"（展示听觉增强）→ ④不追补"不是普通的动静——练气四层的灵识像一根被拨动的琴弦，嗡嗡颤了一下"
   ❌ 前面已展示完毕 → 后面跟"练气四层的灵识像被拨动的琴弦"（把读者已经接收的信息又解释了一次）
   ❌ "他翻出脑子里前世残留的一卷古籍记忆，把白天记下的那串坐标摊开来比对。对了。那阵法叫聚灵引天阵" → 读完"对了"读者已经知道那串坐标是什么了 → 后面"那阵法叫聚灵引天阵"又来了一遍

29. **去量化比较——用「竟然」「就」替代测量数据**——不写"比之前细了一倍""隔着二十米每个字都清清楚楚"这类数字化比较。"竟然"或"就"一个字能传达的变化/意外体感，不需要拆成测量报表打断叙事流。
   ✅ "耳朵竟然捕捉到前面路口等红灯的大爷在跟人打电话"
   ❌ "耳朵捕捉到的声音比之前细了一倍——前面路口等红灯的大爷在跟人打电话，隔着二十米，每个字都清清楚楚"

30. **开篇不过渡——缩短从场景到场景的距离**——不写"和XX说的一样""不出所料""正如他想的那样""果然如何如何"这类照应性铺陈。直接从时间+角色位置开始上舞台。
   ✅ "早上。<角色甲>刚回到<场景甲>。"
   ❌ "早上的<场景甲>和<配角乙>说的一样——刚上班就有活儿。不是散件，是站长直接喊的。"（铺垫了"和<配角乙>说的一样""不是散件，是站长喊的"两个信息，但没有一个比"<配角乙>手里捏着一张单子"更直接地推进叙事）

### 设定迁移防流失

31. **每章绑定设定锚点三重检查**——正文生成后，必须逐条核对本章的"人物锚点兑现""伏笔进度偏离""沉默设定阈值"三项，防止人物卡设定、伏笔线、标志物在连续章节推进中自然遗忘。
   ✅ 生成第6章后检查 → <角色甲>掐诀：已兑现 / <标志物甲>：沉默5章触发阈值→补一笔 / <配角甲>：沉默4章触发阈值→安排出场
   ❌ 连续生成3章后从未回头检查"人物卡的习惯动作写了没有""次要伏笔已经多久没提了"，导致设定向正文迁移流失率持续上升

## 三、常见写作病句对照表

| 错误写法(AI味) | 诛仙式写法 | 改进要点 |
|---------------|-----------|---------|
| "他非常愤怒" | "他攥紧拳头，指甲掐进掌心，指节泛白" | 动作替代情绪 |
| "天色很暗，风很大" | "一道闪电裂空而过，草庙在风中孤独伫立" | 意象+动词+拟人 |
| "他修为很高" | "也不见他如何作势，枯瘦身子霍地拔地而起" | 用动作展示修为 |
| "这是一件邪恶的法宝" | "阴风大作，鬼气大盛，腥臭之气扑面而来" | 感官描写替代说明 |
| "他准备使用一个强大的法术" | "他双手结印，一字一字念道:吨嘛呢呗咪叫" | 用动作和口诀展示 |
| "他非常震惊" | "他脸上突现怒容" / "他脸色一沉" | 面部细节替代心理 |
| "他和对手激烈地战斗" | "几声闷响，黑气霍然止住" | 只写结果，压缩过程 |
| "这是一个风雨交加的夜晚" | "一道闪电裂空而过，在风中孤独伫立的小草庙亮了一下" | 从"说明"到"体验" |
| "他想，我一定要坚持住" | "他强自镇定心神" | 6字替代300字 |
| "反派说:我要杀了你" | 反派设局，藏毒，示弱，偷袭 | 行动替代口号 |
| "一道磅礴的剑气横扫而出" | "剑起。寒光一闪。" | 短句爆炸力 |
| "他缓缓地、慢慢地走了过去" | "他走过去。脚步很轻。" | 副词冗余→拆句+动作 |
| "此时此刻，他的心情非常复杂" | "他没说话。烟烧到了手指，也没弹。" | 情绪外化=物件+沉默 |
| "整个场面十分混乱" | "桌子翻了。有人踩在碎碗上，骂了一声。" | 大场面=具体碎片 |

### 病句类型速查（按场景分类）

```
【情绪描写类】
  ❌ "他很愤怒/担心/害怕/震惊"
  → 修复：找一个身体反应（手抖/咬唇/瞳孔收缩/呼吸变快），写出来
  → 极简版：面部细节（"脸上突现怒容""脸色一沉"）

【过渡衔接类】
  ❌ "然后…接着…于是…过了几天…与此同时…"
  → 修复：用空行直接跳接；用动作承接（"他推开门。"=场景切换完成）
  → 极简版：省略过渡词，章节内用分段自然切换

【战斗描写类】
  ❌ 逐招拆解（"他先出左掌，继而横扫一腿，再变掌为爪…"）
  → 修复：只写关键帧——起手式 + 逆转瞬间 + 结束状态
  → 极简版："几声闷响，黑气霍然止住"

【设定说明类】
  ❌ 旁白解释设定（"毒血幡是一件非常邪恶的法宝，需要精血炼制…"）
  → 修复：通过角色内心反应或感官体验带出设定
  → 极简版：老僧心中算"三百人精血祭幡"→读者自己推出结论

【对话标注类】
  ❌ "他厉声道""她温柔地说""他愤怒地吼道"
  → 修复：只用"说"／或动作替代标注（"她低下头。'我知道了。'"）
  → 铁律：禁用"X地""X道"式花式标注

【形容词堆叠类】
  ❌ 一个名词前超过一个形容词（"那柄古老的、锈迹斑斑的、寒气逼人的长剑"）
  → 修复：选最精准的一个形容词；其余通过动作/细节分散释放
  → 极简版："那柄剑。锈到了护手。"

【心理活动类】
  ❌ 大段内心独白（"他想…他觉得…他回忆起…他决定…"）
  → 修复：高手无心理——用6字替代300字（"他强自镇定心神"）
  → 例外：Sequel段的反应/困境可以展开心理（但控制在2-3句内）
```

### 4.2 按场景类型·平台差异（从谢晚路由表抽取）

```
战斗场景：

  番茄 → Scene-Sequel三阶段·战斗压缩·装逼打脸如适用
  起点 → Scene-Sequel完整·环境功能五(战斗资源)·三阶段反转·脆弱胜利

对话场景：
  飞芦 → 对话60%+·极短句·反转·跳过三维错位
  番茄 → 对话50%+·情绪驱动·三维错位如适用
  起点 → 对话40%+·信息量驱动·三维错位优先

环境描写：
  飞芦 → 仅造氛围1项·一句话点出·跳过五感细节
  番茄 → 造氛围+反映心理2项·至多2种感官
  起点 → 七功能全路径·2-3种感官详细描写

装逼打脸：
  飞芦 → 压缩版(铺垫1句→触发≤30字→反应≥2人→余波1句)

  起点 → 完整版(四步链+爽点类型学→反应≥3人+权威人物定调)

双视角：
  飞芦 → 时间错位型(要反转不要深度)·跳过三维错位
  番茄 → 认知反差型(要情绪冲击)·三维错位如适用
  起点 → 信息互补型(要信息纵深)·三维错位优先
```

### 4.3 平台错配诊断

```
症状                      │ 可能原因                │ 修复方向
──────────────────────────┼───────────────────────┼───────────
飞芦文被读者说"太慢"        │ 环境描写>1项/章/爽点密度低 │ 压缩环境→1句话·提高爽点→每1500字
番茄文被读者说"看不懂"      │ 设定密度过高/暗线过多      │ 降低设定曝光→L1+L2≤15%·暗线≤1条/10章
起点文被读者说"太小白"      │ 战斗无Scene-Sequel/反派无智商│ 补全Scene→Sequel·反派增加独立计划线
```

## 五、正文生成质检附加项：StyleCheck

在「正文质检卡」的自查中增加第6项：

### 6. 风格检查（StyleCheck）

参考本文件中的31条写作铁律，逐条核查本章正文：

**氛围与描写**
- □ 动词是否有力度？（"裂"＞"闪"，"攥"＞"握"）
- □ 情绪是否通过动作展示而非直接下结论？

**节奏与压缩**
- □ 战斗场景是否只写了结果而非过程？
- □ 是否有过度过渡（"他走啊走""过了几天"）需要删除？

**信息释放**
- □ 是否有一句话叠了2-3层信息？
- □ 设定是否通过冲突带出而非旁白说明？

**人物塑造**
- □ 是否有"他很XXX"类的空洞心理描写？(有则替换)
- □ 反派是否有智商和策略？

**感官与画面**
- □ 关键场景是否使用了至少2种感官？
- □ 胜利是否付出了合理代价？

**跨章构建与信息纵深**
- □ 同类信息列举是否≤3个？（超出则标记，建议分布式释放）
- □ 人物卡招牌动作是否在首次触发情绪时已兑现？
- □ 核心概念跨章出场时，是否锁定同一感官维度建立隐蔽呼应？

**语言精简与叙事效率**
- □ 形容词后是否叠了比喻去"再解释一遍"？（如"歪歪扭扭，像是喝高了写的"→"歪歪扭扭"就够了）
- □ 对话中是否让角色向对方解释对方已经知道的事？（如"掌门——也就是你爹"）
- □ 对话是否用了"第一句/第二句"编号或反复"他说/她又说"报幕？

**冗余剔除与视角一致性**
- □ 感知类描述是否拆成了多个近义短句？（如"没有抑扬顿挫，没有情绪的起伏"→合并为"毫无情绪起伏"）
- □ 破折号/省略号已经完成的动作后，是否跟了叙述旁注？（如"——"后半句咽了回去。）
- □ 内心独白/回忆中是否出现了元叙事标签？（如"序章的时候""如前文所述"等角色不会用的词）

**一次展示不二次解释**
- □ 已通过动作/感官展示过的设定，后续是否又被比喻或说明句复述了一遍？（如"耳朵竟然捕捉到"已展示听觉增强→后面又跟"灵识像被拨动的琴弦"）
- □ 是否有数字化/比较级的量化修饰打断叙事流？（如"比之前细了一倍""隔着二十米"→用"竟然""就"替代）
- □ 开篇是否有照应性铺陈？（如"和XX说的一样""不出所料"→直接从时间+角色位置开始）

**设定迁移防流失（#31）**
- □ 本章出场角色的招牌动作是否已兑现？未兑现的是否标注了"无触发场景"？
- □ 暗线/次要伏笔进度是否与伏笔表对齐？连续≥3章零推进的伏笔是否触发"遗忘阈值"？
- □ 沉默设定扫描：核心标志物（<标志物甲>/<标志物乙>/<标志物丙>等）是否已连续≥3章零提及？是否需要补一笔？

### 检查结论
- □ **全部通过** → 正文交付
- □ **不通过** → 列出未通过项，参照本参考文档中的范例退回重写

## 六、内容纯净度规范

正文中绝对禁止出现的元素，生成后全文搜索检查。

### 6.1 章节编号
**规则**：正文中不得出现"第1章""第一章""Chapter 1"等章节标识。
章节编号仅用于大纲/细纲/推演报告的标注区，不能混入正文内容。

❌ 错误："张三走进大殿，这正是第一章开头所说的那个地方。"
✅ 正确："张三走进大殿，檀香扑面而来，三清像在烛光中低眉垂目。"

### 6.2 英文单词（按题材区分）

**核心原则**：英文的使用规则取决于故事的世界观背景，不能一刀切。

**都市现代/科幻近未来题材**（允许合理使用）：
- ✅ 允许：日常通用的英文名词缩写（VIP、WiFi、OK、DNA、CPU、APP、AI、PPT、PDF、GPS、ATM等）
- ✅ 允许：通用的品牌/产品名称中自带的英文（iPhone、Windows等）
- ❌ 禁止：整句英文对话或长段英文表达
- ❌ 禁止：中英交杂的"夹心话文"（如"这个project需要confirm一下"）
- ❌ 禁止：用英文替代中文意境的表达（"比了个V字"→"比了个手势"）

**历史/古代架空/纯仙侠玄幻题材**（严禁使用）：
- ❌ 禁止出现任何英文单词，包括常用缩写：ok、no、yes、BOSS、VIP、MVP、Lv、HP、MP、PK、WC、CPU、DNA

**都市异能/灵气复苏/隐世修真等混合题材**：
- ✅ 日常场景：按都市现代规则执行（角色说"WiFi密码多少"是合理的）
- ✅ 战斗/秘境/修真场景：尽量避免英文，优先用中文表达
- ❌ 禁止：修真者打架时冒英文（如"BOSS的血量只剩10%了"→应改为"那巨兽气息大不如前"）

### 6.3 特殊符号
**规则**：不得出现非中文标点的特殊符号。
正文标点限用：，。！？、“”：；……——　禁止使用：§ ★ ※ ◆ ☑ ✓ ✗ → ← ↑ ↓ ♥ ☆

❌ 错误："他一掌拍出，★级功法果然不同凡响→对手应声倒下。"
✅ 正确："他一掌拍出，那功法带起的劲风让众人齐齐变色——对手应声倒下。"

### 6.4 背景不符词汇
**规则**：所有用词必须与故事的时代背景保持一致。

| 故事背景 | 禁止出现的词汇 | 说明 |
|---------|-------------|------|
| 玄幻/仙侠 | 手机、互联网、WiFi、科学、法律、心理医生 | 除非设定明确允许现代元素 |
| 古代架空 | 与设定朝代不符的官职称呼、制度名 | 严格按设定走 |
| 都市现代 | 设定不允许的超自然词汇 | 除非设定是异能都市 |
| 历史题材 | 超出该历史时期的知识/技术/制度 | 穿越文除外但需解释来源 |
| 科幻未来 | 与科技等级不符的落后用语 | 保持一致即可 |

### 6.5 全文搜索检测工具

生成正文后执行以下搜索：

```
搜索  "第" + 任意数字 + "章"  →  定位章节编号
搜索  a-z / A-Z（只对仙侠/古代题材）    →  定位英文单词
      （都市现代题材：仅定位长句英文或夹心话文，不拦截常见缩写）
搜索  ★ ※ ◆ § ☑ ✓ → ← ↑ ↓ →  定位特殊符号
搜索  手机/互联网/科学等        →  定位背景违规词汇
```

发现任何违规 → 🟢 轻度违规，退回正文生成修改对应段落

## 七、对话自然度规范

### 7.1 核心原则

对话不是"让角色把话说出来"——是让读者听到两个真人聊天。

| 僵硬写作 | 自然口语 | 区别 |
|---------|---------|------|
| "张三兄，今日欲往何处？" | "诶，老三！这是往哪儿去啊？" | 助词+称呼+语气 |
| "在下欲往青云山拜见掌门。" | "青云山。"他背起剑，"掌门找。" | 短句+不说完整 |
| "如此甚好，你我同行如何？" | "正好啊！"话没说完，已被打断 | 打断+未完成句 |
| "此物乃天下至凶之物。" | "这玩意儿……"老僧深吸一口气，"碰一下，人就没了。" | 停顿+通俗+短句 |

### 7.2 口语化语气助词词库

**句末助词（每轮对话至少1个）**

| 助词 | 场景 | 示例 |
|------|------|------|
| 啊 | 疑问/感叹/催促 | "你倒是说啊！""好大的风啊。" |
| 吧 | 建议/不确定 | "走吧。""大概是吧。" |
| 吗 | 疑问 | "真有那么简单吗？" |
| 呢 | 反问/持续 | "那你呢？""还在练着呢。" |
| 嘛 | 撒娇/理所当然 | "我又不是故意的嘛。" |
| 呗 | 随意/不当回事 | "去就去呗。""死就死呗。" |
| 喽 | 轻松/完成 | "这下完喽。""走喽！" |
| 啦 | 兴奋/不耐烦 | "太好啦！""别废话啦。" |
| 呀 | 惊讶/催促 | "怎么是你呀！""快呀！" |
| 哈 | 友善/亲切 | "你先忙着哈。" |

**句首语助词（表达情绪时带出）**

| 助词 | 情绪 | 示例 |
|------|------|------|
| 哎 | 叹气/招呼 | "哎，别提了……""哎！你过来！" |
| 喂 | 喊人/质问 | "喂！你什么意思？" |
| 嘿 | 惊喜/得意 | "嘿！还真让我找到了！" |
| 啧 | 不耐烦 | "啧，又来了。" |
| 哼 | 不服气/傲娇 | "哼，谁稀罕。" |

### 7.3 自然交谈的 9 种行为模式

每章对话中必须出现至少 2 种以上：

1. **打断**："我先——""你让我说完！"
2. **停顿/打磕**："那个……""嗯……怎么说呢……"
3. **话说一半被抢**："我昨天看到——""看到什么？""没，没什么。"
4. **反问不答**："你觉得呢？""你说呢？"
5. **重复对方的话**："死了？""死了。"
6. **用动作替回答**：他看了她一眼。她只是点了点头。
7. **反问拖时间**："你什么意思？""我什么意思？我说你什么意思？"
8. **带着情绪说话**：她把杯子往桌上一顿，"行，我走。"
9. **突然切换话题**："……算了。对了，你刚才说谁来了？"

### 7.4 角色差异化口语模板

| 角色类型 | 话量 | 助词习惯 | 句式特征 | 示例 |
|---------|------|---------|---------|------|
| 上位者/高人 | 极少，每轮≤15字 | 几乎不用 | 反问替代正面回答 | "你可知道这是哪里？" |
| 年轻人/学徒 | 多且密，爱接话 | 嘛呗啦不离口 | 常在长辈说话时插嘴 | "对对对！跟我想的一样嘛！" |
| 粗人/武夫 | 每句≤8字 | 呸滚放屁扯淡 | 说不出成语典故 | "呸，少废话。打不打？" |
| 老前辈/智者 | 每段不超3句 | 仅用啊、吧 | 说前先停顿半拍 | "(沉默)……走吧。" |

### 7.5 对话常见病句修正

| 错误 | 修正 | 原因 |
|------|------|------|
| "如你所知，此山盛产灵石。" | "你知道的，这山……灵石最多。" | 去掉"如你所知" |
| "综上所述，我认为应该撤离。" | "不废话了。走不走？" | 去掉"综上所述" |
| 一段话写了250字无人打断 | 拆成3段，中间插动作或打断 | 无人能连说250字 |
| 三个角色对话语法一模一样 | 给每人分配不同的助词+句长 | 千人一面是大忌 |
| 反派的独白解释了自己的阴谋 | 反派说3句，主角拼出全貌 | 反派不会主动解释 |
| "此剑甚好，实属不凡。" | "这把剑……"他擦了擦剑身，"不错。" | 书面语转口语 |

## 八、POV/视角管理规则

### 8.1 核心原则

网文最常用的视角是**无限第三人称**（跟主角但不锁定），这带来了最大的灵活性，也带来了最大的风险——头跳（head-hopping）。

**视角管理的黄金法则**：读者在任何时候都应该清楚"现在是谁的眼睛在看、谁的耳朵在听、谁的大脑在思考"。

### 8.2 三级视角切换规则

```
【第一级：场景内视角（最严格）】

一个场景 = 一个视角角色。
同场景内不得无标记切换视角。

✅ 正确（老僧视角贯穿全文）：
  "老僧死死盯着那股黑气。黑气中隐隐传来骨骼作响。"
  （读者通过老僧的耳朵听到，视角未跳）

❌ 错误（头跳——无标记切换）：
  "老僧死死盯着那股黑气。
   黑气中的邪人冷笑一声，心想这秃驴终于上钩了。"
  （突然跳进反派的内心——读者困惑：我现在是谁？）

修复方案1——用外部观察替代内心：
  "老僧死死盯着那股黑气。黑气中传出一声低沉的冷笑。"
修复方案2——做视角切换标记再跳：
  （空一行作为视角分隔线）
  "黑气之中，那邪人嘴角勾起一抹冷笑。等了三天，这秃驴总算咬钩了。"
```

```
【第二级：章节内视角（中等灵活）】

同一章内可以切换视角，但必须遵守：
1. 每次切换用空行分隔（至少一个空行）
2. 新视角的第一句话必须明确"谁在感受"（人物名+感官动词）
3. 同一章内切换不超过3次
4. 主角视角占比不低于本章字数的65%

✅ 正确切换：
  "<角色甲>推开<场景甲>的门。

  街对面的奶茶店里，<角色乙>把吸管咬得变了形。她盯着那道门，数到第十秒。"
  （空行分隔 + "<角色乙>"明确新视角 + 感官动词"盯着""数到"）
```

```
【第三级：跨章/跨线视角（最灵活）】

多线并行时的切换规则：
1. 同一"线"连续不超过5章
2. 切换时在章节开头用环境/时间建立锚点
3. 各线时间流速必须在附A·时间-地点-人物位置总表中标注
4. A线角色获知B线事件的时间 ≥ B线事件发生时间 + 信息传递最短时间
```

### 8.3 视角选择策略

| 场景类型 | 推荐视角 | 原因 |
|---------|---------|------|
| 战斗场景 | 主角/参战者 | 近距离的感官冲击和战术思维 |
| 装逼打脸 | 主角 + 围观者（切换） | 主角的"出招" + 围观者的"震惊反应" |
| 悬念埋伏 | 非全知角色 | 限制视角 = 限制读者信息 = 制造悬念 |
| 反派密谋 | 反派 | 制造戏剧反讽——读者知道但主角不知道 |
| 情感高潮 | 情感承受者 | 让读者代入情感最强烈的那个角色 |
| 信息密集场景 | 信息最少者 | 读者和信息最少的角色一起"被揭示" |
| 首次亮相 | 目击者 | "通过别人的眼睛看"比自述更有冲击力 |

### 8.4 每章视角归因检查

```
☐ 本章出现了几个角色的内心活动？
   → 如果≥2个 → 每次切换是否有空行标记？（否则 = 头跳）
☐ 有没有角色"看到/听到/感受到"了他不可能获取的信息？
   → 是 → 附B1·知情矩阵核查该角色是否具备该信息
☐ 主角视角占比是否≥65%？
   → 否 → 检查是否有"水配角视角"在灌水
☐ 如果有反派视角段落 → 是否制造了有效的戏剧反讽而非单纯解释？
```

---



### 8.5 同一事件双视角讲述规则

网文高频手法：同一事件从两个不同视角各讲一次。用得好像复调音乐——两条旋律各自独立，合在一起产生第三种意义；用不好就是灌水。

```
【双视角使用条件】（满足全部三项才能使用）

☐ 第二个视角是否提供了"第一个视角绝对不可能知道的信息"？
   → 不是 → 第二个视角是灌水，删除
☐ 两个视角对同一事件的"感受/理解"是否产生了有意义的反差？
   → 不是 → 两个视角只是换了人称代词，无增量价值
☐ 双视角的总字数是否≤该事件如果是单视角写法的120%？
   → 超过 → 压缩第二视角，不是把同一件事写两遍

═══════════════════════════════════════════
📐 双视角三种模式
═══════════════════════════════════════════

模式一：信息互补型（最常用）
  视角A看到"发生了什么" → 视角B看到"为什么发生"

  示例·战斗场景：
  视角A（主角）："他一剑刺出，对方竟然不闪不避，任由剑锋划过左肩。"
  视角B（对手）："他等这一剑等了十年。剑锋入肩的那一刻，他笑了——赌对了。
          这一剑的位置，恰好激活了肩胛骨下埋了十年的那道封印。"
  → 视角A看到表面，视角B揭示真相。不是重复，是互补。

模式二：认知反差型
  视角A的理解 vs 视角B的理解——同一事件，两种完全不同的解读

  示例·对话场景：
  视角A（表白者）："他终于说出口了。三年了，每个字都像从胸腔里掏出来的。"
  视角B（被表白者）："'我喜欢你'——这四个字从她嘴里说出来的时候，
          他脑子里只闪过一个念头：这是她第几次说这句话了？"
  → 视角A觉得是"终于"，视角B觉得是"又来了"。读者的感受在这两个版本之间震荡。

模式三：时间错位型
  视角A在事件发生的当下 → 视角B在事件发生的很久之后（回忆/追溯）

  示例：
  视角A（当下）："他把那块玉递给她，什么都没说。她接过，笑了笑。"
  视角B（十年后）"十年了。她至今不知道那天他递过来的玉，是他拿命换的。
          她只知道那天他什么都没说——她以为是不在乎。"
  → 时间的错位让简单的动作有了重量。
═══════════════════════════════════════════
```

### 8.6 限知视角下的环境描写约束

限知视角的核心铁律：**读者只能通过当前视角角色的感官体验世界。任何视角角色"不可能看到/听到/感知到"的描写，都是POV违规。**

```
【限知视角环境描写·三问自检】

每写一段环境描写，自问三个问题：

① 这段描写的"感知源"是谁？
   → 必须明确：是通过谁的视觉/听觉/触觉/嗅觉？
   → 如果是"上帝视角在描述" → 违规，改写成某个角色的感知

② 当前视角角色在这里能看到/听到/感受到这些吗？
   → 检查：他站在什么位置？视线是否被遮挡？是否有超感知能力？
   → 如果没有超感知但写出了"墙后的动静" → 违规

③ 这段描写的"用词"是否来自当前视角角色的认知体系？
   → 古代书生不会用"分子结构"描述一杯茶
   → 刚入门的弟子不会用"元婴期的威压"描述高手（他没见过元婴期）

═══════════════════════════════════════════

❌ 违规示例·上帝视角泄漏：
  "<角色甲>推开门的瞬间，没有注意到门框上方有一道细细的裂痕，
   从门楣一直延伸到天花板。那是三天前地震留下的。"
  → 违规：<角色甲>没注意到，那是谁在描述？上帝视角。

✅ 修复·限知视角：
  "<角色甲>推开门的瞬间，一片灰从门框上簌簌落下来，掉在他头发上。
   他皱眉，伸手在头顶一抹——指尖沾了灰，还有细碎的石屑。"
  → 合规：<角色甲>通过触觉（灰落在头发上）发现异常，不靠上帝视角。
═══════════════════════════════════════════
```

## 九、场景结构模板（Scene-Sequel 引擎）

### 9.1 双单元场景引擎

商业小说的场景结构由两种单元交替组成，形成自然的推动力：

```
【场景单元 Scene】目标 → 冲突 → 灾难
【续章单元 Sequel】反应 → 困境 → 决策（→ 新目标 → 下一场景）
```

网文语境下的适配：

| 原版概念 | 网文适配 | 示例 |
|---------|---------|------|
| 目标（Goal） | 欲望/需求——不一定是显式目标，可以是"想搞清楚那道黑气是什么" | "老僧想知道黑气中是何人" |
| 冲突（Conflict） | 阻碍——有对手/环境/信息差拦在主角和欲望之间 | "黑气中人不答话，反而祭出毒血幡" |
| 灾难（Disaster） | 转折——意外发生，局势逆转 | "七尾蜈蚣突然咬中手腕" |
| 反应（Reaction） | 情绪+生理反应——被打击后的第一反应 | "眼前一黑，法轮摇摇欲坠" |
| 困境（Dilemma） | 选择——在两个坏选项中做出抉择 | "交出噬血珠保命 / 死守到底" |
| 决策（Decision） | 行动——选择后的第一个动作 | "双手结水瓶印，一字一字念出大明咒" |

### 9.2 模板使用规则

**每章至少包含一个完整的 Scene-Sequel 循环。** 短章（2000字以下）一个循环即可。长章（2500-3000字）可以嵌套1-2个循环。

```
【场景自检——每一段结束后问三个问题】
1. 这段是 Scene 还是 Sequel？
2. 如果是 Scene → 这段有明确的目标/冲突/灾难三要素吗？
   - 缺"目标" → 读者不知道角色在干什么 → 补
   - 缺"冲突" → 太平淡 → 加阻碍
   - 缺"灾难" → 没有转折，缺乏推动力 → 加意外
3. 如果是 Sequel → 这段有反应/困境/决策三要素吗？
   - 跳过"反应"直接做决策 → 角色像机器 → 补情绪/生理反应
   - 没有"困境" → 决策太轻易 → 让两个选项都"不好"
```

### 9.3 网文适配变体

| 场景类型 | Scene-Sequel 适配 | 说明 |
|---------|------------------|------|
| 战斗场景 | Scene(目标=击败对手,冲突=对手出招,灾难=意外逆转) → Sequel(反应=受伤,困境=战或逃,决策=绝招) | 三阶段战斗结构天然匹配 |
| 装逼打脸 | Scene(目标=低调不暴露,冲突=被挑衅/轻视,灾难=忍无可忍) → Sequel(反应=冷/怒,困境=暴露多少实力,决策=适度亮剑) | 打脸=灾难→决策的瞬间 |
| 情感场景 | Scene(目标=表达/试探,冲突=误解/掩饰,灾难=说错话/被撞破) → Sequel(反应=尴尬/后悔,困境=解释还是沉默,决策=行动) | 灾难不一定是"坏事"，可以是"意外" |
| 探索/解谜 | Scene(目标=弄清楚,冲突=线索矛盾,灾难=新线索推翻旧假设) → Sequel(反应=困惑/兴奋,困境=继续还是换思路,决策=新方向) | 信息密度高的场景尤其需要Sequel消化 |

### 9.4 嵌套循环编排

一章（2500+字）可含多个 Scene-Sequel 循环，三种嵌套模式：

```
模式A·串联：S1→Q1→S2→Q2
  适用：标准推进章节（事件→消化→新事件→消化）
  示例：遭遇敌人(S1)→受伤后躲藏(Q1)→发现线索(S2)→决策追踪(Q2)

模式B·嵌套：S1→(微型Q1)→S1续→Q2
  适用：战斗/动作高潮——长Scene中插入1-2段微型Sequel（喘口气/观察伤口/队友递药）
  示例：激战(S1)→喘息3秒"手在抖"(微型Q1)→绝地反击(S1续)→战后瘫坐(Q2)

模式C·并行：S1→Q1a(角色A的反应)+Q1b(角色B的反应)→S2
  适用：多角色场景——同一事件/灾难，不同角色有不同的反应路径
  示例：三碗被抓(S1)→红藕的反应是"想办法"(Q1a)+疤眼李的反应是"趁机"(Q1b)→两线并行推进
```

### 9.5 过渡场景的微型 Sequel

日常/过渡场景不需要完整 Scene-Sequel，但必须有至少一个微型 Sequel 结构：

```
微型Sequel = 反应(1句情绪/生理) → 困境(1个选择) → 决策(1个动作)

示例："他看了眼天色。——酉时了。→（反应）
        再不走，城门就关了。但老孙还没回来。→（困境·二选一）
        他又站了一会儿，转身把门虚掩上。"→（决策·选了一个并行动）

⚠ 如果过渡场景连微型Sequel都没有 → 🟡违规（纯灌水段落，删掉不影响剧情）响剧情）

### 9.6 常见 Scene-Sequel 错误

```
错误类型              │ 症状                        │ 修复
─────────────────────┼─────────────────────────────┼───────────
Scene跳Sequel          │ 战斗结束直接跳到下一场景        │ 插入Sequel：角色怎么消化刚才的事？
Sequel跳Scene          │ 角色还在"反应"，突然又开始打架    │ Sequel必须走到"决策"这一步才能触发新Scene
灾难无代价             │ 战斗赢了毫发无伤               │ 每次灾难必须有物理/心理/关系代价
决策太轻易             │ 两个选项中有一个明显"更好"       │ 让两个选项都付出代价——不是"选哪个更好"而是"选哪个更不坏"
微型Sequel缺失         │ 第三章和第四章之间情绪无衔接      │ 在章节开头加一个微型Sequel承接上章情绪
过渡章无Sequel         │ 日常描写无推进，读者跳章            │ 每段日常必须有目标→阻碍→消化三步
```

## 十、装逼打脸的节奏公式

### 10.1 完整四步链

装逼打脸是网文最具辨识度的爽点机制，其节奏链必须完整走完四步，跳步或压缩将导致爽感打折。

```
═══════════════════════════════════════════
💥 装逼打脸四步链
═══════════════════════════════════════════

【第一步：铺垫——建立低估预期】（占总字数35-40%）
  目标：让读者产生"主角被低估/被看不起"的憋屈感
  手法：
  · 对手/围观者用言语/行动表达轻蔑
  · 设置一个"门槛"（等级差/身份差/财富差）
  · 铺垫越长越细，打脸越爽——但不能拖过500字
  检查：
  ☐ 读者此刻是否感到憋屈/不公/想替主角出头？
  ☐ 对手的态度是否有"依据"（哪怕依据是错误的）？

【第二步：触发——主角亮出底牌】（占总字数15-20%）
  目标：一瞬间打破低估预期
  手法（按场景选择）：
  · 实力型："他缓缓抬起手，指尖凝出一缕金光"
  · 身份型："腰间的令牌滑了出来，上面的徽记让全场寂静"
  · 认知型："你说完了？那现在轮到我了"
  检查：
  ☐ 触发动作是否简洁？（不超过50字——越短越有力）
  ☐ 触发时刻是否有一个明确的"转折点"？

【第三步：反应链——多重视角爆炸】（占总字数30-35%）
  目标：通过其他人的反应放大爽感
  必须包含至少3层反应：
  ① 直接对手的反应（震惊/恐惧/难以置信）
  ② 围观者的反应（窃窃私语/倒吸冷气/退后一步）
  ③ 权威/关键人物的反应（"他是……""不可能……"）
  检查：
  ☐ 是否出现了至少3个不同角色的反应？
  ☐ 反应是否逐步升级？（对手→围观→权威）
  ☐ 是否有至少一句直接引语的反应？（"这，这是……！"）

【第四步：余波——新秩序建立】（占总字数15-20%）
  目标：打脸之后，世界发生了什么变化
  手法：
  · 资源解锁（"这块令牌，可以打开了"）
  · 关系重置（"从今天起，他就是核心弟子"）
  · 新冲突萌芽（"但远处，一双眼睛盯上了他"）
  检查：
  ☐ 余波中是否有至少一个"实质性变化"（不是"大家都很震惊"就完了）？
  ☐ 是否埋下了新冲突的种子？

═══════════════════════════════════════════
```

### 10.2 打脸禁忌

| 禁忌 | 说明 | 后果 |
|------|------|------|
| 铺垫过短 | 对手还没充分展示轻蔑，主角就打脸了 | 爽感打折——读者还没进入"憋屈"状态 |
| 触发冗长 | 主角用了一大段话/一套连招来展示实力 | 力量感稀释——真正的强者一句话就够了 |
| 反应缺失 | 只有主角和对手两人，没有围观者 | 最致命的错误——打脸的爽感80%来自围观者的反应 |
| 反应同质化 | 三个围观者的反应都是"他倒吸一口冷气" | 浪费了反应链的多层价值——每个角色反应应有角色特色 |
| 余波空洞 | 打完脸就切场景，没有任何后续影响 | 打脸成了孤立事件——应该改变一些东西 |
| 连续打脸 | 同一章打脸同一个对手多次 | 边际效应递减——第二次爽感不到第一次的30% |

### 10.3 打脸密度控制

```
【打脸频率指南】（按平台）

番茄/飞芦：每3-5章1次打脸事件（含小型打脸）
起点：每5-8章1次打脸事件，每10-15章1次大型打脸

小打脸：一个垫脚石配角被碾压（300-500字完成四步链）
大打脸：核心反派/重要势力被打脸（1000-1500字完成四步链）

⚠ 连续3章无任何打脸 → 🟡中度违规，触发"爽感枯竭"阈值
```

## 十一、爽点类型学

### 11.1 六大爽点类型及结构公式

| 类型 | 核心机制 | 结构公式 | 典型字数 |
|------|---------|---------|---------|
| **实力碾压** | 主角用超出预期的实力碾压对手 | 对手展现实力→旁人不看好主角→主角一击→全场沉默 | 500-800字 |
| **身份反转** | 被看不起的主角展露真实身份 | 身份误会→遭受冷遇/轻蔑→信物/令牌/名字揭露→态度180度转变 | 800-1200字 |
| **资源获取** | 获得稀缺资源/法宝/传承/机缘 | 渴望建立→门槛设置→竞争者失败→主角独特方式通过→获得+附加奖励 | 1000-1500字 |
| **复仇清算** | 清算曾经伤害/背叛主角的人 | 回忆碎片(为什么恨)→当面对峙→对方狡辩/求饶→清算(不一定是杀人)→主角心态变化 | 1200-2000字 |
| **认知颠覆** | 打破众人对主角/世界的固有认知 | 旧认知反复强调→矛盾出现→新事实轰然揭露→震惊→重新评估 | 800-1200字 |
| **收集完成** | 拼图的最后一块到位/集齐 | 铺垫缺失的那一块→多线搜寻→最后关口→获得→拼图完成时的揭示 | 1500-2500字（跨多章） |

### 11.2 爽点共鸣原理

```
【爽感的三个层次】

第一层·即时爽（0.5秒反应）
  → 属于番茄/飞芦的核心追求
  → 机制：读者预期被瞬间满足（看到装逼被打脸的那一刻）
  → 写法：铺垫→反差→释放（三步必须在一章内完成）
  → 例子："金丹？"主角看了一眼，"我三年前就是了。"

第二层·叙事爽（追读过程中持续积累）
  → 属于起点/番茄的核心追求
  → 机制：主角从一个状态成长到另一个状态的可信路径
  → 写法：每50章设置一个"状态里程碑"——读者回看时会发现"原来他已经走了这么远"
  → 例子：从被逐出师门的废物到一宗之主（中间每一步都有迹可循）

第三层·意义爽（全书完成后回味的满足感）
  → 属于起点的终极追求
  → 机制：故事结束后读者发现"一开始就注定了这个结局"
  → 写法：暗线/伏笔/主题的全书闭环——铺垫在开篇，揭晓在结局
  → 例子：主角最终击败的终极反派，正是开篇杀死他师父的人
```

### 11.3 爽点密度检查

```
【每章爽点自检】

☐ 本章是否产生了至少一个"读者会忍不住截图/划线/分享"的瞬间？
   → 否 → 🟡中度违规，检查是否缺少以下至少一项：
   · 一句金句（"金丹？我三年前就是了。"）
   · 一个反转（对手的绝招被主角一根手指抵住）
   · 一个揭示（"你以为他是散修？他是十年前那个……"）
   · 一个高光（主角在绝境中做到了一件不可能的事）

### 11.4 爽点密度计算公式

```
每章爽点密度 = 本章爽点场景总字数 / 本章总字数 × 100%

平台基准：
  飞芦 → 爽点密度 ≥25%（每4字中有1字在造爽）
  番茄 → 爽点密度 ≥18%
  起点 → 爽点密度 ≥12%

低于基准 → 🟡违规（读者会感到"这章没爽点"）

爽点间隔控制：
  飞芦 → 每1500字必须有1个爽点（≤2页）
  番茄 → 每2000字必须有1个爽点（≤3页）
  起点 → 每3000字必须有1个爽点（≤5页）
```

### 11.5 爽点与钩子搭配规则

```
本章爽点类型        │ 推荐出口钩子类型        │ 原因
───────────────────┼──────────────────────┼──────────
实力碾压            │ 悬念型·未知威胁         │ 爽完→埋一个"但更大的麻烦来了"
身份反转            │ 信息型·余波             │ 身份揭晓后→读者想知道"他为什么隐瞒"
资源获取            │ 情绪未落型              │ 获得宝物→让读者沉浸在喜悦中，不急着抛悬念
复仇清算            │ 情绪未落型·代价          │ 复仇完→"他赢了，但他失去了什么"的余味
认知颠覆            │ 悬念型·信息差           │ 旧认知被打破→新认知是什么？
收集完成            │ 悬念型·终极              │ 拼图完成→揭示全局→但全局意味着更大的问题

⚠ 禁忌组合：装逼打脸后接"战斗未完型"钩子 → 读者刚爽完又拉回紧张 → 爽感被截断
           正确做法：装逼打脸后接"余波型"钩子，让读者在余韵中翻下一章
```

### 11.6 爽感疲劳预警

```
同类型爽点连续出现：
  连续2章同类型 → 🟢（允许，但第3章必须换类型）
  连续3章同类型 → 🟡违规（读者会疲劳，爽感递减）
  连续5章同类型 → 🔴重度（必须重新规划）

爽点类型多样性检查（每10章统计）：
  单一爽点类型占比 ≥50% → 🟡违规（触发多样性预警）
```

## 十二、悬念制造方法

### 12.1 四种悬念类型

```
【类型一：信息差悬念】

定义：读者不知道某个信息，但知道这个信息存在
机制：给读者一个"未完成的信息缺口" → 读者的大脑会自动想填上

手法：
· 神秘物品："他从怀里掏出一块令牌。令牌上的徽记，让在场所有人面色大变。"
  （读者不知道令牌代表什么 → 但知道它很重要 → 想知道是什么）
· 未说完的话："你还不知道，你师父当年其实是——"一声钟响，打断了她。
· 异常反应："提到'天衍宗'这个名字时，一向冷静的<角色甲>，手指微微颤了一下。"

【类型二：戏剧反讽悬念】

定义：读者知道但角色不知道
机制：读者看到了危险在逼近，但角色浑然不觉 → 焦虑感持续积累

手法：
· 反派视角段落：先展示反派的陷阱/阴谋 → 再切回主角"毫不知情"的日常
· 隐藏的第三者："<角色甲>推开门的瞬间，巷口的摄像头微微转了一个角度。"
  （读者知道有人在监视，但<角色甲>不知道）
· 倒计时："距离血月之夜，还有三天。而他还在买奶茶。"
  （读者知道大难临头，主角还在日常——焦虑值拉满）

【类型三：倒计时悬念】

定义：读者和角色都知道死线在逼近
机制：时间流逝 = 压力递增

手法：
· 毒发倒计时："那股麻痒感已经蔓延到了肩膀。最多一炷香。"
· 封印倒计时："石门上第三道符文已经开始碎裂。最多一刻钟。"
· 救援倒计时："<角色乙>的灵力波动越来越弱。十五息。十息。五息——"
  倒计时的数字必须递减，不能用"越来越近""快要到了"这类模糊说法。

【类型四：不可靠叙述悬念】

定义：读者和角色都不确定真相——只有模糊的线索
机制：多个互相矛盾的信息碎片 → 读者和角色一起拼图

手法：
· 矛盾信息："古籍上说噬血珠在三百年前被毁。但普智手上那颗，和古籍描述的完全一致。"
· 不可靠信息源："那个疯疯癫癫的老乞丐说：你要找的人，早就死了。可是昨天，有人看见他出现在北城。"
· 多解线索：一个符号、一个梦、一句诗——可能有3种以上解释
```

### 12.2 悬念层级管理

```
【悬念的三层分期】

短期悬念（1-3章内回收）
  → 用途：保证读者点开下一章
  → 就是"出口钩子"——章末制造的信息缺口
  → 用法：每章末必须有至少1个短期悬念
  → 示例："他推开门的刹那，整个人僵住了——屋里坐着的那个人，不该出现在这里。"

中期悬念（10-30章内回收）
  → 用途：保证读者追完一个完整的迷你故事线
  → 就是埋在某卷中的"待揭示信息"
  → 用法：每卷设置2-3个中期悬念
  → 示例：神秘人物的身份、某件物品的真实功能、某个势力背后是谁

长期悬念（100章+ / 全书的终极悬念）
  → 用途：保证读者追完全书
  → 就是暗线——贯穿全文的最大谜底
  → 用法：全书最多3个，第1章就铺设，最后1章揭晓
  → 示例：灵气枯竭的真正原因、主角的前世身份、世界的终极真相
```

### 12.3 悬念健康度检查

```
【每10章运行一次】

☐ 是否有连续≥3章的短期悬念属于同一类型（全是"神秘人物出现"）？
   → 是 → 增加悬念类型多样性
☐ 是否有中期悬念超过30章仍未回收也没有推进？
   → 是 → 🟡中度违规，必须在下10章内推进或回收
☐ 长期悬念的超50章零提及？
   → 是 → 🟡中度违规，必须在下5章内重新露出碎片
```

## 十三、环境描写功能分类

### 13.1 七种功能模式

环境描写不只是"造氛围"。每段环境描写必须承担至少一项明确功能。如果环境描写删掉后不影响读者的任何感受 → 该环境描写是灌水。

```
【功能一：造氛围】（已有覆盖，此处列出模板）

目标：在人物/冲突出场前用环境建立情绪基调
模板：[天气/光线] + [空间特征] + [异常细节]
示例："一道闪电裂空而过，黑暗中，这座在风中孤独伫立的小草庙亮了一下。"

═══════════════════════════════════════════

【功能二：反映心理】（新增）

目标：用环境描写外化角色的内心状态——不写"他很绝望"，写他眼中的世界
模板：角色心情 → 环境被"染色"（同场景在不同心情下的不同描述）

示例·绝望时的世界：
  "雨打在瓦上，滴滴答答。以前他觉得这声音好听，今天只觉得吵——每一下都像在催命。"
示例·希望时的同一场景：
  "雨打在瓦上，滴滴答答。他记得小时候最喜欢听这个声音——像是整个世界在给他伴奏。"

检查：
☐ 如果角色心情改变，他/她注意到的环境细节是否也会改变？
☐ 环境描写的"色调"是否与角色的情绪状态一致？（不一致时可以是有意反差——见功能四）

═══════════════════════════════════════════

【功能三：暗示信息】（新增）

目标：环境细节本身就是伏笔——读者读第二遍时会恍然大悟
模板：[异常细节] + [角色忽略/不以为意] + [后期揭示其意义]

示例：
  "石壁上有一道剑痕。<角色甲>扫了一眼就移开了视线——这种遗迹里剑痕多了去了。
  （第100章揭晓：这道剑痕是他前世留下的——切口的角度，和他现在的剑法一模一样。）"

检查：
☐ 本章是否有至少1个"看起来漫不经心"的环境细节可以成为后续埋笔？
☐ 这个细节是否"不引人注目但经得起推敲"（不是"墙上写着一行大字：此处有宝藏"）

═══════════════════════════════════════════

【功能四：制造反差】（新增）

目标：环境与事件的情绪基调形成刻意反差，制造"不协调感"——加强悲剧/讽刺
模板：[美好的环境] + [残酷的事件] 或 [压抑的环境] + [温暖的时刻]

示例：
  "那天的阳光特别好。好到她后来每次想起这一天，都觉得阳光是一种残忍。"
  （阳光→美好 VS 这天发生的事→残酷 = 反差强化了残酷）

  "暴雨倾盆的深夜，他敲开了她的门。她把一碗热汤推到他面前。"
  （暴雨→压抑 VS 热汤→温暖 = 反差强化了温暖）

检查：
☐ 如果本章有情感高潮 → 环境的情绪基调是"同步"还是"反差"？
☐ 如果是反差 → 反差是否有意义（不是为反差而反差）？

═══════════════════════════════════════════

【功能五：战斗资源】（新增）

目标：环境中存在的元素可以被主角/反派用于战斗
模板：提前描写环境中的可利用元素 → 战斗时被调用

示例：
  "院子里堆满了劈好的柴。——第3段
  他一脚踢翻柴堆，散落的木柴拦住了追兵的去路。——战斗段落"
  （如果院子里没有柴堆，这一脚就踢空了——战斗失去了环境依托）

  "炼丹房的角落里有一缸硝石。——环境铺垫
  她将最后一道灵火打偏，引燃了硝石缸。——战斗调用"
  （好战斗 = 角色利用环境 + 角色创造环境 / 差战斗 = 两人在空白空间对轰）

检查：
☐ 如果本章有战斗场景 → 环境中有至少1个被利用的元素吗？
☐ 这个元素是否在战斗前就已建立（而非战斗时才突然出现）？

═══════════════════════════════════════════

【功能六：身份标志】（新增）

目标：通过环境描写暗示场景中的人物身份/地位/性格（不直接说"他很有钱"）
模板：[空间物件] + [物件的状态细节] → 读者自行推断人物信息

示例：
  "桌上摊着一本账本，翻到一半。砚台里的墨已经干了，笔搁在账本上，笔尖压出一道折痕。"
  （读者推断：此人忙于算账，突然离开，走得很急，很久没回来）
  （说了"这是个管账的"吗？没有。读者自己推断出来的——更有参与感）

检查：
☐ 角色第一次登场的场景 → 环境中是否有≥1个"反映角色身份"的细节？
☐ 这个细节是"让读者自己推断"还是"直接告诉读者"？

═══════════════════════════════════════════

【功能七：过渡控制】（新增）

目标：利用环境切换控制叙事节奏——从激烈场景过渡到平静场景（或反之）
模板：[正在退场的环境] → [过渡中的环境] → [正在进入的环境]

示例：
"石门在身后轰然关闭。甬道里很暗，水滴声从远处传来，一下，一下。
走了约一炷香，前方终于出现了一点光。
推开最后一道石门，阳光劈头盖脸地砸下来——外面竟是一片花海。"
（石门的黑暗甬道 = 过渡区 = 让读者从地下城的紧张中"喘一口气"，再进入花海的新情绪）

检查：
☐ 如果本章有情绪基调的转换（紧张→平静/悲伤→希望） → 是否有过渡环境作为缓冲？
☐ 过渡环境的长度是否与情绪转换的幅度匹配？（幅度越大，过渡越长）
```

### 13.2 环境描写功能自检

```
【每段环境描写的三问】

1. 这段环境描写承担了七种功能中的哪一种（或哪几种）？
   → 答不上来 → 删除或赋予功能
2. 删除这段环境描写后，读者的体验会损失什么？
   → 什么都不损失 → 删除
3. 这段环境描写的信息是否可以融入人物的动作/对话中？
   → 可以 → 优先融合而非单独写一段
```

## 十四、三维错位：用思想·话语·行动的落差刻画深度

### 14.1 核心原理

平面人物：思想 = 话语 = 行动（三者完全一致，一眼看穿）
立体人物：思想 ≠ 话语 ≠ 行动（有错位、有伪装、有无法说出口的东西）

这种"错位"不是人物设定的瑕疵——恰恰相反，它是人物深度的来源。读者通过观察"角色说的"和"角色做的"之间的裂缝，自行推断角色真正在想什么，这个过程本身就是阅读乐趣。

### 14.2 三维错位模板

```
═══════════════════════════════════════════
📐 三维错位刻画模板
═══════════════════════════════════════════

【维度一：思想层】（角色真正在想什么——不可见）
  → 角色的真实感受/真实意图/恐惧/欲望
  → 这一层读者可能永远看不到完整版本——只能通过错位推断

【维度二：话语层】（角色说出口的——可见）
  → 可能与思想一致（坦诚），可能不一致（伪装/保护/试探）
  → 话语层面的"伪装"本身就是人物塑造

【维度三：行动层】（角色实际上做了什么——可见，最可信）
  → 行动是性格的最终证明
  → 与话语的偏差越大，人物内心的冲突越剧烈

═══════════════════════════════════════════
```

### 14.3 三种典型错位模式

**模式一：思想✗话语（嘴上说一套，心里想一套）**

```
思想：他表面镇定，心里却慌得一塌糊涂——怕被看穿，怕被拒绝。
话语："我没事。"（语气刻意放平缓，却藏不住尾音的颤抖）
行动：一边说着"我没事"，一边悄悄握紧拳头，指节泛白。

读者感受：嘴上说没事的人，恰恰是心里最有事的人。
```

**模式二：话语✗行动（说的和做的不一样）**

```
思想：她早就决定要离开这座城市了，从三个月前就开始看别的城市的招聘。
话语："这里挺好的，我暂时不想走。"
行动：她的行李箱已经收好了，藏在床底。车票夹在钱包最里层，每次结账都会碰到。

读者感受：行动出卖了她——她在骗别人，也在骗自己。
```

**模式三：思想+话语✗行动（连自己都不愿意面对的真相）**

```
思想：他告诉自己"我已经放下了那段感情，早就放下了"。
话语："提她干嘛？都过去了。"
行动：路过那家他们曾经一起去的面馆时，他下意识加快了脚步。连他自己都没注意到，
      他已经三年没有走过那条街了。

读者感受：角色在自欺——而这种自欺比任何直白的"他还是很痛苦"更有感染力。
```

### 14.4 错位的节奏控制

| 错位类型 | 适用场景 | 揭露时机 | 读者体验 |
|---------|---------|---------|---------|
| 话语✗行动 | 人际冲突、谈判、表白 | 即时可见 | 读者自己发现裂缝→参与感 |
| 思想✗话语 | 内心挣扎、成长节点 | 延迟揭露（先给话语和行动，后给思想） | 回头读发现伏笔→二刷价值 |
| 全维错位 | 重大转折、崩溃前兆 | 逐步升级（裂缝越来越明显） | 焦虑积累→最后爆发 |

### 14.5 每章错位自检

```
☐ 本章主要角色的思想、话语、行动是否完全一致？
   → 如果完全一致 → 检查：这个角色此刻是否处于"无需伪装"的状态？
     如果不是 → 考虑增加至少一处错位
☐ 是否有角色"说一套做一套"的细节？（话语✗行动）
☐ 是否有角色"嘴上逞强身体却很诚实"的细节？（行动揭露思想）
☐ 错位的揭露是否有节奏？（不是一次全抖出来，而是让读者逐渐发现）
```

## 十五、选材原则：用1-2个定义性细节代替堆砌

### 15.1 核心原则

**描写不是"写得多=写得好"。恰恰相反——一个精心挑选的细节，比一百个平庸的形容词更有力量。**

这是《七十二堂写作课》中最核心的描写法则：挑选"最深刻印象+最具关键性"的细节，舍弃其余。读者的大脑会自动用这一个细节补全整体形象，过多的描写反而剥夺了读者的想象力。

### 15.2 定义性细节的选择标准

一个合格的"定义性细节"必须同时满足三个条件：

```
① 独特性：这个细节是"只有他/她才有"的吗？
   → 如果换一个人也能用 → 不是定义性细节

② 信息密度：这一个细节能同时传达什么？
   → 至少2层信息（身份+性格 / 处境+欲望 / 过去+现在）

③ 记忆点：读者读完三天后还记得这个细节吗？
   → 如果记不住 → 不是定义性细节，换一个
```

**经典案例——孔乙己的两个定义性细节**：

| 细节 | 独特性 | 信息密度 | 记忆点 |
|------|-------|---------|-------|
| 穿长衫（又脏又破也不肯脱下） | ✅ 只有他 | 身份（读书人）+ 性格（要面子）+ 处境（穷困潦倒） | ✅ |
| 茴香豆的"茴"有四种写法 | ✅ 只有他 | 性格（迂腐）+ 价值观（执着于无用的知识） | ✅ |

鲁迅没有写孔乙己的身高、脸型、声音、步态——但两个细节就够了。读者脑中已经浮现出一个完整的落魄书生形象。

### 15.3 外貌描写的选材规则

规则：**每个角色在首次登场和关键时刻，只给1-2个定义性细节。禁止"从头到脚"的流水账。**

```
❌ 流水账式（无选材，全堆砌）：
  "她有一双大眼睛，高鼻梁，樱桃小嘴，皮肤很白，穿着一条白色连衣裙，
   脚上是一双米色高跟鞋，手里提着一个棕色皮包。"
  → 写了很多，但读完一个都记不住。

✅ 选材式（只抓1-2个定义性细节）：
  "她眼角有两道很深的笑纹，一笑就弯成月牙，哪怕不说话也透着一股亲切感。
   头发花白却梳得整整齐齐，耳后别着一根旧发夹，是她戴了十几年的物件。"
  → 两个细节：笑纹=亲切/岁月，旧发夹=念旧/有故事。
```

### 15.4 动作描写的选材规则

规则：**不写一连串动作，只写一个"出人意料又在情理之中"的动作。**

```
❌ 动作过多（稀释了力量）：
  "他先站起来，走到窗边，推开窗户，深吸一口气，又转身走回桌前，
   拿起杯子喝了一口水，最后才缓缓开口。"
  → 五个动作，读者不知道重点在哪。

✅ 只写关键动作：
  "他张了张嘴，又闭上了。最后只是把杯子往桌上一顿——
  水溅出来，他也没擦。"
  → 两个动作（闭嘴+顿杯），但比上面的五个动作更有表现力。
```

### 15.5 选材自检

```
【每个角色的定义性细节检查】

角色名 │ 定义性细节              │ 传达了什么              │ 独特性 │ 信息密度
──────┼───────────────────────┼───────────────────────┼───────┼─────────
孔乙己 │ 长衫（又脏又破不肯脱）  │ 身份+性格+处境          │ ✅     │ 3层
      │ 茴香豆四种写法          │ 性格+价值观             │ ✅     │ 2层
______ │ ________________       │ ________________       │ ☐     │ __层

☐ 每个主要角色是否都有≥1个定义性细节？
☐ 这些细节是否在首次登场时就呈现了？
☐ 是否有多余的、可以删除而不影响人物辨识度的外貌/动作描写？
```

## 十六、侧面描写：用他人口吻和外界反馈塑造人物

### 16.1 核心原理

直接叙述（正面描写）："他是一个非常坚强的人。"
侧面描写：让另一个角色说——"在所有人的记忆里，老李永远是那个天塌下来也能笑着扛的人。"

两者的区别：正面描写是作者在告诉读者"你要相信这个"。侧面描写是让角色在告诉角色——读者是"偷听"到的，天然更可信。

### 16.2 四种侧面描写手法

**手法一：他人记忆/口碑**

通过其他角色的回忆或评价，间接展示目标角色。

```
示例·写一个坚强的人：
"去年他家里出了大事——老婆住院，孩子又刚好高考。他没跟任何人诉苦，
每天照样按时上班，连请半天假都没有。下了班就去医院，凌晨才回家。
隔壁老张说：要不是有天半夜起来上厕所，看到他家的灯还亮着，
根本不知道他一个人坐在沙发上，对着黑屏的电视发呆。"
→ 通过邻居老张的观察，侧面写了主角的坚韧。
```

**手法二：环境/物品的见证**

角色不在场，但他留下的痕迹、他的物品、他塑造的环境，替他说话。

```
示例·写一个整洁到强迫症的人：
"连他坐过的椅子，走的时候也会推回原位——不像别人随手一拉就走了。
他的办公室桌上，笔帽永远拧紧，稿纸对齐桌边。保洁阿姨最喜欢打扫这间房，
因为根本不需要打扫。"
→ 通过"保洁阿姨喜欢"这个旁人视角的细节，比直接写"他很爱干净"有效十倍。
```

**手法三：缺失带来的真空感**

角色退场后，通过他人的"不适应"来反向塑造。

```
示例·写一个被怀念的人：
"老陈退休的第三天，食堂阿姨还在他的固定位置摆了一副碗筷。
摆完才想起——哦，他已经不来了。
同事小王习惯性地抬头想问他一个问题，对面工位空了。
他愣了几秒，又把头低下去。"
→ 通过"碗筷"和"同事抬头"两个细节，比"大家都很想他"有力百倍。
```

**手法四：反应链——通过多人的反应接力塑造**

不只是一个人说他怎么样，而是一个链条：不同身份、不同关系的人对他的不同反应。

```
示例·写一个被敬畏的角色：
"徒弟提起他，声音都压低三分——'我师父……脾气不太好，你见了别乱说话。'
同行提起他，表情复杂——'那家伙，是疯子，也是天才。'
唯独他妻子提起他，只是轻轻说了一句——'他其实比谁都怕冷。每晚睡觉，
一定要先把被子掖好四个角。'"
→ 徒弟的敬畏 + 同行的复杂评价 + 妻子的温柔细节 = 人物瞬间立体
```

### 16.3 正面描写 vs 侧面描写的使用比例

| 场景类型 | 正面描写占比 | 侧面描写占比 | 说明 |
|---------|:-----:|:-----:|------|
| 主角日常行动 | 80% | 20% | 读者需要直接跟随主角 |
| 配角首次登场 | 40% | 60% | 通过主角的眼睛+其他人的议论来写配角，不要旁白介绍 |
| 已退场的角色 | 0% | 100% | 通过他人的回忆和"缺失感"来延续存在 |
| 神秘角色/终极反派 | 10% | 90% | 越是重要的反派/隐藏角色，越要用侧面描写保持神秘感 |
| 情感高潮 | 50% | 50% | 正面写角色的感受 + 侧面通过他人反应放大 |

### 16.4 侧面描写自检

```
【每章侧面描写检查】

☐ 本章是否有新角色登场？
   → 如果有 → 该角色的首次信息是否至少有40%来自"他人口吻/他人观察"而非旁白介绍？

☐ 本章是否有已退场/已死亡的角色被提及？
   → 如果有 → 提及方式是否通过回忆/物品/缺失感而非直接倒叙？

☐ 本章的主角高光时刻是否有"围观者反应"作为侧面烘托？
   → 如果没有 → 考虑在关键时刻插入≥1个旁人的反应（一句话即可）
```

## 十七、细节创新审计：在模板框架内做出差异化

### 17.1 核心定位

**创新不是颠覆整个题材——而是在规范框架内，做细节层面的差异化打磨。**

网文的底层框架可以借鉴通用逻辑（技能本身已经保证了这一点），但成品想要走出模板化、拥有辨识度、让读者记住，必须在三个细节层面主动注入差异化。

### 17.2 三个创新维度

#### 维度一：人设差异化（给模板角色注入"不完美"）

| 模板化写法 | 差异化改写 | 差异点 |
|-----------|----------|--------|
| 高冷男主，话少实力强 | 高冷是因为口吃——他不是不想说话，是怕被嘲笑。实力强是因为从小只能靠拳头表达。 | 给"高冷"一个具体的、有温度的成因 |
| 活泼女主，善良乐观 | 她的"乐观"是装出来的——母亲临终前说"你要笑着活"。她怕停下来，一停就会崩溃。 | 给"乐观"一个伤口——让读者心疼这份伪装 |
| 老谋深算的反派 | 他的每一步算计，都是为了兑现对亡妻的承诺。他不是"想赢"，他是"不能输"。 | 给反派一个读者无法反驳的动机 |

**检查模板**：
```
【人设差异化自检】

☐ 主角的"核心特征"是否有具体成因（不是笼统的"因为小时候"）？
☐ 配角的性格是否有一个"例外时刻"（比如粗人突然温柔了一把）？
☐ 反派的动机是否有至少一个"读者无法反驳"的理由？
☐ 是否有至少一个角色的性格标签在故事进程中产生过"微调"（不是崩塌，是成长）？
```

#### 维度二：桥段差异化（同样的困境，不同的破局方式）

| 经典困境 | 模板化解法 | 差异化破局 | 创新点 |
|---------|----------|----------|--------|
| 主角被围困 | 爆种升级，一人反杀全场 | 主角利用围困者的内部矛盾，策反了其中一支，用敌人的手瓦解了围困 | 靠智谋而非蛮力 |
| 女主被抓走 | 主角单枪匹马杀入敌营 | 主角在敌营外等了三天，等到敌人自己把女主"请"出来——因为他提前布局，让女主变成了敌人的烫手山芋 | 靠布局而非冲锋 |
| 宗门大比 | 隐藏实力，层层碾压 | 主角在决赛前主动认输——因为他发现大比的真正目的是筛选"祭品"，认输的代价是失去荣誉，但保住了所有人的命 | 靠信息差颠覆规则 |

**检查模板**：
```
【桥段差异化自检】

☐ 本章的核心困境是否有至少一种"非模板化"的破局思路？
   → 不是"更强的力量碾压"——而是"换个维度解决"
   → 不是"等别人来救"——而是"主动改变规则"
☐ 如果本章有战斗场景 → 胜负的方式是否有新意？
   （不是"更强的招式"——是"利用环境""利用信息差""利用敌人的弱点"）
☐ 本章的解决方式是否"只有这个角色能做"？（而非"随便换个人也能这样解决"）
```

#### 维度三：情感差异化（拒绝套路化的感动）

最常见的模板化情感：牺牲（为救主角而死）、误解（明明相爱却互相伤害）、反转（原来他是坏人/好人）。

差异化方向：
- **牺牲**：不写"用生命挡刀"，写"用后半辈子的平庸换主角一次出头的机会"。
- **误解**：不写"因为我爱你所以我不说"，写"因为我说了真话，所以被误解——真相比谎言更伤人"。
- **反转**：不写"他其实是好人"，写"他一直是好人，但他的'好'恰恰是最大的伤害"。

### 17.3 创新审计频率与尺度

```
【创新审计执行规则】

频次：每20章执行一次（不每章执行——防止创新焦虑）
尺度：只标记"建议差异化"——不强制修改，不触发回退
输出：列出本章/本卷中模板化程度最高的3个元素 + 各给1条差异化建议

审计单格式：
═══════════════════════════════════════════
🔍 细节创新审计 — 第X章至第X+N章
═══════════════════════════════════════════

模板化元素           │ 模板表现               │ 差异化建议
────────────────────┼──────────────────────┼────────────────
人设·男主高冷        │ 全程话少+实力碾压       │ 在某次受伤后，他下意识喊了一句"疼"——
                    │                       │  然后立刻闭嘴。读者才知道他不是冷，是忍。
桥段·被围后反杀      │ 爆种一人灭全场          │ 反杀的方法是"揭露围困者中一人的秘密"——敌人内讧
情感·师尊牺牲        │ 为主角挡下致命一击      │ 师尊没有挡刀，而是把毕生修为封印进主角体内——
                    │                       │  从此，主角每一次突破，都能"听到"师尊的声音
═══════════════════════════════════════════
```

### 17.4 创新与规范的平衡

创新的底线：**不能违反已确立的世界观规则和人物底线。**

```
☐ 差异化方案是否符合第一阶段确立的力量体系规则？
☐ 差异化方案是否会让角色做出违反其"底线与原则"的行为？
☐ 差异化方案是否与已发布的正文内容矛盾？
```

## 十八、碎片化铺陈：零存整取式人物登场

### 18.1 核心原则

**首次登场只给一个定义性细节。其余特征分散到后续章节中，逐步释放。让读者像在现实中结识一个人那样，慢慢拼凑出完整形象。**

这是当前技能体系中的一个隐含矛盾：七维人物设计卡定义了角色从身份到原则的全部特征，但角色首次登场时是否应该一次性展示全部七维标签？答案是否定的——一次性倾倒全部人设，等于给读者发了一份"人物档案"，刻板枯燥，看过即忘。

### 18.2 释放节奏模型

```
═══════════════════════════════════════════
📐 人物特征碎片化释放模型
═══════════════════════════════════════════

首次登场（第N章）→ 1个定义性细节（外在，可被观察）
第N+1~N+5章     → 1-2个性格侧面（通过行动和对话自然暴露）
第N+10~N+20章   → 1个隐藏维度（矛盾点/恐惧/软肋，通过压力场景触发）
第N+30章+       → 底线原则的考验场景（角色被迫在原则之间做出选择）
全书中期         → 深层欲望的完整揭示（读者终于理解"他为什么一直是这样的"）

═══════════════════════════════════════════
```

**经典案例——安娜·卡列尼娜的登场**：

| 章节 | 释放的碎片 | 读者拼出的形象 |
|------|----------|-------------|
| 首次登场 | 落座时抬手理顺颈间的狐皮围脖 | 优雅、自持、体面 |
| 后续章节 | 零星补一笔微卷发丝 | 有了具体的画面 |
| 又后续 | 一笑弯起的眉眼 | 有了温度，不再只是"优雅" |
| 全书读完 | 所有碎片拼合——一个有欲望、有挣扎、有温度的女人 | 不是"读懂的"，是"认识的" |

### 18.3 首次登场的信息配额

```
【首次登场信息释放规则】

角色类型     │ 首次登场可释放信息               │ 禁止释放的信息
────────────┼──────────────────────────────┼────────────────
主角        │ 1个定义性细节 + 1个处境暗示      │ 全部七维标签、完整背景故事
核心配角    │ 1个定义性细节 + 1句对话暗示性格  │ 性格全貌、与主角的完整关系
次要配角    │ 1个定义性细节（仅此而已）         │ 超过1个细节
反派        │ 1个定义性细节 + 1个"不对劲"的暗示 │ 反派动机、完整阴谋
路人/龙套   │ 1个功能性特征（如"戴眼镜的店员"）│ 任何超出功能需求的描写

⚠ 首次登场的定义性细节：必须是"可被旁观者直接观察到的"外在特征
   → 可以写：走路的姿态、手上的茧、耳后的旧发夹、开口前的犹豫
   → 不能写：内心独白、深层欲望、童年创伤、隐藏的秘密
```

### 18.4 碎片铺陈规划表

动笔前为每个主要角色规划"什么特征在第几章首次释放"：

```
【碎片铺陈规划表：______（角色名）】

七维标签条目          │ 首次释放章节 │ 释放方式（行动/对话/环境/他人视角）
─────────────────────┼───────────┼──────────────────────
① 身份标签            │ 第1章      │ 环境暗示（工位名牌、穿着）
② 性格·核心词          │ 第1章      │ 对话态度（对同事的一句话）
③ 性格·矛盾点          │ 第12章     │ 行动（压力下暴露的反常举动）
④ 核心欲望（表层）      │ 第5章      │ 对话（在不经意的抱怨中透露）
⑤ 核心欲望（深层）      │ 第50章     │ 关键时刻的抉择
⑥ 深层恐惧            │ 第30章     │ 噩梦/闪回/下意识回避
⑦ 习惯动作 + 说话模式  │ 第1章      │ 动作（招牌动作首次触发）
⑧ 成长弧线·起点        │ 第1-3章    │ 处境（当前状态的展示）
⑨ 底线与原则           │ 第25章     │ 困境中的抉择
⑩ 底线·触碰反应        │ 第80章     │ 被逼到墙角时的爆发
```

### 18.5 碎片化铺陈 vs 分布式信息释放的区别

| 维度 | 分布式信息释放（铁律#19） | 碎片化铺陈（本技法） |
|------|----------------------|-------------------|
| 管什么 | 世界观信息（设定、背景知识） | 人物信息（性格、过往、欲望） |
| 释放驱动 | 剧情需要什么信息就暴露什么信息 | 角色需要什么场景就暴露什么侧面 |
| 节奏 | ≤3个同类信息/章 | 首次≤1个定义性细节，后续每章≤1-2个新维度 |
| 目的 | 避免设定倾泻 | 避免人物档案化——让读者"认识"而非"查阅" |

### 18.6 每章碎片化自检

```
【碎片化铺陈自检——每章正文生成后运行】

☐ 本章是否有新角色首次登场？
   → 有 → 该角色的首次信息是否≤1个定义性细节 + 1个对话/处境暗示？
   → 如果写了≥3个特征 → 🟡中度违规：退回正文生成，将多余特征分散到后续3-5章

☐ 本章已登场角色的信息释放量是否合理？
   → 是否在本章一次性释放了该角色的≥2个全新维度？
   → 如果是 → 检查：本章是否有足够的"压力场景"支撑多个维度的同时暴露？
   → 如果没有压力场景 → 保留1个维度，其余推迟到后续章节

☐ 是否有角色的"深层特征"在首次登场或前3章内被提前释放？
   → 检查范围：深层欲望、深层恐惧、底线原则、童年创伤
   → 如果已释放 → 🟡中度违规：确认是否有特殊剧情需求？
     如果没有 → 移回后续章节
```

## 十九、回忆交织：双时间线叙事技法

### 19.1 核心定位

网文中双时间线叙事极为常见：主角的前世记忆碎片、功法传承中的祖师残像、重生者脑海中两世人生的重叠。好的回忆交织不是"插播一段倒叙"，而是让两条时间线在当下场景中产生化学反应——过去照亮现在，现在赋予过去新的意义。

### 19.2 三种交织模式

**模式一：触发式闪回**

由当下场景中的一个感官触发，自然滑入回忆，不做"他想起了……"的硬切换。

```
示例·气味触发：
  "空气里飘来一股焦糊的中药味。
   他端着杯子的手顿了顿。
   母亲走的那年冬天，屋里也是这个味道——炉子上的药罐子咕嘟咕嘟地
   滚着，她靠在床头，说这药太苦了，比命还苦。
   他回过神来，中药味已经散了。像是在提醒他，该去看看她了。"

技法要点：
  · 触发物必须是当下场景中自然存在的（不是空中掉下来的）
  · 回忆结束必须有"回神"标记（一个动作/一个感知）
  · 回忆段落的感官描写必须≥2种——让它和当下一样有"体感"
```

**模式二：对照式并行**

当下发生的事情，在回忆中有一个"镜像版本"。读者在两个版本的对照中，感受到变化（或不变）。

```
示例·物是人非：
  当下：他蹲下身，在鞋柜最底层翻找。"那双旧拖鞋呢？"
    "扔了。"妻子头也不抬，"都破成什么样了。"

  回忆（5年前·同一场景）：母亲把那双拖鞋从垃圾桶里捡回来。
    "还能穿！"她拍掉上面的灰，"你看看，底都没磨平呢。"
    他把鞋抢过来，扔得更远——"丢人的东西，不要了。"

技法要点：
  · 两个版本之间必须有"同一个锚点"（同一件物品/同一个地点/同一句话）
  · 对比的方向不一定是"美好过去 vs 悲惨现在"——可以是"过去也不美好，
     现在理解了当时的不易"
```

**模式三：渗透式碎片**

不对完整回忆场景，而是让过去的碎片直接渗透到当下的叙事中——一句话、一个画面，转瞬即逝。

```
示例·渗透式：
  "他把女儿举过头顶。小丫头咯咯笑着，两条腿在空中乱蹬。
   她笑起来的样子——眼睛先弯，嘴角才跟上。
   他愣了一下。举着女儿的手微微发颤。
   然后他笑了，把女儿往上又举了一次。笑声把那个愣神盖过去了。"
   （读者推断：女儿笑起来像某个人——没有说出来的人）

技法要点：
  · 渗透的信息不超过1句话
  · 不解释——让读者自己推测"他为什么愣了一下"
  · 本章内最多使用2次渗透式碎片，超过则改为模式一或模式二
```

### 19.3 双线叙事的时间流速控制

当两条时间线并行时（如重生文"前世"和"今生"交替推进），必须遵守：

```
☐ 两条线的时间流速是否在附A·时间线总表中标注？
   → 前世线: Ch1-Ch10对应"前世·15岁-20岁"
   → 今生线: Ch1-Ch10对应"今生·重生后第1天-第30天"
☐ 两条线的信息交叉点是否标注？
   → 今生第50章主角使用前世的某个知识 → 前世第20章已展示这个知识的获取
☐ 控制章节配比：主角所在"主线时间线"占总篇幅≥70%
   → 回忆/前世/闪回线占≤30%
```

### 19.4 每章双线自检

```
☐ 本章是否包含回忆/闪回/前世内容？
   → 如果是 → 回忆的"触发物"是否来自当下场景（非凭空出现）？
   → 如果是 → 回忆结束后是否有明确的"回神"标记？
☐ 如果本章是双线并行 → 本章两条线的字数比是否合理？
   （建议：当前主线≥70%，回忆线≤30%）
☐ 回忆内容是否"解释了当下的某些东西"？（而非单纯的信息堆砌）
   → 如果删掉这段回忆，当下场景的感染力会损失什么？
```

## 二十、物品象征：让物件替人物说话

### 20.1 核心原则

**人物不会自己说"我很孤独""我放不下""我变了"——但他们身边的东西会说。**

物品象征与设定迁移清单（标志物追踪）的关系：设定迁移清单负责"标志物是否被遗忘"（防御性），物品象征负责"物品如何在当下场景中承载情感和主题"（进攻性）。

### 20.2 三个象征层次

```
【层次一：归属象征】
物品代表一个人——看到物品，就想起人。

示例：
  · <标志物甲> → 代表师父的存在
  · <标志物乙>微微发烫 → 代表师父在"回应"
  · 办公桌第三格抽屉里锁着一张旧合影 → 代表某个不能说的人

技法：物品首次出场时平铺直叙，后续每次出场都附加一层新的情感含义。
```

```
【层次二：变化象征】
物品的状态变化 = 人物关系/心境的变化。

示例·裂痕：
  "那把木梳子跟了她二十年，从外婆传给母亲，再到她手里。
   梳子上有一道细细的裂痕——那是母亲最后一次梳头时，手上没力气，梳子滑落摔的。
   后来她用胶补上了。梳子还能用，但那道裂痕，怎么也补不平。"

技法要点：
  · 物品的"变化"必须是自然发生的（不是作者安排的奇迹）
  · 变化的时刻 = 情感的转折点
  · 读者不需要被告诉"这里很感人"——物品会替人物说
```

```
【层次三：缺失象征】
物品的缺席 = 人物缺失了什么。

示例·空位：
  "老陈退休后，食堂阿姨还在窗边摆着一副碗筷。
   他的老位置。靠窗，第三排。
   摆了三天。第四天，碗筷收了。那张桌子又坐满了人。
   阿姨没有解释，但每天打饭的时候，还是会往那个方向看一眼。"

技法要点：
  · 不写"大家都很想念他"——写"碗筷还在"
  · 缺失的冲击力来自"之前一直在的东西，现在不在了"
```

### 20.3 物品象征的节奏规则

```
【标志物全生命周期规划】

阶段      │ 章节区间      │ 物品做什么                           │ 读者感受
──────────┼──────────────┼───────────────────────────────────┼──────────
引入      │ 首次出场       │ 平实描写，不过度渲染                    │ 注意到，但不会多想
初次赋义   │ 第N+5~10章    │ 物品首次展现出与角色的情感关联            │ "哦，这个东西不简单"
反复出场   │ 第N+10~N+50章 │ 每次出场叠加一层新含义，或展示状态变化    │ 渐渐成为"有分量的东西"
高潮赋义   │ 关键场景       │ 物品的状态/归属发生根本性变化            │ 情绪引爆点
终局收束   │ 结局附近       │ 物品的最终归宿（传承/毁灭/封存/归还）    │ 给读者一个"完整的圆"
```

### 20.4 与设定迁移清单的联动

```
【本章物品象征检查——与设定迁移清单协同运行】

☐ 本章中出现的标志物，是否只是在"被提及"还是承担了情感功能？
   → 如果只是提及（"<标志物甲>还在"） → 🟢轻度：在下一章赋予功能
   → 如果承担了功能（如上面示例中的"裂痕""空碗筷"） → ✅ 合格

☐ 是否有标志物已经连续≥5章仅做"提醒式提及"而无功能推进？
   → 是 → 🟡中度：在下5章内安排一次功能性出场（归属/变化/缺失三层之一）

☐ 对全书≥2个核心标志物，是否已规划了全生命周期（引入→初次赋义→反复出场→高潮→终局）？
   → 如果没有 → 🔵建议：在设定文档中补充生命周期规划（不强制，不回退）
```

## 二十一、三项精准强化规则

三条来自顶尖作家实战心法的硬规则，每条独立可查，精准命中高频写作问题。

### 规则一：戒副词——用动词替代所有"地"字修饰

> **"通往烂文的路，是副词铺出来的。"**

副词（用力地、愤怒地、缓缓地、冷冷地）暴露的是动词不够精准。每出现一个"地"字副词，意味着你本可以找到一个更好的动词——但你没有。

```
❌ 副词凑数：
  "他用力地、愤怒地关上了门。"（告诉读者"他生气"，没有画面）

✅ 精准动词：
  "他攥紧拳头，狠狠摔上房门，门框发出一声闷响。"
  （动词"攥""摔" + 名词"闷响"= 情绪、力度、画面全部到位）
```

**自检规则**：正文生成后全文搜索`地`（作为副词的"地"），每发现一处就问：能否用一个精准动词替代这个副词+动词的组合？

### 规则二：对话标注只用"说"——禁止一切花式后缀

> **"怒斥道、低喃道、冷声道、喘息道、咬牙道——全部禁止。"**

标注人物对话只有一种写法：某某"说"。人物的情绪、状态、性格，靠对话内容本身 + 伴随动作 + 神态展示。花式标注是作者跳出来替角色"解释情绪"——这恰恰是读者最不需要的东西。

```
❌ 花式标注：
  老金咬牙道："你别后悔。"
  李莎喘息道："我真的没办法了。"

✅ 只用"说" + 动作神态：
  老金攥紧掌心，一字一顿："你别后悔。"
  莎娜胸口起伏，声音发颤："我真的没办法了。"
```

**自检规则**：正文生成后全文搜索`道`，排查是否存在"X道"（X为情绪/动作修饰词）的花式标注。

### 规则三：改稿公式——初稿×90% = 二稿

> **"初稿的灵气 + 二稿的精准 = 定稿的质感"**

写作流程分两阶段，而非一次性写到完美：

```
【第一阶段·初稿】完整讲完故事，不纠结文笔。
  任务：保热情、保灵气、一口气写完
  禁忌：中途不要听他人意见、不要反复修改

【第二阶段·二稿】删减10%，收紧节奏。
  公式：二稿字数 = 初稿字数 × 90%
  原则：删完后故事主体、氛围、节奏不残缺 → 删减成功
        删完后故事残缺 → 说明初稿废话太多，继续删
  核心：不以个人喜好留内容，只以作品质量定取舍

【冷却期】写完初稿后静置一段时间（≥24小时），
  脱离自我视角后再通读，客观发现语病/漏洞/冗余。
```

**自检规则**：当前章节初稿完成后，二稿字数是否≤初稿的90%？如果不是，逐段排查冗余。

## 二十二、时间跳跃处理：跳跃期的写法、状态与信息管理

### 22.1 三种跳跃类型

```
═══════════════════════════════════════════
⏱ 时间跳跃三类型
═══════════════════════════════════════════

类型      │ 跨度          │ 典型场景               │ 处理策略
──────────┼──────────────┼──────────────────────┼──────────
短跳      │ 数天~数周     │ 赶路/养伤/等待         │ 1-2段概括 + 1个状态变化锚点
中跳      │ 数月~1年      │ 闭关修炼/外出历练       │ 1个代表性场景 + 回顾清单
长跳      │ 数年以上      │ 转世/封印/沉睡/大境界跨越│ 对比式写法 + 残留线索
═══════════════════════════════════════════
```

### 22.2 短跳：1-2段概括 + 状态锚点

```
【短跳模板】

[跳跃声明·1句话] + [期间概括·1-2句] + [当前状态锚点·1个细节]

示例：
  "三天后，伤口结了痂。
   这三天里他几乎没有离开过山洞，靠着储物袋里的干粮和水撑了过来。
   他试着握了握拳——灵力运转到掌心时还有些滞涩，但比起三天前已经好了太多。"

技法要点：
  · 跳跃声明必须精确到天数（不能写"过了几天"）
  · 状态锚点是读者重新"接入"角色的抓手——选最有辨识度的状态变化
  · 禁止跳跃期间插入完整场景（短跳就是短跳，不要趁机写一大堆）
```

### 22.3 中跳：1个代表性场景 + 回顾清单

```
【中跳模板】

[代表性场景·1段] → [回顾清单·逐条列出跳跃期间的关键变化]

示例·闭关三个月后：
  "三个月。洞口的藤蔓从枯枝抽成了绿帘。
   最后一次收功时，丹田里的灵力比以前多了一倍不止——运气时经脉隐隐发胀，
   像是河道突然变宽，水流一时还适应不了新宽度。（代表性场景）

   这三个月里：境界突破了一次，储物袋里多了十二颗筑基丹，肩上那道旧伤
   已经完全消了疤。只是左手的剑茧变薄了——太久没握剑了。（回顾清单）"

技法要点：
  · 代表性场景 = 最能浓缩"这期间发生了什么"的一个瞬间
  · 回顾清单 = 跳跃前状态 vs 跳跃后状态的逐条对照
  · 每项变化不超过1句话——这是在"盘点"，不是在"展开"
```

### 22.4 长跳：对比式写法 + 残留线索

```
【长跳模板】

[跳跃前·某件物品/某个人/某个习惯] → [跳跃后·同一锚点的变化] + [残留线索·暗示中间发生了什么]

示例·百年后：
  "他记得离开时，山门前的石碑上刻着自己的名字——第三个，字体还新。
   一百年了。石碑还在，只是他的名字已经被挤到了最下面一排，风吹雨打，
   字迹模糊得几乎看不清。上面密密麻麻全是新名字。（对比：石碑）

   他在碑前站了很久。老槐树还在，只是树干上多了一道歪歪扭扭的刻痕——
   像是在数什么。他数了数：二十二道。（残留线索：谁刻的？为什么要数？）"

技法要点：
  · 长跳的核心张力来自"变了"和"没变"的对照
  · 至少1个残留线索暗示跳跃期间发生了什么——不解释，交给后续章节
  · 长跳后角色必须有一个"重新认识这个世界"的过渡场景
```

### 22.5 跳跃后状态继承规则

```
【时间跳跃·附A更新必查项】

跳跃前                         │ 跳跃后必须更新                         │ 更新方式
───────────────────────────────┼──────────────────────────────────────┼──────────
附A·时间线                      │ 故事日期跳过___天/月/年                 │ 直接标注跨度
主角等级                        │ 跳跃期间是否修炼/突破？                  │ 是→更新等级
主角位置                        │ 跳跃期间是否移动？                       │ 是→更新位置
关键角色位置                    │ 所有未死亡角色重新确认位置                │ 逐一标注
持有物品                        │ 消耗品自动扣减（时间×日常消耗率）          │ 按规则计算
                               │ 新获得物品标注来源（跳跃期间获得）          │
中毒/受伤/临时状态              │ 过期状态自动清除                         │ 逐条标记
                               │ 持续状态标注"仍在持续·已过___天"          │
人际关系                        │ 标注跳跃期间的关系变化                    │ 至少检查盟友/敌对
附D·心理状态                    │ 衰减期事件是否已过期？                    │ 过期→注销
                               │ 跳跃期间是否有新的情绪事件？               │ 有→新注册
附C·承诺兑现                    │ 应兑现区间是否被跳过？                    │ 跳过→立即处理
                               │ 如有未兑现承诺被跳过 → 🟡中度违规         │
```

### 22.6 跳跃自检

```
☐ 本章是否包含时间跳跃？
   → 如果是 → 跳跃属于短跳/中跳/长跳哪种类型？
   → 跳跃后的状态锚点是否在第1段就确立（让读者立即"接入"）？
☐ 跳跃前后是否进行了状态继承检查（附A/附B2/附D/附C的跨跳更新）？
☐ 附C·承诺兑现：是否有应兑现承诺的区间被跳跃跨过？
   → 是 → 🟡中度违规，必须在跳跃前兑现或跳跃后立即处理
```

## 二十三、连载商业优化：标题、卷间衔接与钩子多样性

### 23.1 章节标题写作规则

章名不是大纲里的标注——它是读者在目录页决定"点不点进去"的唯一依据。平庸的章名 = 白写的正文。

```
═══════════════════════════════════════════
📛 章节标题三原则
═══════════════════════════════════════════

原则一：标题必须是一个"微型钩子"
   ✅ "第3章：我好像闯祸了"（悬念：闯了什么祸？）
   ✅ "第15章：师父说，你打不过他的"（冲突：谁？为什么？）
   ❌ "第3章：入门试炼"（信息型，没有情绪钩子）
   ❌ "第15章：大战黑风怪"（剧透式，读者已经知道结果）

原则二：标题不剧透本章核心转折
   ✅ 暗示冲突，不暗示结果
   ✅ 暗示危险，不暗示化解
   ❌ "他赢了""反杀""虐渣"等结果型标题——读者看完标题就不需要看正文了

原则三：标题包含1个"可感知的具体事物"
   ✅ "第8章：那碗面里有毒"（面→具体，有毒→悬念）
   ✅ "第21章：她留下的那把伞"（伞→具体，她→悬念）
   ❌ "第8章：化险为夷"（抽象，没有画面）
   ❌ "第21章：旧情难忘"（抽象，没有可感知的具体事物）
═══════════════════════════════════════════
```

### 23.2 分平台标题策略

| 平台 | 标题长度 | 标题风格 | 示例 |
|------|---------|---------|------|
| 飞芦 | ≤10字 | 脑洞型、反转型 | "第3章：我好像闯祸了" |
| 番茄 | ≤12字 | 冲突型、情绪型 | "第3章：她一开口，全场死寂" |
| 起点 | ≤15字 | 信息型、悬念型 | "第三章：入门试炼的隐藏规则" |

**自检**：章名生成后，检查是否满足对应平台的标题规则和长度限制。

### 23.3 换卷衔接·前情回顾锚点

读者隔了一段时间回来追下一卷，需要"回忆锚点"来快速重新接入故事。不是写一段"前情提要"——是用1个场景内的1个细节，唤醒读者对上一卷的记忆。

```
【回忆锚点模板】

换卷后第1章的前200字内，必须出现≥1个"上一卷的标志性锚点"：

锚点类型      │ 示例
──────────────┼────────────────────────────────────
物品锚点      │ <标志物甲>微微发热——上一次发热是在第X卷结尾。
              │ （读者：对了，上次说到刻痕……）
身体锚点      │ 他摸了摸左肩——那道疤已经淡了，但阴雨天还是会隐隐发痒。
              │ （读者：对了，上一卷他被刺了一剑……）
人物锚点      │ <配角甲>还是老样子，趴在他脚边，尾巴一下一下拍着地面。
              │ （读者：对了，<配角甲>上次差点死了……）
对话锚点      │ "你真的不打算告诉她？""——说完。等了三卷，还没说。"
              │ （读者：对了，那个秘密……）

⚠ 锚点必须是上一卷中读者已经有情感投入的事物——不能是新引入的。
⚠ 锚点之后立即切入本卷新剧情，不拖泥带水。
```

### 23.4 换卷衔接·软性状态重置

换卷后主角从"上层变底层"的硬性重置（换地图规则）已有。但还有一种"软性重置"——信息重置和关系重置——同样重要：

| 重置类型 | 说明 | 示例 |
|---------|------|------|
| 信息重置 | 在新环境中，主角之前掌握的信息大部分失效 | "他在东域的人脉，到了北域连一个传音符都发不出去" |
| 关系重置 | 旧盟友/旧敌人在新环境中以新身份重新建立关系 | "那个在东域追杀他的人，现在成了北域必须合作的唯一盟友" |
| 认知重置 | 新环境中对主角的认知从零开始 | "在北域没人知道他是谁——他得重新'被人认识'" |

### 23.5 钩子类型多样性检测

```
【每10章运行一次·钩子类型复用度检测】

最近10章的出口钩子类型分布：
章号范围: ChX-ChY

钩子类型        │ 使用次数 │ 健康阈值
────────────────┼─────────┼─────────
悬念型·信息差    │ ___次    │ ≤4次
悬念型·戏剧反讽  │ ___次    │ ≤3次
悬念型·倒计时    │ ___次    │ ≤3次
悬念型·不可靠叙述│ ___次    │ ≤2次
冲突型           │ ___次    │ ≤3次
情绪未落型       │ ___次    │ ≤3次

☐ 是否有单一类型占最近10章的≥50%？
   → 是 → 🟡中度违规：钩子类型单调，读者产生"又是这套"的疲劳感
   → 修复：替换其中≥2章的钩子类型
```

### 23.6 开篇第一章·冲突密度最低标准

```
【开篇第一章专项约束】

☐ 第1章前200字内必须出现冲突（不是铺垫、不是世界观、不是人物介绍——是冲突）
☐ 第1章必须包含≥1个"读者会截图/分享"的瞬间（金句/反转/揭示/高光）
☐ 第1章的人物碎片释放≤2个（按碎片化铺陈规则）
☐ 第1章的L1设定曝光≤总体设定的15%（不要在第1章就开始讲世界观）
☐ 第1章结尾钩子必须是"悬念型·信息差"（让读者有一个必须看到第2章的谜）
```

## 二十四、非线性成长：进两步退一步的人物弧线

### 24.1 核心原则

**网文中最动人的成长，从来不是一条平滑的上扬曲线——而是前进、跌倒、爬起来、再前进的螺旋。**

七维设计卡定义了角色的起点和终点，但起点到终点之间的路径不应该是直线。非线性成长要求在角色的能力/心智/道德三个维度上各设置至少一次"倒退"或"停滞"。

### 24.2 三种非线性模式

```
模式一：能力倒退（最常见的非线性）
  获得力量 → 力量失控/被封印/被剥离 → 在更弱的状况下重新成长
  经典案例：主角突破到新境界 → 走火入魔经脉受损 → 被迫回到更低等级从头修炼
  写作要点：倒退后的"重新成长"必须和第一次成长有质的区别——
           不是"再来一遍"，而是"带着上一次的记忆和教训，用不同方式成长"

模式二：代价式成长（获得的同时失去）
  获得重要能力/法宝/盟友 → 同时失去同等重量的东西
  经典案例：主角拜入最强宗门 → 但必须割舍之前的全部人际关系
  写作要点：失去必须是"不可逆的"——读者能感受到主角是真的付出了代价，
           而不是"暂时失去后面又拿回来了"

模式三：觉醒式倒退（心智层面的"知道得越多越痛苦"）
  角色对世界的认知被颠覆 → 原有的价值观崩塌 → 重新建立更复杂的价值观
  经典案例：主角一直相信的恩师实则是终极反派 → "信仰"崩塌 → 重新寻找立足之地
  写作要点：这不是"好人变坏人"——是"简单的好人变成了复杂的、但仍然选择善良的人"
```

### 24.3 非线性成长规划表

```
【非线性成长规划表：______（角色名）】

成长维度    │ 第1次倒退    │ 倒退原因     │ 倒退后的变化              │ 恢复/新平衡
───────────┼────────────┼────────────┼───────────────────────┼──────────
能力维度    │ 第__章      │ ___        │ 失去___/被封印___          │ 第__章以新方式恢复
心智维度    │ 第__章      │ ___        │ 原有的信念___被___颠覆      │ 第__章建立新信念
道德维度    │ 第__章      │ ___        │ 做了___违背底线的事       │ 第__章面对后果/赎罪

⚠ 三个维度的倒退不能集中在同一章节（否则变成"全面崩溃"——读者会感到绝望而弃书）
⚠ 两次倒退之间至少间隔10章（让读者有时间在"恢复期"建立新的情感连接）
```

### 24.4 非线性自检

```
☐ 主角的能力/心智/道德三个维度中，是否有≥2个维度规划了非线性弧线？
   → 如果三个维度全是直线上升 → 🟡中度违规：角色成长过于平坦
☐ 回溯的"低谷"是否有≥1章的篇幅充分展开（不是一笔带过）？
☐ 从低谷恢复后，角色是否发生了"不可逆的变化"（而非回到原点）？
☐ 两次倒退之间是否间隔≥10章？
```

## 二十五、群像场景调度：≥4人同场的焦点管理

### 25.1 核心难题

当前系统在单/双/三人场景中运转良好。但≥4人同场时——师门大会、朝堂论辩、战队集结——容易出现"全员背景板"问题：除了正在说话的那个人，其余全部沉默。

群像场景的调度本质是焦点管理：让读者任何时候都知道"现在镜头在谁身上"，并且镜头在合理流动。

### 25.2 焦点分配规则

```
【群像场景·焦点三圈模型】

第一圈·当前焦点（1人）
  → 此刻正在说话/行动/被关注的角色
  → 占本段字数的50%+

第二圈·反应圈（1-2人）
  → 对焦点角色的言行做出即时反应的角色
  → 反应可以是一句话、一个眼神、一个动作——但不能沉默
  → 占本段字数的20-30%

第三圈·存在感圈（其余人）
  → 不被遗忘但也不抢焦点
  → 每过半页（约300字）给≥1个"存在感标记"（如"XXX靠在椅背上，眼睛盯着天花板"）
  → 不参与当前互动的角色 → 用1个动作证明"他还在"

═══════════════════════════════════════════

示例·五人会议场景的焦点分配：
  [焦点] "我觉得应该从东路进攻。"<角色甲>敲了敲地图。
  [反应] <配角乙>皱眉，没说话。赵哥点头，幅度很小。
  [焦点→转移] "东路有暗哨。"开口的是<角色乙>——他一直靠在窗边，
    这会才直起身。（焦点从<角色甲>转移到<角色乙>）
  [存在感] <配角甲>趴在角落里打盹，耳朵动了一下，又耷拉下去。
  [新焦点] "暗哨的位置，你确定？"<角色甲>转向<角色乙>。
```

### 25.3 焦点轮转节奏

```
【焦点轮转规则】

场景时长     │ 焦点切换次数 │ 同一角色连续处于焦点区的最大时长
────────────┼────────────┼────────────────
短场景(<500字)│ 1-2次       │ 整个场景（短场景允许不切换）
中场景(500-1500字)│ 2-4次     │ 400字
长场景(>1500字)│ 4-8次       │ 500字

⚠ 如果同一角色连续处于焦点≥500字 → 🟢轻度：检查是否需要让其他角色"刷存在感"
```

### 25.4 群像场景自检

```
【群像场景·出场角色追踪表（≥4人时填写）】

角色名 │ 本场景总字数 │ 处于焦点区字数 │ 焦点占比 │ 存在感标记次数 │ 状态
──────┼────────────┼─────────────┼─────────┼─────────────┼─────
<角色甲>   │            │             │ ___%     │             │ ☑/☐
<配角乙>   │            │             │ ___%     │             │ ☑/☐
<角色乙>   │            │             │ ___%     │             │ ☑/☐
<配角甲>   │            │             │ ___%     │             │ ☑/☐

☐ 是否有人物在本场景中零出场字数？（被遗忘的角色）
☐ 是否有人物焦点占比>80%？（实际是单人场景而非群像）
☐ 是否有人物存在感标记=0？（出场了但读者完全感受不到他的存在）
```

## 二十六、死亡角色的持续影响：死后仍是故事的一部分

### 26.1 核心原则

**一个角色死后，不应该从故事中消失——而是从"行动者"转变为"影响者"。**

当前技能已有"通过缺失感写怀念"（写作参考十六·侧面描写），但这只是写法层面。还需要系统层面的追踪：已死角色在第N章是否仍有影响？影响是否在衰减？读者是否已经忘记了他？

### 26.2 死后影响的三种形态

```
═══════════════════════════════════════════
💀 死亡角色影响形态
═══════════════════════════════════════════

形态一：遗产型影响（最持久）
  角色留下的物品/功法/话语/规矩 → 在后续剧情中被继承或打破
  示例：师父死后，他的"剑不出鞘"规矩仍然被弟子遵守——直到第80章，
        弟子第一次在弟子面前拔剑，打破了师父的规矩。
  追踪：该物品/规矩最后一次被提及的章号 ____ 间隔 ____ 章

形态二：空缺型影响（中程衰减）
  角色生前占据的位置/关系 → 死后这个位置如何被填补（或故意不填）
  示例：师兄死后，他的工位一直空着——新人来了又走，没人能坐那个位置。
        直到某一天，新来的师弟无意中坐下来了，所有人都愣了一下。
  追踪：该位置/关系最后一次被提及的章号 ____ 间隔 ____ 章

形态三：回响型影响（间歇触发）
  角色生前的某句话/某个动作 → 在关键时刻被某个生者想起
  示例：第150章生死关头，主角突然想起师父说过"剑不是用来赢的"——
        那是第20章师父临死前说的。130章过去了，这句话还在。
  追踪：该回响距死亡章节的间隔 ____ 章，频次 ____ 次/100章
```

### 26.3 影响衰减与唤醒

```
【死后影响衰减规则】

死亡后章节数 │ 最低提及频次         │ 衰减处理
────────────┼───────────────────┼──────────
0-10章      │ 每3章≥1次         │ 密集影响期——读者还在悲痛中
11-30章     │ 每5章≥1次          │ 影响稳定期——偶尔提及
31-100章    │ 每15章≥1次         │ 影响稀释期——需要"唤醒事件"
100章+      │ 每30章≥1次 + 至少1次"唤醒事件" │ 沉睡期——需要重大事件重新激活

⚠ "唤醒事件" = 一个让所有角色（和读者）重新想起这个已死角色的场景
  → 可以是忌日/遗物被发现/有人问起/相似场景触发的闪回
  → 唤醒后，衰减周期重置（从"密集影响期"重新开始一轮）
```

### 26.4 死亡角色持续影响自检

```
【每卷结束·死亡角色影响度检查】

角色名 │ 死亡章号 │ 距当前卷的间隔 │ 上一卷提及次数 │ 影响形态 │ 是否触发唤醒
──────┼────────┼─────────────┼─────────────┼─────────┼──────────
______ │ 第__章  │ ___章       │ ___次        │ 遗产/空缺/回响│ ☐
______ │ 第__章  │ ___章       │ ___次        │ 遗产/空缺/回响│ ☐

☐ 是否有已死>30章的角色，上一卷提及次数=0？
   → 是 → 🟡中度违规：该角色已从读者记忆中消失，需要唤醒事件
☐ 每个已死角色是否分配了"唤醒事件"的触发章节？
   → 如果没有 → 在下一卷大纲中规划≥1个唤醒事件
```

## 模块 27：上帝视角因果交代

**核心用途**：写事件因果时——交代清楚前因后果但不过度解释，让读者自己理解"为什么发生"。

### 27.1 三层因果递进标准

| 层级 | 交代要求 | 写法 |
|------|---------|------|
| 直接因果（A→B） | 必须交代，不可跳过 | 事件B发生前必须有事件A的铺垫 |
| 间接因果（A→B→C） | 一句话或一个动作带过 | 不展开推演链，不写成说明文 |
| 深层因果（需要推理） | 给线索不给答案 | 把拼图摆桌上，读者自己拼 |

### 27.2 核心铁律

- **禁止**旁白过度解释角色动机（"他之所以这么做，是因为……"）
- **禁止**反转后用旁白补叙"其实之前早就暗示了"
- **一句话检验法**：删掉所有解释后，读者还能理解事件因果吗？→ 能=过 / 不能=补因果（补在动作/场景里）

### 27.3 质检标准

- 搜索"之所以""是因为""也就是说""其实"——标记旁白解释句
- 每个关键事件回溯前因：是否以动作/场景形式存在于前文（非旁白补叙）

> 详细规则与正反对照范例 → `references/urban-warfare-rules.md` §二

## 模块 28：情绪细节外化

**核心用途**：写人物情绪时——禁止标签式情绪词，用肢体语言+生理变化+行为细节写过程。

### 28.1 情绪三维度

| 维度 | ❌ 标签式（禁用） | ✅ 细节式 |
|------|-----------------|---------|
| 肢体语言 | "他紧张地握紧拳头" | "他把手插进裤兜，拇指在口袋布上搓了两下" |
| 生理变化 | "他害怕得浑身发抖" | "后背的汗顺着脊沟往下淌" |
| 行为细节 | "他愤怒地摔门而去" | "他一脚踢翻扳手箱，扳手哗啦啦滚了一地，没回头" |

### 28.2 情绪四铁律

**写过程不写结论 / 写变化不写状态 / 写具体不写抽象 / 写差异不写共性**

> ⚠️ **执行优先级**：情绪场景中 [28] 与 [14]（三维错位）有交叉路径。先按 [28] 约束写法（禁用标签词，用肢体/生理/行为写），写完后再按 [14] 检验是否有"思想≠行动"的落差。[28] 负责"怎么写"，[14] 负责"写完后有没有深度"——不要同时用两个规则反复检查同一段。

### 28.3 情绪标签词黑名单（出现即🟡）

`指尖发白 / 浑身发抖 / 面色苍白 / 咬牙切齿 / 怒目圆睁 / 心如刀绞 / 泪流满面 / 坐立不安 / 得意洋洋 / 万念俱灰`

### 28.4 7种核心情绪方向

害怕→退/手找东西/汗 | 愤怒→踢/砸/牙缝挤话 | 悲伤→蹲/叠了又拆/烟忘了抽 | 紧张→敲桌面/哑嗓子 | 得意→靠椅背/嘴角压不住 | 羞耻→低头/摸脖颈 | 绝望→往下滑/手慢慢松开

## 模块 29：冲突场景画面感

**核心用途**：写冲突/打斗时——五层搭建法+打斗写点不写面+旁观者纵深+镜头语言。

### 29.1 五层搭建

① 环境（空间/光线/声音/气味）→ ② 对峙（距离/姿态/眼神/手）→ ③ 递进（试探→施压→临界）→ ④ 周围人（后退/围观/喊叫/悄悄行动）→ ⑤ 爆发点

### 29.2 打斗五点必写（写"点"不写"面"）

**落点**（打在哪儿）/ **声音**（闷响/咔嚓/啪/当/噗）/ **即时反应**（眼前黑/腿软/弯下腰）/ **物理后果**（嘴角流血/牙松了/站不起来）/ **打人者的消耗**（指关节疼/胳膊酸/喘得比挨打的厉害）

### 29.3 镜头切换节奏

对峙：远→中→近·慢推 | 爆发：特写⇄近景·快切 | 收尾：近→中→远·慢拉

### 29.4 全流程模板

`平静 → 异样 → 对峙 → 爆发(5必写点) → 余波(环境变化+身体状态+旁观者)`

> 每阶段必写要素+质检标准 → `references/urban-warfare-rules.md` §四

## 模块 30：破折号解释禁令

**核心用途**：全文禁用破折号/冒号/括号加解释性文字——原因写进画面。

### 30.1 禁用句型

"——不是X，是Y" / "——是因为……" / "——也就是说……" / "——他心里清楚……" / "——尽管……"

### 30.2 合法用法（仅三种）

话被打断 / 场景切换 / 时间跳跃

### 30.3 修正原则
