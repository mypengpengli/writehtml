## 一、CK-1 修真/仙侠/玄幻常识

### CK-1.1 境界体系标准参考

| 境界层 | 通用名称 | 核心能力标志 | 寿命参考 | 写作要点 |
|--------|---------|-------------|---------|---------|
| 炼气期 | 引气入体/感气 | 感知灵气，百病不侵 | 120岁 | 不可离开地面飞行，最多轻身纵跃 |
| 筑基期 | 凝结道基 | 真元初成，可短暂御器飞行 | 200岁 | 御器飞行≠肉身飞行；筑基失败是常见桥段 |
| 金丹期 | 龙虎交汇 | 金丹大成，神识外放百丈 | 500岁 | "一粒金丹吞入腹，始知我命不由天"，金丹碎裂是常见破而后立桥段 |
| 元婴期 | 碎丹成婴 | 元婴可脱体遨游，瞬移短距 | 1000岁 | 元婴是第二生命——肉身毁则元婴逃，元婴散则神魂灭 |
| 化神期 | 天人合一 | 神识覆盖千里，掌控天地之力 | 3000岁 | 与天地灵气的"支配权"而非"借用权" |
| 合体期 | 返璞归元 | 元婴与肉身合二为一 | 5000岁 | 肉身即元婴，攻击=法术+物理双重伤害 |
| 大乘期 | 渡劫飞升 | 引天劫淬体，渡过则飞升 | 万载 | 天劫不是惩罚，是筛选——飞升失败≠死亡（可转散仙） |
| 散仙 | 天劫失败 | 肉身被毁、元婴重塑仙体 | 每千年一劫 | 一劫散仙→二劫→……→九劫散仙（九劫后真仙），多数小说到三劫足矣 |

**写作禁忌**：
- 筑基砍元婴——除非有逆天法宝或禁术代价，否则荒谬
- 炼气飞行——只能借法器短暂腾空，不能高空自由飞行
- 主角同阶无敌——可以，但必须给出合理原因（功法品级/战斗经验/体质特殊）

### CK-1.2 修炼元素速查

| 元素 | 功能定位 | 常见写法 |
|------|---------|---------|
| 灵气 | 修炼基础能源 | 浓度决定修炼速度；灵气稀薄区=凡人区，灵气浓郁区=宗门重地 |
| 灵石 | 交易货币+修炼资源 | 下品/中品/上品/极品，通常100:1递进 |
| 丹药 | 辅助突破/疗伤/临时增幅 | 品级对应境界（一阶丹药炼气用，二阶筑基用……）；丹毒=连续服用副作用 |
| 法器/法宝 | 战斗力加成 | 法器(筑基以下)→灵器(金丹)→法宝(元婴+)；本命法宝与主人神识绑定 |
| 功法 | 修炼速度+战斗技能 | 天地玄黄四阶最常见；功法品级决定同境界战力上限 |
| 禁术/秘术 | 代价型增幅 | 燃烧精血/寿元/修为——代价必须在下文兑现，不能"用了秘术、过两章没事了" |
| 血脉 | 天生优势 | 血脉浓度决定觉醒程度；血脉冲突=混血主角的经典冲突源 |

### CK-1.3 势力体系模板

```
宗门层级：外门弟子 → 内门弟子 → 核心弟子 → 真传弟子 → 长老(内门/外门/太上) → 宗主
家族层级：旁支 → 直系 → 嫡系 → 少主 → 家主 → 族老 → 老祖
散修路径：散修 → 加入宗门/建立势力/依附势力（散修必须有三者之一才有资源）
```

## 二、CK-2 古风/架空常识

### CK-2.1 中央官制速查（三省六部·以唐制为基础）

| 机构 | 长官 | 核心职能 | 写作要点 |
|------|------|---------|---------|
| 中书省 | 中书令 | 起草诏令（皇帝的笔） | 中书舍人具体执笔，中书令审核 |
| 门下省 | 侍中 | 审核诏令（皇帝的锁） | 有"封驳权"——觉得诏令不妥可退回、不盖章 |
| 尚书省 | 尚书令 | 执行诏令（皇帝的手） | 下辖六部；唐以后尚书令虚设，以左右仆射实际主持 |
| 吏部 | 吏部尚书 | 官员任免/考核/升降 | 四品以下吏部可自决，三品以上需皇帝钦点 |
| 户部 | 户部尚书 | 户籍/田赋/财政 | 管钱粮和人口统计，权力极大 |
| 礼部 | 礼部尚书 | 科举/祭祀/外交礼仪 | "清贵"衙门——权不大但地位高 |
| 兵部 | 兵部尚书 | 武官任免/军籍/兵器 | 有调兵权无统兵权（统兵权在将领手中） |
| 刑部 | 刑部尚书 | 司法审判/刑律 | 与大理寺、都察院合称"三法司"（三司会审） |
| 工部 | 工部尚书 | 水利/工程/屯田 | 管工程实操，技术人员多 |

**架空写作注意**：
- 架空朝代不必原样照搬，但必须逻辑自洽——行政机构的存在是为了"解决问题"
- 架空官制命名建议：避免直接用"尚书省"（太像唐），可用"政事堂/枢密院/内阁"等
- 架空朝代最关键：地方政府怎么管？——中央→州/府→县，中间层级决定行政效率

**写作场景指南**：
- **科考场景**：乡试考三场，每场三天，考生被锁在号舍（每人小隔间，宽约三尺深四尺，两块木板当桌/床），自带干粮蜡烛，臭号（靠近厕所的号舍）是惩罚
- **放榜场景**：乡试放榜叫"桂榜"（因八月桂花），会试放榜叫"杏榜"，殿试放榜叫"金榜"

- **连中三元**：解元+会元+状元（极罕见，历史上仅十余人）
- **落第桥段**：名落孙山（孙山是榜单最后一名，"名落孙山"=比最后一名还差）

### CK-2.3 古代军事/战争常识

**军队编制**（以宋明为参考）：
```
伍(5人) → 什(10人) → 队(50人) → 旅(100人) → 营(500人) → 军(2500人+)
百人将/千夫长/都统/将军 对应统领层级
```

**冷兵器战争写作原则**：
- **军队不会"冲上去就是一通乱砍"**——真实的古代战争靠阵型。阵型散了=败局已定
- **后勤决定上限**："兵马未动粮草先行"——一支万人军队日均消耗约30-50石粮草，运输损耗约60%（运100石到前线剩40石）
- **攻城战**：不是爬墙——是围城断粮（围点打援）。云梯攻城是最后手段，伤亡率极高
- **骑兵三用**：冲锋破阵/侧翼包抄/追击溃兵——骑兵不会正面撞击枪阵（马的直觉会绕开）
- **兵器常识**：
  - 长枪≠又长又重——实战枪长约2.5-4米，重量约3-5斤（极轻以便刺出收回）
  - 刀剑对决：刀劈砍、剑刺击——剑比刀更"贵族"，对使用者技术要求更高
  - 弓弩差异：弓→射速快/射程近(约100-150米)/需要长期训练；弩→射速慢/射程远(约200-300米)/平民可速成

**古代战争规模参考**：
- 村级械斗：数十到数百人
- 县级冲突：数百到一两千人
- 府级用兵：数千到万余人
- 国家级会战：数万到十余万人（超过20万的后勤几乎无法支撑）

### CK-2.4 古代经济/货币

| 货币 | 材质 | 购买力参考（以宋代为准） | 换算 |
|------|------|---------------------|------|

| 一两金 | 金 | 约合10两银 | ≈10000文 |

**日常物价参考**（以北宋中等城市）：
- 一碗面：5-10文 | 一斤猪肉：30-40文 | 一匹布：300-500文
- 一头牛：5-7两银 | 一匹马：20-50两银（战马更贵）

### CK-2.5 礼仪/称谓

**称谓之于身份**：
| 自称 | 对称 | 尊称 |
|------|------|------|
| 臣 | 陛下/皇上 | 皇帝自称"朕"（先秦普通人也可自称"朕"，秦以后专属皇帝） |
| 下官/卑职 | 大人 | 下级对上级 |
| 学生/晚生 | 先生/老师 | 学生对老师 |
| 草民/小人 | 老爷/大人 | 平民对官员 |
| 贫僧/小道 | 施主 | 出家人对俗人 |
| 妾身/奴家 | 夫君/官人 | 妻对夫 |

**写作禁忌**：
- 古风人物不要说"你好""谢谢""不客气""再见" —— 替换为"久仰""有劳""告辞"
- 平民对官员不能直呼其名，官员之间可以称字号
- 只有皇帝能用"朕"，亲王用"本王"，郡王用"本郡王"

### CK-2.6 古代律法/刑罚

**五刑**（以唐律为参考）：笞(竹板打)→杖(大板打)→徒(劳役)→流(流放)→死(绞/斩)

**常见罪与罚**：
| 罪行 | 刑罚 | 写作要点 |
|------|------|---------|
| 偷窃 | 笞/杖+赔偿 | 数额决定轻重；夜间行窃加重 |
| 伤人 | 杖/徒 | 使用凶器加重；以卑犯尊（下人伤主家）极重 |
| 杀人 | 绞/斩 | 故杀(蓄意)斩、斗杀(互殴致死)绞、误杀(过失)流 |
| 忤逆 | 死 | 十恶不赦之首，遇赦不赦 |
| 贪污 | 徒/流/死 | 金额决定刑罚等级 |

**架空写作提醒**：架空世界不需要复制古代律法，但律法的存在是世界观厚度的重要来源——主角不是因为"作者说了算"而逍遥法外，而是因为"实力碾压法度"或"钻了法条的空子"。

## 三、CK-3 历史架空类专项常识

### CK-3.1 各朝代行政区划速查

| 朝代 | 最高区划 | 中间层级 | 基层 | 写作要点 |
|------|---------|---------|------|---------|
| 秦汉 | 郡（36→100+郡） | 县 | 乡/亭/里 | 郡守权力极大（军政一把抓） |
| 隋唐 | 州（后改郡） | 县 | 乡/里 | 州之上设"道"（监察区，非行政区）；节度使辖区=实际地方权力中心 |
| 宋 | 路 | 府/州/军/监 | 县 | 路设四司分权（漕宪帅仓），防止地方坐大 |
| 元 | 行省 | 路→府/州 | 县 | 行省制鼻祖，"省"从此成为行政区划名 |
| 明 | 布政使司（省） | 府/直隶州 | 县 | 三司分权：布政(民政)/按察(司法)/都指挥(军事) |
| 清 | 省 | 府/直隶州/直隶厅 | 县/散州/散厅 | 总督管数省（正二品），巡抚管一省（从二品） |

### CK-3.2 古代建筑/城池常识

**城池结构**（从内到外）：
```
宫城（皇城核心）→ 内城（官署+权贵住宅）→ 外城（市井）→ 瓮城（城门外的半圆防御工事）→ 城外（附郭/农田）
```

**城池规模参考**：
| 等级 | 城墙周长 | 人口 | 门数 |
|------|---------|------|------|
| 京城 | 40-60里 | 50-100万+ | 9-13门 |
| 省城 | 20-30里 | 10-30万 | 4-8门 |
| 府城 | 10-15里 | 3-10万 | 4门 |
| 县城 | 5-10里 | 0.5-3万 | 2-4门 |

**城墙常识**：
- 城墙顶部宽约5-10米（可跑马），不是"站在狭窄墙头"
- 城门≠城楼——城楼是城门上方的建筑，用于瞭望和指挥
- 中国古代城门大多有瓮城（方形或半圆形的小城墙环绕城门，敌人冲入瓮城会被四面射杀）
- 城墙上的垛口（女墙）高约1.5-2米，每50-100米设一座敌台（马面）

### CK-3.3 古代交通/通讯

**陆路速度**：
| 方式 | 日行距离 | 适用场景 |
|------|---------|---------|
| 步行 | 30-50里 | 平民出行 |
| 骑马 | 100-200里 | 单人赶路；需换马（驿站制） |
| 马车 | 60-100里 | 载人/载货 |
| 急递（驿马接力） | 300-500里 | 八百里加急（理论极限，实际很难） |

**水路速度**：顺流约100-200里/日，逆流约30-60里/日，视水势而定。

**通讯方式**：
- 驿站（官方）：每30-50里一驿，分驿/站/铺三级；驿传=马递，步递=步行传递
- 信鸽（民间/军用）：约300-500里/日（飞直线距离而非道路距离）
- 烽火台（军用）：传递速度≈光速（但信息量极少，只传递"有敌情"的二进制信号）

## 四、CK-4 现代都市类常识（操作手册级）

### CK-4.1 公安系统架构

```
公安部
  ├── 省/自治区/直辖市公安厅（局）
  │     ├── 地级市公安局
  │     │     ├── 区/县公安（分）局
  │     │     │     ├── 公安派出所（基层，处理日常治安）
  │     │     │     ├── 刑侦大队/责任区刑警队（刑事案件）
  │     │     │     ├── 经侦大队（经济犯罪）
  │     │     │     ├── 禁毒大队
  │     │     │     ├── 网安大队（网络安全/网络犯罪）
  │     │     │     └── 治安大队（治安管理/特种行业/黄赌）
  │     │     ├── 交警支队（交通管理/交通事故）
  │     │     ├── 巡特警支队（巡逻防控/反恐防暴/重大活动安保）
  │     │     └── 出入境管理支队
  │     └── 直属单位（高速交警/机场公安/森林公安等）
  └── 直属机构（铁路/民航/海关缉私/长航公安等）
```

### CK-4.2 刑事 vs 治安案件区分（核心常识，写作必须准确）

| 维度 | 刑事案件 | 治安案件 |
|------|---------|---------|
| **管辖部门** | 刑侦大队/责任区刑警队 | 公安派出所/治安大队 |
| **法律依据** | 《刑法》《刑事诉讼法》 | 《治安管理处罚法》 |
| **立案标准** | 涉嫌犯罪（如盗窃数额≥3000元*） | 违法行为但未达到刑事追诉标准 |
| **处理程序** | 立案→侦查（讯问/搜查/逮捕）→移送检察院→公诉 | 受理→调查取证→行政处罚（罚款/拘留） |
| **强制措施** | 拘传/取保候审/监视居住/刑事拘留/逮捕 | 无（只能传唤，最长24小时） |
| **记录性质** | 刑事犯罪记录（案底） | 违法记录（非刑事案底，但对某些行业有影响） |

> *盗窃罪数额标准因省份而异，3000元为多数省份的"数额较大"起点。更高档为"数额巨大"(约3-10万元)和"数额特别巨大"(约30-50万+)。

**写作关键区分——这些话不能混用**：
- ❌ "派出所刑警" —— 派出所管治安，刑警队在分局/县局层面
- ✅ "派出所民警将案件移交分局刑侦大队"
- ❌ "治安拘留15天" —— 合并执行最长20天（《治安管理处罚法》第16条）
- ✅ 正确表述："因寻衅滋事被行政拘留十日"
- ❌ "逮捕令" —— 中国法律体系是《逮捕证》（批准逮捕）而非"令"
- ✅ "经人民检察院批准，签发逮捕证"

### CK-4.3 各警种职能边界（写作正确分工）

| 警种 | 管什么 | 不管什么 | 典型触发场景 |
|------|--------|---------|------------|
| **派出所民警** | 治安纠纷/邻里矛盾/打架斗殴/小偷小摸/户籍管理/110接处警 | 杀人/抢劫等重大刑事案件（需移交刑警） | 主角报警后第一个到达现场 |
| **刑警**（刑事侦查） | 杀人/抢劫/强奸/绑架/放火/投毒/重大盗窃等八类严重犯罪 | 经济犯罪(经侦)/毒品(禁毒)/网络犯罪(网安)/交通事故(交警) | 命案现场：法医+技术中队+侦查员 |
| **经侦**（经济犯罪侦查） | 金融诈骗/非法集资/职务侵占/挪用资金/合同诈骗/传销 | 暴力犯罪(刑警)/毒品(禁毒) | 主角的商业对手用空壳公司诈骗→经侦立案 |
| **禁毒** | 毒品制造/贩卖/运输/种植/吸毒 | 其他犯罪(除非与毒品交叉) | 主角意外接触到毒品交易链条 |
| **网安**（网络警察） | 网络诈骗/黑客攻击/侵犯个人信息/网络赌博/传播淫秽物品 | 实体犯罪(除非有网络证据链) | 主角的信息在网上被盗用→网安介入 |
| **交警** | 交通秩序/交通事故/酒驾/醉驾/车辆管理 | 利用车辆实施的故意犯罪(如故意驾车撞人→移交刑警) | 车祸场景；醉驾入刑（《刑法》第133条之一） |
| **巡特警** | 街面巡逻/反恐防暴/劫持人质/重大活动安保 | 一般刑事案件(巡逻中发现移交刑警) | 主角在街上遇到突发暴力事件，特警持枪到场 |
| **治安大队** | 黄赌毒(治安层面)/特种行业(旅馆/典当/刻章/旧货)/枪爆危险品 | 刑事层面黄赌毒(移交刑警或禁毒) | 主角的KTV/网吧被查→治安大队管辖 |

### CK-4.4 刑事案件标准流程（从接报到移送）

```
① 接处警（110或派出所接报）
   ↓
② 案件初查（确定是否构成犯罪，是否达到立案标准）
   ├─ 不够立案 → 治安案件处理或告知自诉
   └─ 应当立案 → 呈请立案报告书
   ↓
③ 立案侦查
   ├─ 现场勘查（技术中队：拍照/提取指纹/DNA/足迹/痕迹）
   ├─ 调查访问（询问证人/受害人）—— 注意：对犯罪嫌疑人用"讯问"，对证人/受害人用"询问"
   ├─ 调取监控/通讯记录/银行流水/网络数据
   ├─ 技术鉴定（法医/痕迹/文检/电子数据/毒化/DNA）
   └─ 采取强制措施：
       · 拘传（强制到案，最长12小时→可延长至24小时）
       · 取保候审（缴纳保证金或保证人担保，最长12个月）
       · 监视居住（指定居所，最长6个月）
       · 刑事拘留（关押在看守所，最长30天+检察院审查批捕7天=37天）
       · 逮捕（检察院批准后，羁押期限=侦查2个月+可延长）
   ↓
④ 侦查终结 → 移送检察院（制作起诉意见书）
   ↓
⑤ 检察院审查起诉 → 向法院提起公诉 或 不起诉/退回补充侦查
   ↓
⑥ 法院审判（一审→可能的二审→死刑复核）
```

**写作场景常见错误**：
- ❌ 警察当场就把人"逮捕"了 —— 应该是"刑事拘留"，逮捕需检察院批准，不可能当场
- ❌ "关监狱" —— 未判决前关"看守所"，判决后送"监狱"
- ❌ 派出所一夜之间破了杀人案 —— 命案由分局/市局刑侦大队处理，派出所只负责保护现场和前期访问
- ✅ 正确流程：派出所接报→保护现场→上报分局→刑侦大队到场→成立专案组→技术中队勘查→摸排走访→锁定嫌疑人→传唤/拘传→讯问→刑事拘留→提请批捕

### CK-4.5 常见法律条文引用速查

| 场景 | 引用法律 | 关键条款 | 引用格式示例 |
|------|---------|---------|------------|
| 故意杀人 | 《中华人民共和国刑法》第232条 | 故意杀人的，处死刑、无期徒刑或者十年以上有期徒刑 | "依据刑法第二百三十二条"（正文中不用阿拉伯数字编号） |
| 故意伤害 | 刑法第234条 | 轻伤三年以下/重伤三至十年/致死十年以上至死刑 | "涉嫌故意伤害罪" |
| 盗窃 | 刑法第264条 | 数额较大三年以下/数额巨大三至十年/特别巨大十年以上至无期 | 注意：入户盗窃/扒窃/携带凶器盗窃不论数额均构罪 |
| 抢劫 | 刑法第263条 | 三年以上十年以下；入户/公交/银行/多次/数额巨大/致伤亡等→十年以上至死刑 | 抢劫罪起刑点高于盗窃，且八种加重情节 |
| 强奸 | 刑法第236条 | 三年以上十年以下；情节恶劣/多人/公共场所/轮奸/致重伤→十年以上至死刑 | 注意：奸淫不满十四周岁幼女以强奸论，从重处罚 |
| 诈骗 | 刑法第266条 | 数额较大三年以下/数额巨大三至十年/特别巨大十年以上至无期 | 电信诈骗可跨省并案（犯罪地/嫌疑人居住地/被害人所在地均可管辖） |
| 交通肇事 | 刑法第133条 | 致重伤/死亡/重大财产损失→三年以下；逃逸/情节恶劣→三至七年；逃逸致死→七年以上 | 区分"交通肇事罪"（过失）与"以危险方法危害公共安全罪"（故意） |
| 寻衅滋事 | 刑法第293条 | 随意殴打/追逐拦截/强拿硬要/公共场所起哄闹事→五年以下；纠集他人多次→五至十年 | 轻微寻衅滋事走治安处罚（《治安管理处罚法》第26条） |
| 正当防卫 | 刑法第20条 | 不负刑事责任；明显超过必要限度→应当减轻或免除 | 2018年后司法解释明确：不能苛求防卫人"理性人标准" |
| 传唤 | 《刑事诉讼法》第119条 | 传唤/拘传最长12小时；案情特别重大复杂→可延长至24小时 | 不得以连续传唤变相拘禁 |
| 搜查 | 《刑事诉讼法》第138条 | 须出示搜查证；紧急情况（逮捕/拘留时）可无证搜查 | 搜查妇女身体应由女工作人员进行 |

**写作提示**：正文中引用法律条文时，用"刑法第XX条"而非"《刑法》第XX条"（对话中可省略书名号）。非法律专业人士（如普通民警）对话中不会逐条引用法条，而是说"这涉嫌XX罪"——只有检察官/法官/律师发言才可能精确引用条文。

### CK-4.6 执法场景专业术语

| 正确术语 | 含义 | 常见误用 |
|---------|------|---------|
| 讯问 | 对犯罪嫌疑人提问 | 不可对证人说"讯问"——证人是"询问" |
| 询问 | 对证人/受害人提问 | 不可对犯罪嫌疑人说"询问" |
| 刑事拘留 | 侦查阶段对现行犯/重大嫌疑分子的临时羁押 | ≠逮捕（逮捕需检察院批准） |
| 逮捕 | 检察院批准或法院决定的长期羁押 | ≠拘留；不可能"当场逮捕" |
| 传唤 | 要求当事人到指定地点接受调查（非强制） | ≠拘传（拘传可强制到案） |
| 拘传 | 强制犯罪嫌疑人到案接受讯问 | ≠传唤；拘传可使用戒具 |
| 取保候审 | 缴纳保证金/提供保证人后，嫌疑人在外等待审判 | 严重暴力犯罪/累犯/流窜作案者不适用 |
| 监视居住 | 在指定居所接受监视（适用于不宜关押的特殊情况） | 电子脚环/禁止会客/禁止通信等辅助措施 |
| 立案 | 正式启动刑事侦查程序 | ≠"把案子立起来"——立案需要"认为有犯罪事实需要追究刑事责任" |
| 前科 | 曾经被判处有期徒刑以上刑罚的记录 | ≠违法记录（行政拘留不产生前科） |
| 案底 | 泛指违法犯罪记录（非法律术语，日常用语） | 口语可用，正式文书中用"犯罪记录"或"违法记录" |

### CK-4.7 审讯室/讯问场景写作（讯问笔录模板）

**场景要素**：
- 时间：讯问一般不超过12小时（第119条），延长需批准
- 人数：讯问人员不少于2人（侦查人员）
- 全程录音录像——这是近年来的硬性规定（对可能判处无期/死刑的案件和其他重大犯罪案件必须录）
- 如实供述可从宽处理——告知"如实供述自己罪行可以从宽处理"是告知书上的固定表述

**典型的讯问笔录开头**：
```
问：我们是XX市公安局XX分局的民警（出示证件），现依法对你进行讯问。你应当如实回答我们的提问。对与案件无关的问题，你有拒绝回答的权利。你听清楚了吗？
答：听清楚了。
问：根据规定，本次讯问将全程同步录音录像，你是否清楚？
答：清楚。
问：你的基本情况（姓名/年龄/身份证号码/职业/住址/家庭成员）？
答：……
问：你以前是否受过刑事处罚或行政处罚？
答：……
```

### CK-4.9 医疗场景常识

**医院等级**：三甲（最高）→三乙→二甲→二乙→一甲→一乙→社区服务中心

**急诊场景**：
- 急救车上有急救医生+护士+司机（三人标配），不是"只有一个司机"
- 送达后流程：急诊分诊(红黄绿三级)→抢救室(红色)/观察室/普通诊室→专科会诊→办理住院或离院
- 手术前必须签署《手术知情同意书》（本人或授权亲属）
- CPR(心肺复苏)的正确描述：胸外按压深度5-6cm，频率100-120次/分钟，按压通气比30:2

**常见医疗错误（写作必须避免）**：
- ❌ "输血需要血型匹配后就能直接输" —— 还需交叉配血、感染筛查（HIV/乙肝/梅毒等）
- ❌ "手术后醒来的第一句话" —— 全麻苏醒过程是渐进的（麻醉恢复室观察到真正清醒），不是"睁开眼就能清晰对答"
- ❌ 医生给家人透露病人隐私 —— 违反《医师法》和医院规定（除非病人书面授权）

### CK-5.2 各平台禁忌清单

**飞芦**：
- 开局超过500字未出现冲突或悬念 → 读者大概率划走
- "女性角色被降智/物化/工具化" → 被举报概率极高
- 虐主开头（主角被长期欺压才翻身） → 不适合，飞芦读者要"第一页就有快感"

**番茄**：
- 免费转付费节点选择不当（过早→广告收益未最大化，过晚→读者流失）
- 章节末尾没有"下一章更精彩"式强钩子 → 次留率下降
- 黄金法则：前30章是"试吃期"，必须让读者养成阅读习惯

**起点**：
- 开篇灌水（前三章还在介绍世界观） → 被骂"水"并掉收藏
- 境界体系/金手指逻辑不自洽 → 评论区会有人截图打脸
- 更新不稳定 → 掉月票榜=掉自然流量=恶性循环

## 六、CK-6 各题材读者默认期待

### CK-6.1 题材×读者默认接受度

| 题材 | 读者默认接受 | 读者默认拒绝 | 概率较高的差评点 |

| **重生/穿越** | 主角有前世知识优势；知道未来走向 | 主角"全知全能"毫无弱点；前世记忆想不起来就不想起来 | 主角太顺→无聊；感情线太多→烦 |
| **系统流** | 系统面板/任务/奖励/属性面板 | 系统动不动就"叮"；系统无来由无逻辑 | 系统成"亲爹"（要啥给啥） |
| **废柴逆袭** | 开篇被轻视→缓慢成长→逆袭 | 被欺负了一百章还在隐忍 | "憋屈型爽文"——爽点密度不够 |
| **都市异能** | 普通人意外获得异能→适应→崛起 | 获得异能后仍处处受限/畏首畏尾 | "有异能还这么怂" |
| **仙侠/玄幻** | 境界体系/法宝/丹药/宗门 | 境界混乱（筑基虐元婴） | 实力体系不严谨 |
| **悬疑/推理** | 线索逐步释放/推理过程合理 | 主角用上帝视角"猜到"而不是"推理出" | 结尾随便找个凶手→烂尾 |
| **言情** | 主角有成长弧/情感发展有过程 | "一见钟情然后马上生死相许" | 人设扁平/感情线生硬 |
| **历史架空** | 穿越者有现代知识优势 | 穿越者一夜之间改变整个时代 | 历史背景不严谨（唐穿宋官制） |

### CK-6.2 读者默认认知规律

- **力量必须付出代价**：不管金手指多强，读者会问"代价是什么"——有代价=真实，没代价=开挂
- **敌人必须聪明**：反派智商在线的正面效果远大于"反派弱显得主角强"的负面效果
- **配角必须有自己的人生**：配角不是主角的影子——他们有自己的欲望/恐惧/局限
- **规则必须一致**：如果一个设定（如"金丹期不能越级打元婴"）在前50章被严格遵守，第51章主角突然越级——读者会觉得"作者违背了自己的设定"（这比违反真实物理定律更让读者愤怒）

## 七、CK-7 常见世界观参数速查

| 参数 | 参考值 | 写作注意 |
|------|--------|---------|
| 古代城池面积 | 县城约1-3平方公里，府城约3-8平方公里，省城约8-20平方公里 | 不要出现"县城百万人口"——古代县级城市通常1-3万人 |
| 古代行军速度 | 步兵日约30-40公里（轻装）/20-25公里（重装），骑兵约60-80公里 | 翻山/渡河/雨中行军大幅减速 |
| 一里=？ | 古代一里约500米（步：1步=5尺≈1.5米，300步=1里≈500米） | 不要混用现代化"公里"——古风用"里"，不必精确转换为公里 |
| 兵器重量 | 实战刀约1-2公斤，长枪约2-3公斤，环首刀约1公斤 | 不要出现"80斤青龙偃月刀"——那是仪仗器不是兵器 |
| 弓箭射程 | 有效杀伤约80-120米，最大射程约200-300米 | 不要出现"一箭射穿500米外的敌人" |
| 古代房屋 | 百姓住房：土墙+茅草顶；小康：砖墙+瓦顶；权贵：青砖+斗拱+高台基 | "穿越主角一眼就能造出玻璃/水泥"需要合理的知识储备 |
| 古代照明 | 油灯（豆油/菜油，光亮极暗）、蜡烛（较贵）、火把（室外/行军） | 室内照明很暗——古代夜晚的活动空间极其有限 |
| 古风时间 | 十二时辰（子丑寅卯辰巳午未申酉戌亥），子时=23:00-01:00 | 正文禁止"第三个时辰"式表述，用天色/节气/时辰名称 |
| 信鸽速度 | 约60-100公里/小时（飞直线），可传递极简信息（寸纸数语） | 信鸽是单程的——放飞后回巢，不能"A→B→C"接力 |
| 马匹寿命 | 约20-30年，服役年龄约3-15岁 | 长途骑行一天后马匹必须休息——否则会累死 |

## 八、CK-8 通用写作硬规则（因果/情绪/冲突/破折号）

> 来源：`references/writing-style-reference.md` 模块 27-30 + `references/urban-warfare-rules.md`（完整规则与范例，354 行）
> **适用于所有题材**——不是都市专属。4 条硬规则 + 7 种情绪细节表 + 冲突五层搭建法 + 打斗五点细节 + 镜头语言五法。
> 以下为 CK 编号索引。详细规则查阅 urban-warfare-rules.md，核心摘要见 writing-style-reference.md 模块 27-30。

### CK-8.1 上帝视角因果交代（规则A）
- **三层因果递进**：直接因果必须交代 → 间接因果一句话带过 → 深层因果给线索不给答案
- **核心检验**：关掉解释，读者还能不能自己理解为什么发生？
- **易犯错误**：旁白过度解释角色动机（"他之所以这么做，是因为……"）→ 用行动替代旁白解释

### CK-8.2 情绪细节外化（规则B）
- **三维度替代标签**：肢体语言（不自主的身体动作）+ 生理变化（心跳/呼吸/出汗/体温）+ 行为细节（具体做了什么、怎么做、与平时有什么差异）
- **情绪四铁律**：写过程不写结论 → 写变化不写状态 → 写具体不写抽象 → 写差异不写共性
- **7 种核心情绪**（害怕/愤怒/悲伤/紧张/得意/羞耻/绝望）各有禁用标签 + 可用细节参照表
- **关键禁忌**："指尖发白/浑身发抖/怒目圆睁/咬牙切齿/泪流满面"等标签式表达 → 🟡违规

### CK-8.3 冲突场景画面感（规则C）
- **五层搭建法**：① 环境（空间/光线/声音/气味）→ ② 对峙双方（距离/姿态/眼神/手的动作）→ ③ 紧张递进（试探→施压→临界）→ ④ 周围人（后退/围观/喊叫/悄悄行动四种反应）→ ⑤ 爆发点（不可逆的瞬间）
- **打斗写"点"不写"面"**：打击落点 / 打击声音（闷响/咔嚓/啪/当/噗）/ 被打者即时反应 / 物理后果 / 打人者的消耗 → 5 必写
- **五种镜头**：远/中/近/特写/慢镜头，对峙期慢推，爆发期快切，收尾期慢拉
- **冲突全流程模板**：平静 → 异样 → 对峙 → 爆发 → 余波（每阶段有必写要素 + 质检标准）

### CK-8.4 破折号解释禁令（规则D）
- **禁用**：破折号/冒号/括号后加解释性文字（"——不是X，是Y""——是因为""——也就是说""——他心里清楚"等）
- **合法用法仅限**：话被打断 / 场景切换 / 时间跳跃
- **核心原则**：读者能从画面自己得出的结论，不需要作者跳出来解释
- **修复方向**：删掉解释后如果读者得不出结论 → 补画面，不补解释

#### 题材例外与边界（v2.1.0 P1 #6 修复引入）

> 本节为 P1 #6 修复引入——CK-8.4 通用化后，古典/严肃题材文风可能误伤。需要给出例外。

```
按题材分级：

  全严格遵循（推荐适用）：
    ✓ 现代都市 / 战神 / 赘婿 / 系统流 / 爽文
    ✓ 现代悬疑 / 刑侦 / 科幻未来 / 异能
    → 完全禁用：破折号后加任何解释性文字

  允许有限放宽（古典/严肃题材文风默许）：
    ⚠ 古风仙侠 / 历史架空 / 古典文学向
    → 允许场景：
      ① "道号——XXX" 式道号解释破折号
      ② "凡此种种——皆因朝局动荡" 式文白间杂补充
      ③ "张明——本市某银行副行长" 式人物身份补充
      ④ 严肃文学/汪曾祺式文风中"破折号+补充说明"
    → 仍禁止：
      ❌ "——不是X，是Y" 式直接解释
      ❌ "——因为他心里清楚" 式心理补充
      ❌ "——也就是说" 式抽象概括

  谢晚执行判断：
    在写作当前章之前，若 Chapter-题材标签属于"古风/架空/古典"，
    自动放宽 CK-8.4 第①②③④项，仅保留 ❌ 三条铁律禁令。
    否则按全严格模式执行。
```
