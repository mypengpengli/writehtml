# 沉浸式预演模型（IPS）—— 写作执行师进阶训练手册

> 版本：v1.0 | 配套：网文创作工坊 v2.6.0
> 用途：在动笔前，帮助写作执行师完成从"技法合规者"到"角色附体者"的心智切换。

---

## 一、为什么要做 IPS？（解决了什么问题）

| 常见问题（AI味来源） | IPS 解决机制 |
|-------------------|------------|
| 文字概括抽象（"他很生气"） | **①角色附体** + **⑤感官锚点** → 输出具体身体感受 |
| 冲突像走流程，没有纠结感 | **②冲突加压测试** → 强制寻找"两个烂选项" |
| 逻辑有漏洞，写到后面才发现 | **③魔鬼代言人** → 动笔前自检，防错前置 |
| 对话准确但无趣，像说明书 | **④潜台词测绘** → 写出"说≠想"的张力 |
| 读者觉得角色是纸片人 | **全部五步** → 读者感到"我认识这种人" |

---

## 二、IPS 五步法详细教程（含正反范例）

### 第一步：角色附体（Inside-Out Acting）

**核心问题**：如果我是 TA，此刻我的身体在告诉我什么？

| ❌ 外部标签（AI写法） | ✅ 内部感受（IPS写法） |
|---------------------|---------------------|
| 主角很焦虑，担心被催债。 | 右眼皮跳了一上午。手机第三次响了，他没接。胃里像塞了块石头，早饭扒了两口就搁下了。 |
| 反派很得意，觉得胜券在握。 | 他靠在椅背上，手里的笔转了三圈。对面那个家伙越是镇定，他就越想笑——这局棋，对方输定了。 |

**写作执行师填表模板**：
```markdown
【角色附体笔记 · 本章】
（主角 + 至少 1 名对手/关键配角，各填一段）

▶ 角色 A（主角）：______
- 身体信号：______（如：右肩旧伤在阴天隐隐发酸）
- 微小欲望：______（如：想找个没人的地方坐五分钟）
- 回避之物：______（如：不想看手机，怕看到那个人的消息）

▶ 角色 B（对手/关键配角）：______
- 身体信号：______
- 微小欲望：______
- 回避之物：______
```

---

### 第二步：冲突加压测试（Tension Architecture）

**核心问题**：如果我是 TA，这个冲突凭什么让我睡不着？我为什么不能"干脆解决"？

| ❌ 走流程式冲突（AI写法） | ✅ 两个烂选项（IPS写法） |
|---------------------|---------------------|
| 坏人要抢主角的钱，主角决定反抗。 | 不还钱，<配角乙>的店会被搬空；还钱，得把母亲最后的棺材本掏出来。两条路都通向失去。 |
| 主角和男友吵架，最后和好了。 | 揭穿他的谎，这段关系就完了；不揭穿，她得每天盯着他删聊天记录。和好只是暂时的假象。 |

**写作执行师填表模板**：
```markdown
【冲突加压笔记 · 本章】
核心冲突：______
- Lv.1 不解决，今天会怎样？______（短期后果）
- Lv.2 粗暴解决，会失去什么？______（代价）
- Lv.3 回避它，3天后会怎样？______（中期后果）
- Lv.4 冲突失控，谁第一个被牺牲？______（人际成本）
👉 若找不到"两个都不好的选项" → 🟡 回退韩宇推演层
```

---

### 第三步：逻辑漏洞预演（Devil's Advocate）

**核心问题**：最刁钻的读者会怎么挑这一章的刺？我答得上来吗？

| ❌ 写完才发现（AI写法） | ✅ 动笔前自检（IPS写法） |
|---------------------|---------------------|
| 写到第 15 章才想起：他明明不会游泳，怎么从第 3 章的河里爬出来了？ | 动笔前就列出：他不会游泳 → 第 3 章落水必须有人拉，否则逻辑崩。先补设定再写。 |
| 读者问"他为什么要信那个陌生人"，作者答不上来。 | 预演时自问"动机是否成立"，给出"陌生人救过他弟弟"作铺垫，落笔前埋好。 |

**写作执行师填表模板**：
```markdown
【逻辑预演笔记 · 本章】
以"最刁钻读者"身份提 3 个质疑，并自答：
1. 动机质疑：______ → 解答：______
2. 因果质疑：______ → 解答：______
3. 时空质疑：______ → 解答：______
👉 任一质疑无法合理解答 → 主动触发 🟡 回退
```

---

### 第四步：对话潜台词测绘（Subtext Mapping）

**核心问题**：角色嘴上说的，和心里想的，差了几层？

| ❌ 说明书式对话（AI写法） | ✅ 说≠想（IPS写法） |
|---------------------|---------------------|
| "你把钱还给我，不然我就报警。" | "钱的事……我们能不能再谈谈？"（真实意图：怕撕破脸后查不出钱去哪了；在回避：其实她更怕失去这段关系） |
| "我不喜欢你这样做。" | "你这样做，挺聪明的。"（真实意图：讽刺+划清界限；在回避：不想承认自己嫉妒） |

**写作执行师填表模板**：
```markdown
【潜台词地图 · 本章】（选 1-2 个关键对话场景）
场景：______
- 角色 A 说：______ → 真实意图：______ / 在回避：______
- 角色 B 说：______ → 真实意图：______ / 在回避：______
👉 若本章所有对话均无"说≠想"落差 → 🟡 中度违规
```

---

### 第五步：感官锚点定标（Sensory Anchoring）

**核心问题**：读者闭上眼，能"看见/听见/摸到"这一章吗？

| ❌ 抽象形容（AI写法） | ✅ 具体感官锚点（IPS写法） |
|---------------------|---------------------|
| 气氛很紧张，他很害怕。 | 谁都没说话。风扇吱呀呀地转，叶片的阴影在墙上一下一下地扫。他后背贴着墙，凉意透过衬衫渗进来。 |
| 场面很热闹，大家很开心。 | 油锅里吱啦一声，糖醋味呛得人睁不开眼。有人笑呛了，拍着桌子咳嗽，筷子掉在地上当啷响。 |

**写作执行师填表模板**：
```markdown
【感官锚点清单 · 本章】（≥3 个，标注功能）
1. [视觉/听觉/触觉/嗅觉/味觉] ______ → 功能：______（如：交代环境/烘托情绪/暗示伏笔）
2. [感官] ______ → 功能：______
3. [感官] ______ → 功能：______
👉 少于 3 个或全为抽象形容 → 🟢 轻度违规，补足后再交付
```

---

## 附：预演完成自查（进入层级二前必过）

- [ ] ①角色附体：主角 + ≥1 对手/配角 均已写内心独白（身体信号 / 微小欲望 / 回避之物）
- [ ] ②冲突加压：4 级成本阶梯全部回答，且确认存在"两个都不好的选项"
- [ ] ③逻辑预演：3 个质疑均有合理解答（无 🟡 回退未闭环）
- [ ] ④潜台词：≥1 个关键对话已画出"说≠想"地图
- [ ] ⑤感官定标：≥3 个具体感官锚点已标注功能

> 任一项未满足 → 禁止进入「层级二 · 场景淬炼」（详见 `writing-methodology-guide.md` §二）
