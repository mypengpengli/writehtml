# 网文写作方法论完整指南（v2.8.0）

> 配套：网文创作工坊 v2.8.0 | 适用角色：写作执行师（谢晚）


## 一、IPS 沉浸式预演（写前）

*详细内容见 `ips-training-model.md`，本节仅作纲要引用。*

| 步骤 | 名称 | 核心产出 | 时长 |
|------|------|---------|------|
| ① | 角色附体 | 每核心角色 50-80 字内心独白 | 2min |
| ② | 冲突加压 | 4 级成本阶梯完整回答 | 1.5min |
| ③ | 逻辑预演 | 3 个质疑 + 合理解答 | 1.5min |

| ⑤ | 感官定标 | ≥3 个具体感官锚点 | 1min |


## 二、场景淬炼（写中）

### 2.1 淬炼三问详细指南

#### 问题一："这个场景读者为什么要看完？"

| 答案类型 | 合格？ | 说明 |
|---------|:-----:|------|
| "因为发生了XXX" | ✅ | 有事件推进 |
| "因为角色关系变了" | ✅ | 有人物变化 |
| "因为揭开了一个信息" | ✅ | 有信息释放 |
| "因为很爽/很好哭" | ✅ | 有情绪价值 |
| "因为要过渡到下一章" | ❌ | 过渡本身不是理由——过渡中必须嵌入上述至少 1 项价值 |

#### 问题二："删掉最后一句，场景还剩什么？"

- 如果删掉最后一句后，场景仍然完整 → 出口钩子太弱 → 补一句有悬念/有余味的收尾
- 如果删掉后场景不完整 → 说明最后一句是关键信息，保留

#### 问题三："换一个角色来演，会不会一模一样？"

- 会 → 角色缺乏独特性 → 给角色增加一个"只有 TA 才有的反应"
  - 示例：同样的被质问场景——
    - <角色甲>会沉默，手指在桌面敲
    - <角色乙>会反问，用问题回答问题
    - <配角乙>会拍桌子，嗓门提高八度

### 2.2 场景信息四层递进范例

**原场景（只有一层·事实）**：
> <角色甲>接到电话。对方让他三天内还钱。

**四层递进后**：
> 【一层·事实】手机响了。来电显示是陌生号码。
> 【二层·情绪】他盯着屏幕看了五秒，拇指悬在接听键上，没按下去。胃里像塞了块冰。
> 【三层·关系】这个号码他认识——五年前借他钱的那个人。那个人的声音，他忘不了。
> 【四层·走向】"三天。"对方说，"三天后我去找<配角乙>。"
> <角色甲>攥着手机的手在抖。不是因为怕，是因为他知道——<配角乙>的店，是他唯一不能连累的人。

### 2.3 感官替换对照表

| 抽象写法 | 感官替换 |
|---------|---------|
| 他感到害怕 | 他后背贴着墙，凉意透过衬衫渗进来，他不敢回头。 |
| 她很生气 | 她把杯子往桌上一顿，水溅出来，她没擦。 |
| 空气很紧张 | 谁都没说话。风扇吱呀呀地转，叶片的阴影在墙上一下一下地扫。 |
| 他很疲惫 | 他坐下的时候，腰是慢慢弯下去的，像一节一节折起来的。 |
| 她很难过 | 她没哭。眼睛红了，眨了两次，又忍回去了。 |


## 三、迭代自检（写后）

### 3.1 迭代七问完整模板

```markdown
【本章迭代自检 · 第X章】

□ 1. 本章的开头 200 字和结尾 100 字，是否值得被截图分享？
   → 截图金句：______（若无则补）
□ 2. 本章读者的情绪被调动了几次？
   → 情绪锚点 1：______（第__段）
   → 情绪锚点 2：______（第__段）
   → 少于 2 次则需增加
□ 3. 本章有没有"读者可以跳过不读"的段落？
   → 可删段落：______（删除/压缩）
□ 4. 本章的角色有没有"只有 TA 才会说的话/做的事"？
   → 独特表现：______（若无则补）
□ 5. 本章的对话去掉"说"字后，还能分清谁在说话吗？
   → □ 能 □ 不能（需重写部分对话）
□ 6. 本章结束后，读者对"接下来会发生什么"有期待吗？
   → 出口钩子：______（若弱则补）
□ 7. 如果我是读者，合上屏幕后我能记住一个画面吗？
   → 定义性画面：______（若无则补）
```

### 3.2 三遍检索操作细则

**第一遍：抽象词替换**

搜索关键词：很、非常、特别、十分、极度

每找到一处，检查后面的形容词是否有具体替代方案

有 → 替换；无 → 保留（但每章不超过 3 处）

**第二遍：冗余删除**

逐段问："删掉这句，读者会失去什么？"

答案 = "什么都不会失去" → 整句删除

答案 = "会失去一个信息/一个情绪/一个人物侧面" → 保留

**第三遍：对话润色**

每段对话朗读一遍（模拟角色语气）

标记所有"不像人会说的话" → 修改为口语

特别关注：句末助词（啊/吧/吗/呢）、句首语助词（哎/嘿/啧/哼）、打断与停顿


## 四、与现有写作体系的协同关系

- **14×26 技法路由表（能力二）**：IPS 预演与场景淬炼不替代路由表，而是在其外层做"写前定调 / 写中打磨"。每层产出的结论（角色身体状态、冲突成本阶梯、潜台词地图、感官锚点）应作为路由调度的输入。
- **独立价值测试（能力三）**：迭代七问是独立价值测试的增强版——独立价值测试查"有没有价值"，迭代七问查"价值是否到位、是否可记忆"。
- **5 张附表（附A-E）**：IPS 预演产出的"冲突成本阶梯 / 潜台词地图"可回写附B1 知情矩阵与附C 承诺，保证预演结论进入主线追踪。
- **改稿公式（能力五）**：三遍检索的第二遍（冗余删除）即改稿公式的落地操作；第一遍（抽象词替换）补足"去 AI 味"。

## 五、叙事结构显影规则（v2.8.0 新增 · 强制项）

> 背景：第01章实战暴露两类读者错觉——
> 📌 **范例约定（v2.9.1）**：本节反例/正例使用**虚构演示角色**（老周/钱某/沈某/某地产等），角色名已通用化、不指向任何真实项目；规则本身全题材通用，新项目以本项目角色代入理解。①跨场景并行剪切（平行蒙太奇）时间锚点打架，读者感知时间被拽回数小时；②多线/双渠道并行时线间无交代，读者把两条线误认成一条，重建出矛盾模型。本规则为强制项，写作时逐条自查，质检卡 #14/#15 对应对账。

### 规则一 · 跨场景时序锚点一致（对应质检卡 #14）

**铁律**：任何平行剪切/跨场景切换，每个场景必须有明确时间锚点；锚点与场景内全部时间性细节（台词、环境光、物件连续性）必须互相印证，不允许互相矛盾。

**判定三步**：
1. 标锚点：本场景落在哪个时刻？用明确词标注（当晚 / 凌晨X点 / 次日清晨 / "同一时刻"=前幕X点）。
2. 验细节：场景内每一处时间性描写——台词（"这么晚了"类）、环境（"夜色/天光"类）、物件连续性（"停→滑、开→关"类）——是否与锚点同向？
3. 查复用：同一地点在本章多次出现时，每次是否都打时间戳？**地点复用是错觉重灾区。**

**反例（第01章实战）**：【反派甲】结尾被"同一时刻"锚到次日清晨（与后院落子平行），但台词"这么晚了"、"驶进夜色"、宾利"今晚停→清晨滑出"全是当晚深夜标记 → 读者感知时间被拽回8小时前，整章读起来"颠三倒四"。
**正例（修后）**："驶进刚亮起来的天光"+"大清早的，什么事？"+"同一时刻"锚到次日清晨后院落子 → 平行成立，时间轴干净。

### 规则二 · 多线/双渠道显影（对应质检卡 #15 · 用户核心红线）

**铁律**：同一章内多条线（或多渠道投递/多路消息/多线行动）并行时，必须让读者在脑内把各线**分离**；严禁因叙述紧邻或措辞雷同把两条线误认成一条。

**硬性要求**：
1. **每条线至少提一嘴**：非主角线（如幕后操作里的官方/律师线）至少有一处明示——一句台词或一句叙述，交代"这条线是谁、走什么渠道、去向哪里、何时见效"。只写主角线而让另一条线靠读者脑补 = 违规。
2. **措辞不得雷同**：两份不同材料/文件/消息，内容描述不得用完全相同的话（"赵氏地产违规资金流向"×2 即雷同）——读者分不清是两份。
3. **数量与清单对账**：写"N份材料/几个人/几个渠道"时，前文描述项数必须能对上（写"三份"却只描述两项 = 违规）。
4. **相邻独立线须隔离**：两条独立线若一前一后紧邻叙述，读者会默认后者是前者的结果——若二者实为独立，中间必须隔开或显式声明"另一份/另一条线"。

**反例（第01章实战）**：【老周】塞报馆（媒体线，正面动作）+ 【钱某】备律师信函（官方线，车窗剪影）紧邻叙述，两份都写"【某地产】违规资金流向" → 读者误认"同一份资料从报社流到经侦"。
**正例（修后）**：【老周】问"【钱律师】那边，也该差不多了吧？"【主角】答"他那份走的是官面，明早一准到" → 一句话钉死两条线的去向（媒体/官方）与见效时间（明早），读者脑内两条线分离。

### 与三层方法论的协同

- **IPS 逻辑预演（③）新增必答项**：本章有无平行剪切？每条线时间锚点是什么？有无多线并行？非主角线的交代点在哪？
- **迭代自检（写后）追加 2 问**：①按规则一重读所有跨场景切换，锚点是否全一致？②按规则二数一遍并行线，每条线是否都"提了一嘴"？
