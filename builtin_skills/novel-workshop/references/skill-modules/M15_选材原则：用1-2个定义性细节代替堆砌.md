## 十五、选材原则：用1-2个定义性细节代替堆砌

### 15.1 核心原则

**描写不是"写得多=写得好"。恰恰相反——一个精心挑选的细节，比一百个平庸的形容词更有力量。**

这是《七十二堂写作课》中最核心的描写法则：挑选"最深刻印象+最具关键性"的细节，舍弃其余。读者的大脑会自动用这一个细节补全整体形象，过多的描写反而剥夺了读者的想象力。

### 15.2 定义性细节的选择标准

一个合格的"定义性细节"必须同时满足三个条件：

```
① 独特性：这个细节是"只有他/她才有"的吗？
   → 如果换一个人也能用 → 不是定义性细节

② 信息密度：这一个细节能同时传达什么？
   → 至少2层信息（身份+性格 / 处境+欲望 / 过去+现在）

③ 记忆点：读者读完三天后还记得这个细节吗？
   → 如果记不住 → 不是定义性细节，换一个
```

**经典案例——孔乙己的两个定义性细节**：

| 细节 | 独特性 | 信息密度 | 记忆点 |
|------|-------|---------|-------|
| 穿长衫（又脏又破也不肯脱下） | ✅ 只有他 | 身份（读书人）+ 性格（要面子）+ 处境（穷困潦倒） | ✅ |
| 茴香豆的"茴"有四种写法 | ✅ 只有他 | 性格（迂腐）+ 价值观（执着于无用的知识） | ✅ |

鲁迅没有写孔乙己的身高、脸型、声音、步态——但两个细节就够了。读者脑中已经浮现出一个完整的落魄书生形象。

### 15.3 外貌描写的选材规则

规则：**每个角色在首次登场和关键时刻，只给1-2个定义性细节。禁止"从头到脚"的流水账。**

```
❌ 流水账式（无选材，全堆砌）：
  "她有一双大眼睛，高鼻梁，樱桃小嘴，皮肤很白，穿着一条白色连衣裙，
   脚上是一双米色高跟鞋，手里提着一个棕色皮包。"
  → 写了很多，但读完一个都记不住。

✅ 选材式（只抓1-2个定义性细节）：
  "她眼角有两道很深的笑纹，一笑就弯成月牙，哪怕不说话也透着一股亲切感。
   头发花白却梳得整整齐齐，耳后别着一根旧发夹，是她戴了十几年的物件。"
  → 两个细节：笑纹=亲切/岁月，旧发夹=念旧/有故事。
```

### 15.4 动作描写的选材规则

规则：**不写一连串动作，只写一个"出人意料又在情理之中"的动作。**

```
❌ 动作过多（稀释了力量）：
  "他先站起来，走到窗边，推开窗户，深吸一口气，又转身走回桌前，
   拿起杯子喝了一口水，最后才缓缓开口。"
  → 五个动作，读者不知道重点在哪。

✅ 只写关键动作：
  "他张了张嘴，又闭上了。最后只是把杯子往桌上一顿——
  水溅出来，他也没擦。"
  → 两个动作（闭嘴+顿杯），但比上面的五个动作更有表现力。
```

```
☐ 每个主要角色是否都有≥1个定义性细节？

```
