## 二十二、时间跳跃处理：跳跃期的写法、状态与信息管理

### 22.1 三种跳跃类型

```
═══════════════════════════════════════════
⏱ 时间跳跃三类型
═══════════════════════════════════════════

类型      │ 跨度          │ 典型场景               │ 处理策略
──────────┼──────────────┼──────────────────────┼──────────
短跳      │ 数天~数周     │ 赶路/养伤/等待         │ 1-2段概括 + 1个状态变化锚点
中跳      │ 数月~1年      │ 闭关修炼/外出历练       │ 1个代表性场景 + 回顾清单
长跳      │ 数年以上      │ 转世/封印/沉睡/大境界跨越│ 对比式写法 + 残留线索
═══════════════════════════════════════════
```

### 22.2 短跳：1-2段概括 + 状态锚点

```
【短跳模板】

[跳跃声明·1句话] + [期间概括·1-2句] + [当前状态锚点·1个细节]

示例：
  "三天后，伤口结了痂。
   这三天里他几乎没有离开过山洞，靠着储物袋里的干粮和水撑了过来。
   他试着握了握拳——灵力运转到掌心时还有些滞涩，但比起三天前已经好了太多。"

技法要点：
  · 跳跃声明必须精确到天数（不能写"过了几天"）
  · 状态锚点是读者重新"接入"角色的抓手——选最有辨识度的状态变化
  · 禁止跳跃期间插入完整场景（短跳就是短跳，不要趁机写一大堆）
```

### 22.3 中跳：1个代表性场景 + 回顾清单

```
【中跳模板】

[代表性场景·1段] → [回顾清单·逐条列出跳跃期间的关键变化]

示例·闭关三个月后：
  "三个月。洞口的藤蔓从枯枝抽成了绿帘。
   最后一次收功时，丹田里的灵力比以前多了一倍不止——运气时经脉隐隐发胀，
   像是河道突然变宽，水流一时还适应不了新宽度。（代表性场景）

   这三个月里：境界突破了一次，储物袋里多了十二颗筑基丹，肩上那道旧伤
   已经完全消了疤。只是左手的剑茧变薄了——太久没握剑了。（回顾清单）"

技法要点：
  · 代表性场景 = 最能浓缩"这期间发生了什么"的一个瞬间
  · 回顾清单 = 跳跃前状态 vs 跳跃后状态的逐条对照
  · 每项变化不超过1句话——这是在"盘点"，不是在"展开"
```

### 22.4 长跳：对比式写法 + 残留线索

```
【长跳模板】

[跳跃前·某件物品/某个人/某个习惯] → [跳跃后·同一锚点的变化] + [残留线索·暗示中间发生了什么]

示例·百年后：
  "他记得离开时，山门前的石碑上刻着自己的名字——第三个，字体还新。
   一百年了。石碑还在，只是他的名字已经被挤到了最下面一排，风吹雨打，
   字迹模糊得几乎看不清。上面密密麻麻全是新名字。（对比：石碑）

   他在碑前站了很久。老槐树还在，只是树干上多了一道歪歪扭扭的刻痕——
   像是在数什么。他数了数：二十二道。（残留线索：谁刻的？为什么要数？）"

技法要点：
  · 长跳的核心张力来自"变了"和"没变"的对照
  · 至少1个残留线索暗示跳跃期间发生了什么——不解释，交给后续章节
  · 长跳后角色必须有一个"重新认识这个世界"的过渡场景
```

### 22.5 跳跃后状态继承规则

```
【时间跳跃·附A更新必查项】

跳跃前                         │ 跳跃后必须更新                         │ 更新方式
───────────────────────────────┼──────────────────────────────────────┼──────────
附A·时间线                      │ 故事日期跳过___天/月/年                 │ 直接标注跨度
主角等级                        │ 跳跃期间是否修炼/突破？                  │ 是→更新等级
主角位置                        │ 跳跃期间是否移动？                       │ 是→更新位置
关键角色位置                    │ 所有未死亡角色重新确认位置                │ 逐一标注
持有物品                        │ 消耗品自动扣减（时间×日常消耗率）          │ 按规则计算
                               │ 新获得物品标注来源（跳跃期间获得）          │
中毒/受伤/临时状态              │ 过期状态自动清除                         │ 逐条标记
                               │ 持续状态标注"仍在持续·已过___天"          │
人际关系                        │ 标注跳跃期间的关系变化                    │ 至少检查盟友/敌对
附D·心理状态                    │ 衰减期事件是否已过期？                    │ 过期→注销
                               │ 跳跃期间是否有新的情绪事件？               │ 有→新注册
附C·承诺兑现                    │ 应兑现区间是否被跳过？                    │ 跳过→立即处理
                               │ 如有未兑现承诺被跳过 → 🟡中度违规         │
```

### 22.6 跳跃自检

```
☐ 本章是否包含时间跳跃？
   → 如果是 → 跳跃属于短跳/中跳/长跳哪种类型？
   → 跳跃后的状态锚点是否在第1段就确立（让读者立即"接入"）？
☐ 跳跃前后是否进行了状态继承检查（附A/附B2/附D/附C的跨跳更新）？
☐ 附C·承诺兑现：是否有应兑现承诺的区间被跳跃跨过？
   → 是 → 🟡中度违规，必须在跳跃前兑现或跳跃后立即处理
```
