## 模块 30：破折号解释禁令

**核心用途**：全文禁用破折号/冒号/括号加解释性文字——原因写进画面。

### 30.1 禁用句型

"——不是X，是Y" / "——是因为……" / "——也就是说……" / "——他心里清楚……" / "——尽管……"

### 30.2 合法用法（仅三种）

话被打断 / 场景切换 / 时间跳跃

### 30.3 修正原则

删掉解释 → 读者能自己得出结论？能 = 该删 | 不能 = **补画面，不补解释**

### 30.4 质检标准

搜索 `——不是` / `——是因为` / `——也就是说` → 出现即🟡。
