## 一、经典范例全文标注

### 范例段一：氛围建立 + 冲突入场

```
①一道闪电裂空而过②，黑暗中，这座在风中孤独伫立的小草庙③亮了一下，
只见那老僧在这片刻间已站在了庙门口④，一脸严肃⑤，双眉越皱越紧⑥。

西边村子中，不知何时⑦已起了一股黑气，浓如黑墨，翻涌不止⑧。
老僧站在草庙之中，死死盯着这股黑气⑨。

忽然，那股黑气一卷，盘旋而起⑩，径直便往村外而去，正向着草庙方向而来。
它速度极快，转眼即至⑪。老僧眼尖，一眼便看见其中竟夹带着一个小孩，
正是白天见过的林惊羽⑫。

老僧脸色一沉，再不迟疑⑬，也不见他如何作势⑭，枯瘦身子霍地拔地而起⑮，
直插入黑气之中。

黑暗中不知名处，传来了一声微带讶异的声音:"咦?"⑯

几声闷响⑰，黑气霍然止住，在草庙上空盘旋不去。老僧肋下夹着林惊羽，
缓缓落下，但身后袈裟已被撕去了一块⑱。

借着微弱光线，只见林惊羽双目紧闭，呼吸平稳，也不知是睡了还是晕了过去。

---普智上前一步---⑲

"阁下道法高深，为何对无知孩童下手，只怕失了身份吧?"⑳
"你又是谁，敢管我的闲事?"㉑
"此处乃青云山下，若为青云门知道阁下在此地胡作非为，只怕阁下日后就不好过了。"㉒
"青云门算什么，就仗着人多而已。老秃驴莫要多说，识相的就快快把那小孩给我。"㉓
"阿弥陀佛，出家人慈悲为怀，老衲断不能眼睁睁看着这小孩遭你毒手。"㉔
"好贼秃，你是找死。"㉕
```

### 段一技法标注

| 标注 | 技法 | 说明 |
|------|------|------|
| ① | 动词选最重 | "裂"比"闪"重十倍，破坏感和暴力美学 |
| ② | 氛围先于人物 | 在人物出现前用意象堆出气氛 |
| ③ | 意象叠加 | 黑暗+风中+孤独+伫立=四重压抑 |
| ④ | 动作即修为 | 不说"他很快"，用"已站在"展示 |
| ⑤ | Show不Tell | 不下结论"他很担心"，用"严肃"呈现 |
| ⑥ | 情绪通过细节 | "双眉越皱越紧"=忧虑但不慌乱 |
| ⑦ | 制造紧张 | "不知何时"暗示敌人已逼近但未察觉 |
| ⑧ | 四字短句控节奏 | "浓如黑墨""翻涌不止"突然加速 |
| ⑨ | 动作替代心理 | "死死盯着"比"他很戒备"有力十倍 |
| ⑩ | 短促动作 | "一卷，盘旋而起"番茄式快节奏 |
| ⑪ | 省略中间过程 | 7字完成接近过程，不写"它飞过了...又绕过了..." |
| ⑫ | 第三人称视角 | 通过老僧的视线引入信息，不跳出视角 |
| ⑬ | 果断不磨叽 | "脸色一沉，再不迟疑"=人物性格在动作中 |
| ⑭ | 省字法写高手 | "也不见他如何作势"说明修为不需蓄力 |
| ⑮ | 反差塑造人物 | "枯瘦"VS"拔地而起"=看似弱实则强 |
| ⑯ | 语气词做最大伏笔 | "咦?"三个字暗示背后还有主使 |
| ⑰ | 战斗压缩 | "几声闷响"覆盖整个战斗过程，高潮留白 |
| ⑱ | 信息叠层 | "袈裟已被撕去"=战斗结束+对手不弱+老僧没赢 |
| ⑲ | 过渡自然 | 对话前不需要"他说""他道"，动作直接衔接 |
| ⑳ | 对话有礼貌有距离 | "阁下"体现老僧身份和修养 |
| ㉑ | 反派不废话 | 直接反问，体现性格 |
| ㉒ | 对话含信息 | 亮出"青云山"背景+搬靠山+试探对方 |
| ㉓ | 反派有底气 | "青云门算什么"暗示反派来头不小 |
| ㉔ | 立场坚定 | 表明动机和决心，不拖泥带水 |
| ㉕ | 冲突升级 | 每轮对话升高一级：试探→对峙→威胁→骂战 |

### 范例段二：多阶段战斗 + 三层叙事

```
①随着他的话语，原来一直盘旋的黑气中，一道深红异芒在其中闪了一闪，
刹那间这小小草庙周围，阴风大作，鬼气大盛。②

"毒血幡!"③老僧脸上突现怒容，"孽障，你竟然敢修炼此等丧尽天良、
祸害人间的邪物，今日绝饶不了你!"④

那沙哑声音一声冷笑，却不答话⑤，只听一声呼啸，红芒大盛，从半空之中，
腥臭之气大作⑥，一面两丈红幡缓缓祭起。这时，鬼哭之声越发凄厉，
似有无数怨灵夜哭，其间还隐隐有骨骼作响声，令人毛骨悚然⑦。

"贼秃，受死!"那黑气中人一声断喝，只见从那血色红幡之上，突现狰狞鬼脸，
有三角四眼、尖齿獠牙，"咔咔咔咔"骨骼乱响处⑧，鬼脸上的四只眼睛突然
全部睁开，"吼"的一声，竟化为实体，从幡上冲出，带着无比血腥之气，
击向老僧。

---第一回合：法轮 VS 鬼物---

老僧脸上怒色更重，知道这毒血幡威力越大，修炼过程中害死的无辜之人越多。
要炼成眼前这般威势，只怕要以三百人以上的精血祭幡方才可以。⑨
这邪人实在是丧尽天良!

眼看那鬼物就要冲到眼前，老僧却并不放下肋下小孩林惊羽，只用持着
碧玉念珠的左手在身前虚空画圆，单手结佛门狮子印，五指屈起，指尖隐隐
发出金光，片刻间已在身前唤出一面金色法轮，金光闪闪，与那鬼物抵持
在半空中。⑩

"小小伎俩，也来卖......"⑪

---第二回合：七尾蜈蚣偷袭，战局逆转---

那老僧一个"弄"字还未说完，突然全身大震，只觉得抱着林惊羽的右手
手腕被异物咬了一口，一股麻痒感立时行遍半身，眼前一黑，身前法轮
登时摇摇欲坠。⑫

就在此时，前方那个鬼物又有诡异变化，在它左右四眼正中额头上，
"咔咔"两声，竟又开了一只血红巨目，腥风大起，威势更重，只听一声
鬼嚎，血色红光闪过，那鬼物将金色法轮击得粉碎，重重地打在老僧的
胸口上。⑬

老僧整个人被打得向后飞了起来，途中几声闷响，怕是肋骨已尽数断了，
肋下的林惊羽也掉在地上。片刻之后，他枯瘦的身子砸在草庙壁上，
"轰"的一声，尘土飞扬，一整面墙都塌了下来。⑭

"哈哈哈哈......"黑气中人一阵狂笑，得意无比。⑮

老僧颤巍巍地站起，喉咙一热，忍不住一口热血喷了出来，把身前僧衣都
染红了，甚至连手上念珠珠串都溅到了血迹。一时之间，他只觉得眼前金星
乱闪，全身剧痛，那股麻痒感觉也越来越逼近心脏。⑯

他强自镇定心神⑰，眼角扫过倒在地上兀自昏迷的林惊羽，却见在他衣襟之中，
缓缓爬出只分叉彩色蜈蚣，个大如掌，最奇异的是它尾部分了七叉，看去仿佛
有七条尾巴似的。而且每只分叉各呈一色，各不相同，色彩绚丽，只是美丽中
却带了几分可怖。⑱

"七尾蜈蚣!"老僧呐呐说了一句，语调中带了几分痛苦之意。⑲

---信息揭示：反派有计划，目标是老僧---

他脸上黑气越来越重⑳，嘴角也不断流出血来，似乎已是难以支撑，但仍然
强撑着不愿倒下。他看着半空中那团黑气，道:"你将这天下奇毒之物放在
那孩子身上，又故意隐藏实力，看准机会一击伤我。你是冲着我来的吧?"㉑

黑气中人"嘿嘿"冷笑一声，道:"不错，我便是专门冲着你普智秃驴来的。
若非如此，凭你一身天音寺佛门修行，倒也不好对付。好了，现在快快把
'噬血珠'交出来，我便给你七尾蜈蚣的解药，饶你不死!"㉒

普智惨笑一声，道:"枉我名中还有一个智字，竟想不到你炼这毒血幡邪物，
岂有不贪图噬血珠的道理。"他脸色一肃，断然道，"要我将这世间至凶之物
给你，却是妄想。"㉓

那黑气中人大怒:"那你便去见你的佛祖吧。"红芒一闪，毒血幡迎风招摇，
鬼哭声声，巨大鬼物再现，在空中微一盘旋，再次冲向普智。

---第三回合：六字大明咒，绝地反击---

普智手掌一翻，将那深紫珠子一把抓在手中，藏在怀里，双手随即结左右
水瓶印，两目圆睁，全身上下隐有金光，口中一字一字念道:
"吨嘛呢呗咪叫!"㉔

"六字大明咒。"黑气中人的口气立时多了几分凝重。㉕

随着普智"叫"字声落，刹那间所有碧玉念珠一起大放光芒，同一时刻，
那邪人祭起的鬼物已冲到跟前，血腥之气扑面而来。但一接触到碧玉青光，
顿时化为无形，不能近前，就此僵持在半空中。

饶是如此，普智的身子又是一阵摇晃，七尾蜈蚣是天下绝毒之物，纵然他
道行深厚，仍然难以抵挡。只是他隐泛黑气的脸上，却露出一丝淡淡笑容，
带了几分凛然。㉖

"呔!"㉗
普智一声大喝，如作狮子吼，声震四野，身前碧玉念珠受佛力驱驰，光芒
更盛，忽地一颗念珠"噗"的一声碎裂，在半空中幻作一个"佛"字，疾冲
向前，打在那鬼物脸上。

"哇......呀!"那鬼物一声凄厉号叫，登时退了几步，周身红芒大为衰退，
显然已受了伤。黑气中人怒道:"好你个秃驴!"

他正要动作，只是为时已晚。说时迟那时快，片刻间七八颗念珠都幻作
佛家真言打中鬼物。那鬼物号叫不止，连连退避，做恐惧状，在被第九颗
碧玉念珠击中时，终于一声长嚎，五目齐齐迸裂，骨骼乱响，轰然一声
跌落在地，挣扎了几下，便僵直不动了，缓缓化作血水，腥臭无比。㉘
```

### 段二技法标注

| 标注 | 技法 | 说明 |
|------|------|------|
| ① | 承接自然 | "随着他的话语"无痕衔接上一段对话 |
| ② | 法宝出场用感官轰炸 | 视觉(红芒)+体感(阴风)+氛围(鬼气) |
| ③ | 通过角色喊出法宝名 | 老僧喊出"毒血幡"既自然又带情绪 |
| ④ | 情绪推动剧情 | 愤怒之下老僧承诺"绝饶不了你"，冲突固化 |
| ⑤ | 反派不废话 | "一声冷笑，却不答话"比长篇大论高级 |
| ⑥ | 嗅觉加入感官 | "腥臭之气大作"让读者闻到 |
| ⑦ | 声音环境描写 | "鬼哭之声""骨骼作响"多维度造氛围 |
| ⑧ | 拟声词增强画面 | "咔咔咔咔"让读者听到骨骼响 |
| ⑨ | 战中说设定 | 通过老僧的视角说出"300人精血"，自然不突兀 |
| ⑩ | 战中仍有细节 | "单手结印""不给放下小孩"展示修为+性格 |
| ⑪ | 嘲讽未完被打断 | "小小伎俩"没说完→中毒，最经典的节奏打断 |
| ⑫ | 战斗中下毒 | 利用老僧的慈悲心（抱着小孩）做突破口 |
| ⑬ | 鬼物有三阶段 | 初现(四眼)→受伤(五目全开)→被杀(碎裂) |
| ⑭ | 碰撞感 | "轰"的一声+墙塌了=力量感的实体化 |
| ⑮ | 反派得意=虐读者 | 笑声在主角受伤后出现，拉仇恨值 |
| ⑯ | 毒效渐进的写法 | "行遍半身→逼近心脏"制造时间紧迫感 |
| ⑰ | 省字写心理 | "强自镇定心神"6字替代300字内心戏 |
| ⑱ | 描写反派也认真 | 七尾蜈蚣七色分叉用了50字描写——不因为它是"反派的东西"就敷衍 |
| ⑲ | 名字即评价 | "七尾蜈蚣!"语气中已经带出"这是顶级毒物" |
| ⑳ | 毒效持续 | "脸上黑气越来越重"不是中毒后就好了，持续恶化 |
| ㉑ | 主角会推理 | 老僧从布局中看出了对方的目标是自己，不傻 |
| ㉒ | 名在关键时刻出 | "普智"这个名字在2000字后才揭晓——名字是奖励 |
| ㉓ | 拒绝不磨叽 | 断然拒绝，展现骨气。反派反而被激怒=反派情绪推动剧情 |
| ㉔ | 口诀一类用缓写 | "一字一字念道"拉长节奏，为后续爆发蓄力 |
| ㉕ | 通过对手反应体现实力 | "口气多了几分凝重"比直接写"这招很强"高级 |
| ㉖ | 赢不了的惨笑 | "淡淡笑容，带了几分凛然"=悲壮感 |
| ㉗ | 单字爆发 | "呔！"一个字=力量集中的极简写法 |
| ㉘ | 战斗结束写得完整 | "轰然跌落→挣扎→僵直→化作血水"四步收尾 |
