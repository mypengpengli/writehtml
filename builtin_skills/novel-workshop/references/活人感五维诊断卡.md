# 活人感五维诊断卡

> 配套文件：`agents/writing-executor.md`（v3.2.0 谢晚活人感专项 A1 上位指标）
> 用途：谢晚写前必读的"北极星"，替代"以规则清单为纲"的心理姿态；周言 `scripts/check_style.py` 扫描的反例来源。
> 版本：v3.2.0（2026-08-20）
> ⚠ 占位符约定：本文所有 【主角】【配角甲】【配角乙】 等均为通用演示载体，不得写入任何具体项目角色名（专家包防污染铁律）。

---

## 一、底层判据

**特异性是 AI 味的解药**：死文的每个细节都可以被同类替换而毫无损失，活文的细节不可替换。

五分量共同指向一个事实——活人感不是玄学，是五个可辨识、可工程化、可自检的分量。

---

## 二、五维定义 + 活句标志 + 死文反模式

### 维度 1 · 特异性（Specificity）
- **定义**：细节是"这一个"，不是"这一类"。
- **活句标志**：读到细节能想见唯一画面，换成别人就讲不通。
- **死文反模式**：套话式情绪/动作描写，任意同类角色可替换而文意无损。

| | 内容 |
|---|---|
| ✅ 正例 | 【主角】手不自觉去摸兜里的打火机，摸了个空才想起三天前就扔了。 |
| ✅ 正例 | 【配角甲】把筷子架在碗沿上，转了半圈，没吃。 |
| ✅ 正例 | 【主角】鞋尖朝着门，人却还坐在椅子上没动。 |
| ❌ 反例（库·待项目生长） | 他很紧张地搓了搓手。 |
| ❌ 反例（库·待项目生长） | 她默默地流下了眼泪。 |
| ❌ 反例（库·待项目生长） | 他深吸一口气，平复了一下心情。 |
| ❌ 反例（库·待项目生长） | 房间里弥漫着一股压抑的气氛。 |
| ❌ 反例（库·待项目生长） | 两人相视无言，气氛有些尴尬。 |

### 维度 2 · 内在性（Interiority）
- **定义**：角色有连续内心生活，不是事件触发态。
- **活句标志**：没有台词的段落里，角色仍在"过自己的日子"。
- **死文反模式**：角色只在轮到自己时才存在，下一场立刻清零。

| | 内容 |
|---|---|
| ✅ 正例 | 旁人在吵架，【主角】盯着桌上凉透的茶，想起今早泡它时水还烫嘴。 |
| ✅ 正例 | 【配角乙】排队时数着前面的人，数到第七个又从头数——他根本没在听广播。 |
| ✅ 正例 | 【主角】等回信的间隙把窗台擦了三遍。 |
| ❌ 反例（库·待项目生长） | 他站在原地，等待命令。 |
| ❌ 反例（库·待项目生长） | 她听完了，点了点头表示理解。 |
| ❌ 反例（库·待项目生长） | 消息传来，他陷入了沉思。 |
| ❌ 反例（库·待项目生长） | 他沉默了一会儿，然后继续赶路。 |
| ❌ 反例（库·待项目生长） | 听到这个消息，她露出了思索的神情。 |

### 维度 3 · 潜台词（Subtext）
- **定义**：说的不等于想的，文字信任读者。
- **活句标志**：台词底下有另一层意思，读者自己能品出来。
- **死文反模式**：台词即直给信息，说完即尽，毫无余味。

| | 内容 |
|---|---|
| ✅ 正例 | "钱的事……我们能不能再谈谈？"（其实是"我现在还不上"） |
| ✅ 正例 | 【配角甲】"你来决定。"（其实是"我不敢担这个干系"） |
| ✅ 正例 | "没事，你去忙。"（其实是"你果然还是先走了"） |
| ❌ 反例（库·待项目生长） | "你把钱还给我，不然我就报警。" |
| ❌ 反例（库·待项目生长） | "我不喜欢你这种做法，请你停止。" |
| ❌ 反例（库·待项目生长） | "你错了，我是对的，事实就是这样。" |
| ❌ 反例（库·待项目生长） | "这件事我不能告诉你，因为涉及机密。" |
| ❌ 反例（库·待项目生长） | "你不要生气，我不是那个意思。" |

### 维度 4 · 不对称（Asymmetry）
- **定义**：人有口吃、跑题、自相矛盾；文字密度不均匀。
- **活句标志**：重要的地方慢下来，不重要的地方一笔带过。
- **死文反模式**：每段用力均匀、结构工整如流水账。

| | 内容 |
|---|---|
| ✅ 正例 | 他讲了三页纸的来龙去脉，最后一句"所以我没去"只用了五个字。 |
| ✅ 正例 | 大战前写了两百字风声，战败只用"输了"两个字。 |
| ✅ 正例 | 【主角】卡在"对不起"三个字上，整段反复绕，就是没说出来。 |
| ❌ 反例（库·待项目生长） | 首先……其次……最后……（三段等长，权重相同） |
| ❌ 反例（库·待项目生长） | 他先做了A，然后做了B，接着做了C，最后做了D。 |
| ❌ 反例（库·待项目生长） | 这件事有三个方面：一是……二是……三是…… |
| ❌ 反例（库·待项目生长） | 回忆、现实、感慨各写一段，篇幅均匀。 |
| ❌ 反例（库·待项目生长） | 每个角色出场都给等量的外貌+动作+台词。 |

### 维度 5 · 声音（Voice）
- **定义**：节奏/用词/句法有指纹且贯穿。
- **活句标志**：抽一段不看署名也知道是谁写的。
- **死文反模式**：句长均匀、开头雷同、主语全是"他"。

| | 内容 |
|---|---|
| ✅ 正例 | 【配角乙】句句短促、爱用反问、"是吧？""你说呢？"——口语指纹贯穿。 |
| ✅ 正例 | 【主角】独白爱用长句裹着破折号，旁白却极简——两种声音分明。 |
| ✅ 正例 | 全文环境描写只用"气味"切入——这是作者的感官偏好指纹。 |
| ❌ 反例（库·待项目生长） | 连续五句以"他"开头。 |
| ❌ 反例（库·待项目生长） | 每段落长都在 80-100 字，毫无波动。 |
| ❌ 反例（库·待项目生长） | 所有对话都是一个节奏，分不出谁在说话。 |
| ❌ 反例（库·待项目生长） | 开头永远是"这时候""就在这时""与此同时"。 |
| ❌ 反例（库·待项目生长） | 形容词堆砌均匀，像同一把尺子量出来的。 |

## 三、反例库生长机制（E2 闭环）

- 反例库初始为**通用示例**（上方 ❌ 行），仅作示范。
- 每个项目进入"外部破壁点（每 10 章用户抽读）"后，用户指认的"读着像机器写的"死句，**追加进本项目反例库**（标注来源章节）。
- 反例库随项目生长，是系统自我纠偏的唯一通道——`scripts/check_style.py` 的「反例库命中」扫描直接消费本卡中的 ❌ 句。
- 维护权：主理人（林墨）在接受用户反馈时更新；周言在质检中发现典型死句也可提议入册。

## 四、谢晚使用方式（写前 30 秒）

1. 写前装载：本章基调卡（来自注射包）+ 风格范本 + 文风指纹卡（B2/B3）。
2. 默念五维，问自己：这一章我想让哪个维度"立住"？（不必五维齐发，但至少 1 维要有意识）
3. 写完后按五维逐维 1-5 分自评（见 writing-executor.md 层级三）；任一维 ≤2 → 回炉重写。
4. 恒 4-5 全分（无波动）同样可疑——陆衡审计 G 层会抽查"恒高分=走过场"。
