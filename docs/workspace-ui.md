# 写作工作区界面优化

实施日期：2026-10-13。

## 操作入口

目录顶部提供正文、画布和灵感三个入口。本章资料保留正文左侧的剧情、流程、记忆、关系、提醒和上下文。更多菜单的人物与设定入口打开画布设定库；剧情推演从剧情规划进入。人物新建与完整人物档案继续复用现有编辑功能。

## 布局与阅读

普通 AI 面板占据独立布局列，沙盘的覆盖规则只在沙盘打开时生效。根据剩余宽度收起目录、切换本章资料抽屉、调整画布详情的并排或覆盖方式。正文顶部操作保持可见；手机资料与 AI 使用前景面板。

画布主要文字提升到 13-14px，辅助信息至少 12px。正文纸面、工作区和输入区分别使用不同表面色。空设定分类收成新增入口，选中分类和搜索同时作用于中部摘要。搜索不会改变全书统计，也不会将搜索无结果误报为作品没有基础设定。

左侧全书资源采用两级树形目录：人物、规则、地点、技能、道具、组织作为分类文件夹，资源作为子项。箭头独立控制折叠，分类名称筛选中间画布，子项打开原有详情；每个分类提供新建入口。分类筛选不会隐藏其他文件夹，全部资源可以取消筛选。搜索跨分类匹配名称和摘要，自动展开匹配的分类，清空后恢复原折叠状态。折叠偏好按账号和作品保存在当前浏览器。树支持上下方向键、左右展开/折叠、Home/End 和 Enter，长名称截断但完整名称及摘要可悬停查看；手机保留 44px 点击高度。

## 详情与保存

设定卡、人物的基础、本章状态和历史分别显示。设定卡的范围、属性、初始知识边界默认折叠，名称、摘要、详细说明直接可编辑。普通输入自动同步；本章状态草稿保存在本机，明确记录后才产生状态版本。显示位置靠近当前对象，分别报告两种保存状态。

固定操作栏独立于可滚动表单。切换对象前等待已有保存，基础字段和状态字段在切换页签时仍保留在表单中。历史从现有版本表读取，新设定详情 API 校验账号和章节范围。

## AI 与定位

AI 输入占据整行，附件、语音和发送排列在下面。手机写作建议默认折叠；连续普通工具操作可展开查看，撤销、错误、删除和待确认操作单独保留。阅读旧消息时不会因重新渲染强制滚到末尾。

目录支持标题、章号和待处理筛选；剧情规划支持待处理过滤和上级路径。正文进入画布前记录光标与滚动位置，返回同一章时恢复；画布记录当前对象、详情页签、导航和滚动位置。这些状态在当前页面内保存，不改变正文保存、World State 或模型上下文机制。

## 沙盘与键盘交互（2026-11-14）

沙盘按卡片实际高度整理树形布局，新节点渲染后再次避让并滚入视野。支持 Ctrl/⌘＋滚轮缩放、空白处鼠标拖动平移，以及 +、-、0 快捷键和缩放工具条；触屏仍使用原生滚动。缩放后的拖拽使用画布坐标，轻微点击不触发移位和保存。打开、整理默认至少保留 60% 缩放，手动“适应”允许进一步缩小。深浅主题分别提供方向标签文字颜色。

窄屏编辑工具条保留本章字数。查找替换提供最多 20 次轻量撤销快照；快照绑定账号、作品、章节及加载代次，普通输入交还浏览器原生撤销，重新加载正文或恢复版本时清除旧快照。

弹窗统一补充名称、对话框语义、Tab 焦点循环和关闭后焦点归位；按需创建的图片素材库也使用同一机制。Esc 只处理当前最上层弹窗，正文冲突仍要求明确选择；输入法组词时不会关闭弹窗或工作区。

### 新增回归

`test_workspace_ui.py` 同时检查替换撤销及跨章节隔离、同步聚焦后的焦点归位、嵌套弹窗、输入法 Esc、动态图片库、长卡片避让、树形布局、缩放拖拽、点击不移位、窄屏字数，并输出沙盘深浅主题及手机尺寸截图。浏览器测试使用隔离数据库和本地后端，不调用真实模型；手机尺寸模拟不等同于真机触屏验收。

## 章节、关系与操作搜索（2026-11-15）

章节行支持键盘回车选择，行尾“⋯”提供上移、下移和删除，手机按钮保持 44px。排序即时更新序号；同一作品保存期间禁止重复提交，失败时优先重新读取服务端顺序，无法联网时回滚快照。延迟响应只更新原作品，切换作品不会串写目录；重排后的待复核标记重新从服务端读取。

章节状态画布的缩放条固定在视口外层，支持 40%–160%、以光标为中心的 Ctrl/⌘＋滚轮、空白处拖动平移和“适应”。不再截断章前状态的前八项；手机继续采用完整宽度的纵向卡片。灰字、阶段提示及画布强调色按深浅主题配置，节点名称、摘要和影响提醒提高字号。

人物关系以可交互 SVG 展示，支持方向、多条关系、历史关系虚线、悬停关联高亮和放大查看。点击或键盘选择关系可进入原有编辑表单；下方完整列表保留。布局最多计算 28 人、100 条关系，并明确显示展示数量；可聚焦某个人物查看关联，避免大作品的图计算阻塞输入。

Ctrl/⌘＋K 或“更多 → 搜索操作 / 章节”可搜索现有菜单、视图和当前作品章节，支持上下键、回车、触屏和中文组词保护。复用统一弹窗焦点管理；必须选择的冲突对话框打开时不允许从搜索面板绕开。

字数区域增加“本机今日净增”：按本浏览器今日首次打开各章节的实际编辑器字数建立基线，累计仍存在章节的净变化，含 AI 改稿，最低显示 0。导入、新增有正文的章节在首次打开时建立各自基线，删除章节不制造新增字数。记录仅存浏览器，不能作为跨设备、精确工时或纯手写字数统计；存储不可用时隐藏该数字。

新增功能组织在 `static/workspace-tools.js`，沿用现有后端 API，不增加依赖。`test_workspace_tools_ui.py` 接入现有隔离浏览器回归，覆盖排序恢复与作品隔离、手机菜单、今日净增刷新/导入、命令搜索、关系编辑与转义、长关系数据的规模限制、画布适应与缩放锚点。

## 回归

`test_workspace_ui.py` 使用独立数据库和临时端口，覆盖 1920、1440、1024、390px，检查面板边界、工具折叠、错误可见、表单切换、自动同步、状态记录、历史、底栏和位置恢复。已加入 GitHub CI。测试需要 Playwright Chromium；运行时会启动并关闭自己的测试服务。

同一测试服务随后运行原有 `test_story_plan_ui.py` 和 `test_writing_packs_ui.py`，固定底栏的按钮定位已同步更新；浏览器渠道可通过 `BROWSER_CHANNEL` 指定，CI 使用安装的 Chromium。后端冒烟补充了新设定详情端点的历史读取与账号隔离检查。应用依赖、数据库结构和 Docker 更新步骤保持原样。
