# 写作工作区界面优化

实施日期：2026-10-13。

## 操作入口

目录顶部提供正文、画布和灵感三个入口。本章资料保留正文左侧的剧情、流程、记忆、关系、提醒和上下文。更多菜单的人物与设定入口打开画布设定库；剧情推演从剧情规划进入。人物新建与完整人物档案继续复用现有编辑功能。

## 布局与阅读

普通 AI 面板占据独立布局列，沙盘的覆盖规则只在沙盘打开时生效。根据剩余宽度收起目录、切换本章资料抽屉、调整画布详情的并排或覆盖方式。正文顶部操作保持可见；手机资料与 AI 使用前景面板。

画布主要文字提升到 13-14px，辅助信息至少 12px。正文纸面、工作区和输入区分别使用不同表面色。空设定分类收成新增入口，选中分类和搜索同时作用于中部摘要。搜索不会改变全书统计，也不会将搜索无结果误报为作品没有基础设定。

## 详情与保存

设定卡、人物的基础、本章状态和历史分别显示。设定卡的范围、属性、初始知识边界默认折叠，名称、摘要、详细说明直接可编辑。普通输入自动同步；本章状态草稿保存在本机，明确记录后才产生状态版本。显示位置靠近当前对象，分别报告两种保存状态。

固定操作栏独立于可滚动表单。切换对象前等待已有保存，基础字段和状态字段在切换页签时仍保留在表单中。历史从现有版本表读取，新设定详情 API 校验账号和章节范围。

## AI 与定位

AI 输入占据整行，附件、语音和发送排列在下面。手机写作建议默认折叠；连续普通工具操作可展开查看，撤销、错误、删除和待确认操作单独保留。阅读旧消息时不会因重新渲染强制滚到末尾。

目录支持标题、章号和待处理筛选；剧情规划支持待处理过滤和上级路径。正文进入画布前记录光标与滚动位置，返回同一章时恢复；画布记录当前对象、详情页签、导航和滚动位置。这些状态在当前页面内保存，不改变正文保存、World State 或模型上下文机制。

## 回归

`test_workspace_ui.py` 使用独立数据库和临时端口，覆盖 1920、1440、1024、390px，检查面板边界、工具折叠、错误可见、表单切换、自动同步、状态记录、历史、底栏和位置恢复。已加入 GitHub CI。测试需要 Playwright Chromium；运行时会启动并关闭自己的测试服务。

同一测试服务随后运行原有 `test_story_plan_ui.py` 和 `test_writing_packs_ui.py`，固定底栏的按钮定位已同步更新；浏览器渠道可通过 `BROWSER_CHANNEL` 指定，CI 使用安装的 Chromium。后端冒烟补充了新设定详情端点的历史读取与账号隔离检查。应用依赖、数据库结构和 Docker 更新步骤保持原样。
